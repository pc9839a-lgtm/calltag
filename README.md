# 콜태그 (CallTag)

전화가 오면 고객 상태와 최근 메모를 보여주고, 통화가 끝나면 고객 할 일과 캘린더까지 연결하는 페이지로 CRM 서비스입니다.

## 제품 한 문장

> 전화 전에는 고객 상황을 확인하고, 전화 후에는 다음 할 일을 남긴다.

## 페이지로 서비스 관계

- `페이지로 콜링크`: 통화 후 문자·이미지·템플릿·발송 이력
- `페이지로 콜태그`: 고객 상태·메모·통화·할 일·캘린더·통계
- 공통 체계: 페이지로 계정·고객 식별자·통화 식별자·웹 관리

권장 공개 도메인은 `https://calltag.pagero.kr`이다. 향후 통합 포털은 `https://app.pagero.kr`, 공통 API는 `https://api.pagero.kr`을 기준으로 한다.

## 현재 개발 버전

- Android 버전: `v0.13.0`
- 패키지명: `kr.pagero.calltag`
- 최소 Android: API 26
- 수신 고객정보 표시: Android 10 이상 권장
- 개발 브랜치: `agent/calltag-foundation`

## v0.13.0 핵심 변경

### 선택 UX 통일

글자 목록에 클릭 기능만 붙인 화면을 제거했다.

다음 선택 화면은 모두 배경·간격·색상·화살표가 있는 카드 버튼으로 표시한다.

- 고객 선택
- 고객 상태 선택
- 고객 상태 필터
- 최근 연락일 필터
- 일정 종류 선택
- 일정 변경 메뉴
- 통화 후 다음 할 일 종류

주요 실행은 채워진 버튼, 보조 실행은 테두리 버튼으로 구분한다. 고객 카드 전체에는 숨은 클릭 기능을 두지 않는다.

### 고객 탭

고객 탭 안에 상단 하위 탭을 제공한다.

1. 고객 목록
2. 통계

고객 목록 기능:

- 고객명 검색
- 전화번호 검색
- 고객 상태 필터
- 최근 연락일 필터: 전체 기간, 오늘, 최근 7일, 최근 30일
- 고객 카드에서 상태 변경
- 고객 상세 이동
- 고객 상태·색상 편집

통계 기능:

- 전체 고객 수
- 오늘 할 일
- 기한이 지난 할 일
- 상태별 고객 수
- 오늘 연락 고객 수
- 최근 7일 연락 고객 수
- 예정된 전체 할 일 수

### 고객 상태

기본 고객 상태는 세 개다.

1. 신규
2. 진행 중
3. 완료

기본 세 개도 이름과 색상을 수정할 수 있다. 추가 상태는 사용자가 직접 만들고 수정·삭제할 수 있다. 순서 변경 기능은 제공하지 않는다.

`고객 추가` 주요 버튼과 신규 상태가 같은 색상으로 보이지 않도록, 기존 기본 파란색 신규 상태는 보라색으로 변경한다. 사용자가 이미 수정한 색상은 유지한다.

### 할 일과 일정 종류

`다음 연락`이라는 고정 개념을 없애고 `다음 할 일`로 변경했다.

기본 할 일 종류:

1. 전화하기
2. 미팅
3. 자료 보내기

기본 종류도 이름과 색상을 수정할 수 있다. 사용자 일정 종류를 추가·수정·삭제할 수 있다. 순서 변경 기능은 제공하지 않는다.

종류별 실행 문구도 구분한다.

- 전화하기: `전화하기`
- 자료 보내기: `자료 보냄`
- 미팅: `미팅 완료`
- 사용자 할 일: 종류명 또는 `처리 완료`

### 통화 자동 처리

- 연결된 발신·수신 통화는 미처리 목록에 계속 쌓지 않는다.
- 부재중, 거절, 연결되지 않은 발신만 홈의 `확인할 통화`에 표시한다.
- 모호한 `완료` 버튼을 제거한다.
- 확인할 통화에는 `다시 전화`와 `할 일 등록` 버튼만 표시한다.
- 전화하기 일정이 있는 고객과 연결된 통화가 감지되면 가장 가까운 미완료 전화 일정을 자동 완료한다.
- 같은 번호의 기존 부재중·거절·연결 안 됨 항목은 연결된 통화 후 자동 처리한다.

### 캘린더

- 월 헤더와 달력 전체를 하나의 카드로 구성
- 날짜마다 반복되던 과도한 카드 테두리 제거
- 선택 날짜는 파란 배경과 흰 글자
- 오늘 날짜는 테두리
- 일정 점 대신 일정 제목 표시
- 첫 일정 제목과 추가 일정 개수 표시
- 선택 날짜 아래에 전체 일정 카드 표시
- `+ 일정 추가`를 전체 폭 주요 버튼으로 표시
- 일정 색상은 고객 상태가 아니라 일정 종류 색상을 사용

### 수신 고객정보 팝업

- 수신정보 서비스에서 고객정보 전용 화면 실행을 직접 요청
- 전체 화면 실행이 막히면 최근 메모가 포함된 높은 중요도 알림으로 대체
- 설정 화면에 최근 수신 감지 결과와 시각 표시
- 미등록 번호, 제외번호, 전화번호 미전달, 화면 실행 차단, 알림 차단을 구분해 표시
- 잠금화면 표시 범위: 고객명만 / 상태까지 / 메모까지

### 상단 잘림

Android 15에서 일부 화면이 상태바 아래로 들어가던 문제를 막기 위해 앱 테마의 edge-to-edge 적용을 해제했다. 주요 화면 헤더는 상태바 아래에서 시작한다.

## 회원 기능

콜태그는 페이지로 콜링크와 같은 회원가입·로그인 서버를 사용한다.

- 로그인
- 회원가입
- 이메일 인증
- 비밀번호 재설정
- 개인정보 수집·이용 동의
- 이용약관 동의
- 계정정보
- 로그아웃
- 2단계 회원탈퇴

회원탈퇴 시 공유 페이지로 계정과 콜태그 로컬 고객·통화·할 일 데이터가 삭제된다.

## 고객 추가

고객 추가의 기본 진입은 최근 통화 목록이다.

- 최근 통화에서 이름·전화번호 불러오기
- 이미 등록된 번호 제외
- 직접 입력 지원
- 연락처 저장 여부만으로 기존 고객을 판단하지 않음

## 핵심 원칙

1. 클릭 가능한 요소와 읽기 전용 텍스트를 같은 모양으로 만들지 않는다.
2. 고객 상태는 고객 등급이 아니라 현재 진행 상황이다.
3. 고객 상태와 일정 종류는 이름과 색상을 수정할 수 있어야 한다.
4. 고객 카드 전체에 숨은 클릭 기능을 넣지 않는다.
5. `다음 연락`이 아니라 전화·미팅·자료 전송 등 실제 할 일을 관리한다.
6. 연결된 통화는 전화 할 일과 미처리 통화를 자동 처리한다.
7. 통화 전에는 고객 상태와 최근 메모를 확인할 수 있어야 한다.
8. 통화 후 정리는 10초 안에 끝나야 한다.
9. 캘린더에는 일정 점이 아니라 일정 제목을 표시한다.
10. 360dp 화면과 큰 글자 환경에서 좌우·상단 잘림을 허용하지 않는다.
