# 콜태그 (CallTag)

전화가 오기 전 고객의 핵심 메모를 확인하고, 통화가 끝난 뒤 고객 상태·메모·일정·문자를 한 번에 처리하며 후속문자까지 연결하는 Android 고객관리 앱입니다.

## 정식 서비스명과 브랜드 기준

- 정식 한글 서비스명: **콜태그**
- 정식 영문 서비스명: **CallTag**
- 앱명, 스토어명, 웹사이트명, 고객 안내명은 모두 `콜태그`로 통일
- 공개 대표 도메인: `https://calltag.pagero.kr`
- 공개 웹페이지 소스: `web/index.html`

`페이지로 콜링크`와 `콜링크`는 이전 문자 앱과 소스 이력을 설명할 때만 사용하는 레거시 명칭입니다. 공개 웹, 앱 UI, 스토어 소개, 요금제, 고객 안내에서는 별도 서비스명처럼 노출하지 않습니다.

전화관리와 문자자동화는 서로 다른 앱이 아니라 **콜태그 하나의 기능군**입니다.

## 웹사이트 통합 기준

공개 웹사이트는 콜태그 하나만 운영합니다.

- 전화관리·고객관리·일정·문자자동화를 한 제품 흐름으로 설명
- 문자 기능을 별도 콜링크 제품처럼 소개하지 않음
- 대표 URL과 canonical은 `https://calltag.pagero.kr/`로 고정
- 루트 배포와 `web` 출력 디렉터리 배포 모두 같은 콜태그 페이지로 연결
- 이전 `call.pagero.kr` 계열 주소를 계속 운영한다면 Cloudflare에서 `calltag.pagero.kr`로 영구 리디렉션

상세 기준은 [`docs/BRAND_WEB_CONSOLIDATION_KO.md`](docs/BRAND_WEB_CONSOLIDATION_KO.md)를 따릅니다.

## 제품과 구독

앱과 계정은 콜태그 하나이며 구매 권한에 따라 기능만 나눕니다.

| 상품 | 월 구독료 | 제공 범위 |
|---|---:|---|
| 전화관리 | 1,900원 | 고객·통화·상태·메모·일정·통계 |
| 문자자동화 | 990원 | 템플릿·자동·수동·예약·단체문자 |
| 통합 이용 | 2,500원 | 전화관리와 문자자동화 전체 및 연결 자동화 |

## 최종 핵심 흐름

```text
전화 수신 전
→ 연락처 이름에서 고객명 + 핵심 메모 확인
→ 통화
→ 통화 종료 큰 정리창
→ 고객 상태·메모·다음 할 일 저장
→ 즉시 문자 또는 후속문자
→ 고객 타임라인 반영
```

사용자 화면에서 `전화정보 고객표시`, `수신정보 앱`, `오버레이 테스트` 같은 기술 메뉴를 제거하고 최초 실행 시 Android 시스템 권한창만 순서대로 요청합니다.

## 문자 메뉴 최종 구조

```text
수신 / 발신 / 부재중 / 후속
```

추가 메뉴:

- 템플릿
- 그룹·단체문자
- 예약·후속문자
- 발송내역
- 발송 제외
- 회선·업무시간·중복방지 설정

기능명은 `후속문자`로 통일하며 `1일 후 / 3일 후 / 7일 후 / 직접 선택`은 발송 시점으로 표시합니다.

## 저장형 템플릿

여러 템플릿을 저장하고 반복 사용합니다.

- 저장·수정·복제·삭제
- 즐겨찾기·최근 사용·검색
- 이미지 첨부
- 수신·발신·부재중·후속 기본 템플릿 지정
- 고객 상세·통화 종료·일정·단체문자에서 공통 사용

지원 변수:

```text
{고객명}
{전화번호}
{통화일자}
{통화시간}
{내이름}
{상호명}
{다음일정}
```

미지원 변수나 미치환 변수가 남으면 발송하지 않습니다.

## 고객과 일정 연결

고객 상세 상단 행동:

```text
전화 / 일정 추가 / 문자
```

상태 변경은 고객명 옆 상태 배지 드롭다운으로 이동합니다.

일정 추가에서는 연결 문자를 선택합니다.

- 없음
- 지금 안내문자
- 일정 하루 전
- 일정 시간
- 일정 완료 후

연결 문자는 후속문자로 저장하고 일정 변경·완료·삭제에 따라 함께 변경·발송·취소합니다.

## 문자 안전장치

### 발송 제외

- 자동문자 제외
- 전체 문자 제외
- 수신·발신·부재중·후속 중 특정 유형 제외

### 중복발송 방지

- 같은 통화의 같은 목적 문자 한 번
- 자동발송과 통화 정리창 수동발송 병합
- 같은 일정의 활성 후속문자 한 건
- 같은 번호가 여러 그룹에 포함돼도 캠페인당 한 번
- 최근 동일 템플릿·본문 제한

## 그룹과 단체문자

- 수동 그룹
- 고객 상태·최근 연락·일정·관리공백 기반 스마트 그룹
- 템플릿 선택
- 수신자별 변수 치환
- 중복번호·제외 고객·번호 오류 제거
- 최종 발송 인원 확인
- 즉시·예약 순차발송
- 실패 대상만 재발송

## 삼성 리마인더와 차별점

> 리마인더는 할 일을 알려줍니다. 콜태그는 전화가 끝난 뒤 해야 할 일을 실제로 처리합니다.

콜태그는 통화 이벤트를 고객 상태, 상담 메모, 일정, 저장형 문자 템플릿, 후속문자, 제외·중복 정책, 그룹 발송과 하나의 고객 타임라인으로 연결합니다.

## 운영 주의

- 기본 전화 앱을 대체하지 않아 에이닷 통화녹음·AI 요약과 공존합니다.
- SMS·통화기록 권한은 스토어 정책 심사 대상입니다.
- 자동문자 규칙과 템플릿은 사용자가 직접 설정해야 합니다.
- 통신사 SMS·MMS 요금은 콜태그 월 구독료에 포함되지 않습니다.
