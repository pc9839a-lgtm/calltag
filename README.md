# 콜태그 (CallTag)

전화가 오면 전화 화면 위에서 고객 상태와 최근 메모를 확인하고, 통화가 끝나면 고객 할 일과 캘린더까지 연결하는 페이지로 CRM 서비스입니다.

## 페이지로 서비스 관계

- `페이지로 콜링크`: 통화 후 문자·이미지·템플릿·발송 이력
- `페이지로 콜태그`: 고객 상태·메모·통화·할 일·캘린더·통계
- 공통 체계: 페이지로 계정·고객 식별자·통화 식별자·웹 관리

권장 공개 도메인은 `https://calltag.pagero.kr`이다. 향후 통합 포털은 `https://app.pagero.kr`, 공통 API는 `https://api.pagero.kr`을 기준으로 한다.

## 현재 개발 버전

- Android 버전: `v0.16.0`
- 패키지명: `kr.pagero.calltag`
- 최소 Android: API 26
- 수신 고객정보 표시: Android 10 이상 권장
- 개발 브랜치: `agent/calltag-foundation`

## 전화 수신 고객정보 오버레이

수신 고객정보는 전화 앱 위에 표시되는 오버레이 카드가 기본이다.

표시 내용:

- 고객명
- 현재 고객 상태와 상태 색상
- 전화번호
- 최근 메모 최대 4줄
- 최근 연락 시각
- 고객 상세 보기 버튼
- 닫기 버튼

동작 기준:

1. Android 수신정보 서비스가 등록 고객 번호를 확인한다.
2. `다른 앱 위에 표시` 권한이 있으면 전화 화면 위에 고객정보 카드를 표시한다.
3. 사용자가 닫기를 누르거나 통화가 종료될 때까지 유지한다.
4. 전화 받기·거절 등 기본 전화 앱 조작을 가리지 않도록 화면 상단에 배치한다.
5. 오버레이 권한이 없거나 시스템이 차단한 경우에만 상단 알림으로 대체한다.

필수 설정:

1. 연락처 권한
2. 전화 상태 권한
3. 콜태그를 Android 수신정보 앱으로 선택
4. `다른 앱 위에 표시` 허용
5. 알림 권한과 통화 종료 팝업 채널 허용

설정 화면의 `수신 화면 테스트`는 앱을 뒤로 보낸 뒤 2초 후 실제 오버레이 카드를 표시한다.

## 통화 종료 알림 팝업

수신·발신·부재중·거절·미연결 통화가 끝나면 앱 실행 여부와 관계없이 별도 높은 중요도 채널로 상단 팝업을 게시한다.

- 알림 제목에 통화 유형과 고객명 표시
- 최근 메모가 있으면 기본 본문에 첫 줄 표시
- 알림을 누르면 통화 정리 화면으로 이동
- 알림함에서 나중에 정리를 이어갈 수 있음

## 고객 탭

- `고객` 제목 옆 고객 추가
- `목록 / 통계` 상단 탭
- 고객명·전화번호 검색
- 상태 필터와 최근 연락일 필터
- 상태·색상 편집
- 고객 카드에서 상태 변경과 상세 이동 분리

## 고객 상태

기본 고객 상태는 `신규 / 진행 중 / 완료` 세 개다. 기본 상태도 이름과 색상을 수정할 수 있으며, 추가 상태는 사용자가 직접 만들고 수정·삭제할 수 있다. 순서 변경 기능은 제공하지 않는다.

## 할 일과 일정 종류

`다음 연락`이라는 고정 개념 대신 실제 `다음 할 일`을 관리한다.

기본 할 일 종류:

1. 전화하기
2. 미팅
3. 자료 보내기

기본 종류도 이름과 색상을 수정할 수 있고, 사용자 일정 종류를 추가·수정·삭제할 수 있다.

## 통화 자동 처리

- 연결된 발신·수신 통화는 미처리 목록에 계속 쌓지 않는다.
- 부재중·거절·연결되지 않은 발신만 홈의 `확인할 통화`에 표시한다.
- 확인할 통화에는 `다시 전화`와 `할 일 등록` 버튼을 표시한다.
- 전화하기 일정이 있는 고객과 연결되면 가장 가까운 미완료 전화 일정을 자동 완료한다.
- 통화 종료 후 정리 알림은 앱 실행 여부와 관계없이 게시한다.

## 캘린더

- 월 헤더와 달력 전체를 하나의 카드로 구성
- 선택 날짜는 파란 배경과 흰 글자
- 오늘 날짜는 테두리
- 일정 점 대신 일정 제목 표시
- 첫 일정 제목과 추가 일정 개수 표시
- `+ 일정 추가`를 전체 폭 주요 버튼으로 표시
- 일정 색상은 일정 종류 색상을 사용

## 회원 기능

콜태그는 페이지로 콜링크와 같은 회원가입·로그인 서버를 사용한다.

- 로그인·회원가입·이메일 인증
- 비밀번호 재설정
- 개인정보 수집·이용 동의와 이용약관 동의
- 계정정보·로그아웃·2단계 회원탈퇴

## 핵심 원칙

1. 고객이 전화했을 때 이름·상태·최근 메모를 전화 화면 위에서 확인할 수 있어야 한다.
2. 수신 오버레이는 닫기 또는 통화 종료 전까지 유지한다.
3. 오버레이 실패 시에만 알림을 대체 수단으로 사용한다.
4. 클릭 가능한 요소와 읽기 전용 텍스트를 같은 모양으로 만들지 않는다.
5. 고객 상태와 일정 종류는 이름과 색상을 수정할 수 있어야 한다.
6. 통화 종료 정리 알림은 앱 실행 여부와 관계없이 게시돼야 한다.
7. 통화 후 정리는 10초 안에 끝나야 한다.
8. 캘린더에는 일정 점이 아니라 일정 제목을 표시한다.
9. 360dp 화면과 큰 글자 환경에서 좌우·상단 잘림을 허용하지 않는다.
