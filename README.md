# 콜태그 (CallTag)

전화가 오기 전 고객의 핵심 맥락을 확인하고, 통화가 끝난 뒤 고객 상태·메모·일정·문자를 한 번에 처리하며 필요한 시점의 후속문자와 단체문자까지 연결하는 Android 고객관리 앱입니다.

## 가장 먼저 읽을 문서

현재 구현 상태, 완료 패치, 남은 패치, 보류 기능과 작업 규칙은 아래 문서를 기준으로 확인합니다.

- [`docs/DEVELOPMENT_STATUS_AND_ROADMAP_KO.md`](docs/DEVELOPMENT_STATUS_AND_ROADMAP_KO.md) — **최신 개발 현황·남은 패치·인수인계 정본**
- [`docs/CALLTAG_UNIFIED_PRODUCT_PLAN_KO.md`](docs/CALLTAG_UNIFIED_PRODUCT_PLAN_KO.md) — 최종 제품 구조
- [`docs/MESSAGE_AUTOMATION_SPEC_KO.md`](docs/MESSAGE_AUTOMATION_SPEC_KO.md) — 문자 정책 상세
- [`docs/PRODUCT_SPEC_KO.md`](docs/PRODUCT_SPEC_KO.md) — 제품 정의 요약
- [`docs/CALLLINK_INTEGRATION_ARCHITECTURE_KO.md`](docs/CALLLINK_INTEGRATION_ARCHITECTURE_KO.md) — 레거시 문자 모듈 통합 구조
- [`docs/BRAND_WEB_CONSOLIDATION_KO.md`](docs/BRAND_WEB_CONSOLIDATION_KO.md) — 브랜드·웹 운영 기준

기획 문서에 적혀 있다는 이유만으로 기능 구현이 끝난 것으로 간주하지 않습니다. 코드, 버전, 기능 커밋과 빌드 결과가 확인된 항목만 완료입니다.

## 정식 서비스명과 브랜드 기준

- 정식 한글명: **콜태그**
- 정식 영문명: **CallTag**
- 패키지명: `kr.pagero.calltag`
- 대표 도메인: `https://calltag.pagero.kr`
- 공개 웹페이지 소스: `web/index.html`

`콜링크`, `페이지로 콜링크`는 이전 문자 모듈과 소스 이력을 설명할 때만 사용하는 레거시 명칭입니다. 앱 UI, 웹사이트, 스토어 소개, 고객 안내에서는 별도 서비스처럼 노출하지 않습니다.

전화관리와 문자자동화는 서로 다른 앱이 아니라 **콜태그 하나의 기능군**입니다.

## 현재 구현 완료 범위

### 통화와 고객관리

- 통화 전 고객 맥락 표시 기반
- 통화 종료 큰 정리창
- 고객 상태·통화 결과·메모
- 다음 할 일과 일정
- 고객 상세 상단 `전화 / 일정 추가 / 문자`
- 고객별 통화·상태·일정·문자 기록 연결

### 문자 템플릿과 안전 정책

- 여러 템플릿 저장·수정·복제·삭제
- 검색·즐겨찾기·최근 사용
- 수신·발신·부재중·후속 기본 템플릿
- 고객·통화·계정·일정 변수 치환
- 미지원·미치환 변수 발송 차단
- 자동·전체·유형별 발송 제외
- 통화·일정·캠페인·템플릿·본문 기반 중복발송 방지

지원 변수:

```text
{고객명}
{전화번호}
{통화일자}
{통화시간}
{내이름}
{상호명}
{다음일정}
```

### 일정과 후속문자

일정 추가 시 연결 문자를 선택합니다.

```text
없음
지금 안내문자
일정 하루 전
일정 시간
일정 완료 후
```

일정 변경·완료·삭제·다시 열기와 통화에 의한 자동 완료 경로까지 연결 문자의 예약·발송·취소 상태를 동기화합니다.

### 이미지 템플릿

- 이미지 저장·압축·복제·정리
- 수동 문자에서 이미지 추가·교체·제거
- 예약 이미지 문자 알림
- 메시지별 이미지 스냅샷
- `FileProvider` 공유

이미지 문자는 기본 메시지 앱에 번호·본문·이미지를 채워 작성창을 엽니다. 실제 전송 버튼은 사용자가 메시지 앱에서 누르며, 콜태그가 확인할 수 없는 실제 전송 완료를 허위로 표시하지 않습니다.

### 그룹과 단체문자

- 수동 그룹
- 고객 상태·미접촉 기간·미완료 일정·거래 여부 스마트 그룹
- 그룹 실행 시 최신 고객 데이터 재계산
- 캠페인당 최대 500명
- 고객별 변수 개별 치환
- 수신자별 4초 간격 순차 예약
- 중복번호·발송 제외·번호 오류·변수 오류 개별 건너뜀
- 수신자별 예정·진행·완료·실패·건너뜀·취소 상태
- 남은 발송 일괄 취소
- 실패·건너뜀·취소 고객 재시도

현재 자동발송 기본 템플릿과 단체문자는 텍스트 전용입니다.

## 웹사이트 기준

공개 웹사이트는 콜태그 하나만 운영합니다.

- 전화관리·고객관리·일정·문자자동화를 한 제품 흐름으로 설명
- 문자 기능을 별도 콜링크 제품처럼 소개하지 않음
- canonical은 `https://calltag.pagero.kr/`로 고정
- 이전 주소를 유지한다면 대표 도메인으로 영구 리디렉션

현재 Android 로컬 데이터가 웹에 실시간 동기화되는 기능은 구현 완료 상태가 아닙니다. 웹 동기화를 약속하려면 서버 모델·인증·암호화·충돌 해결·삭제 정책을 포함한 별도 패치가 필요합니다.
