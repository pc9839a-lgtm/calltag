# 콜태그 (CallTag)

전화가 오기 전 고객의 핵심 메모를 확인하고, 통화가 끝난 뒤 고객 상태·메모·일정·문자 발송까지 연결하는 Android 고객관리 앱입니다.

## 제품과 구독

콜링크는 별도 앱으로 출시하지 않습니다. 검증된 문자 기능을 콜태그의 문자자동화 모듈로 이전합니다.

| 상품 | 월 구독료 | 제공 범위 |
|---|---:|---|
| 전화관리 | 1,900원 | 고객·통화·상태·메모·일정·통계 |
| 문자자동화 | 990원 | 자동·수동·예약 문자·템플릿·발송내역 |
| 통합 이용 | 2,500원 | 전화관리와 문자자동화 전체 및 통합 처리 |

하나의 APK에서 구매 권한에 따라 기능만 분리합니다.

## v0.20.0 통화 종료 원스톱 처리

통화 종료 알림을 누르면 한 화면에서 다음 작업을 처리합니다.

```text
고객명 확인·수정
→ 고객 상태 선택
→ 통화 결과 선택
→ 통화 메모 입력
→ 다음 할 일과 기한 선택
→ 즉시 문자 확인·수정
→ 1일·3일·7일 뒤 후속 문자 선택
→ 저장만 하기 또는 저장하고 문자 보내기
```

### 저장 동작

- 신규 번호는 `고객 + 전화번호 끝 네 자리` 임시 이름으로 구분
- 고객 상태를 사용자 상태 목록에서 드롭다운으로 선택
- 통화 결과가 견적·재연락이면 `진행 중`을 기본 제안
- 거래 완료·종료이면 완료 상태를 기본 제안
- 신규 고객에게 첫 할 일을 추가하면 `진행 중`으로 자동 변경
- 통화·상태·메모·일정을 같은 고객 이력에 저장
- 저장 후 연락처 표시명의 핵심 메모 동기화 요청

### 문자 동작

- 통화 종류에 따라 연결 통화 또는 부재중 기본 문구 제안
- 문구를 통화 종료 화면에서 직접 수정
- `저장만 하기`는 즉시 문자를 보내지 않음
- `저장하고 문자 보내기`는 선택 회선으로 실제 SMS 발송
- 1일·3일·7일 뒤 후속 문자 별도 예약 가능
- 새 통화·완료 상태·제외번호 전환 시 기존 후속 예약 취소
- 문자 발송 요청·예약·성공·실패 결과를 고객 타임라인에 기록
- 실제 통화기록 ID와 고객 ID를 문자 작업에 연결

## v0.19.0 통합 기반

### 최초 실행

기존의 긴 `전화 고객정보 표시` 필수 화면을 거치지 않습니다.

```text
로그인
→ Android 시스템 권한창 자동 표시
→ 허용된 기능 활성화
→ 홈 진입
```

### 전화관리

- 수신·발신·부재중·거절·미연결 통화 감지
- 연락처 표시명에 `고객명 · 핵심 메모` 반영
- 고객 상태 `신규 / 진행 중 / 완료`
- 고객 메모와 다음 할 일
- 통화 종료 정리 알림
- 캘린더와 일정
- 부재중·미연결 확인 목록

### 문자자동화

- 하단 `문자` 메뉴
- 템플릿으로 시작
- 자유롭게 작성
- 수동 SMS 발송
- 통화 종료 후 자동발송
- 부재중·거절 자동발송
- 수동 1~30일 뒤 예약발송
- 연결 통화 후 N일 뒤 후속문자 자동 예약
- 새 통화 시 이전 후속문자 자동 취소
- 업무시간 제한
- 같은 번호 중복발송 방지
- SIM·eSIM 발송 회선 선택
- 장문 multipart SMS
- 발송 성공·실패·건너뜀·취소 기록
- 재부팅·앱 업데이트 후 예약 복구

자동발송 규칙은 설치 직후 모두 꺼진 상태입니다. 사용자가 템플릿과 규칙을 확인하고 직접 켜야 실행됩니다.

## 전화 수신 메모 표시

전화 앱 위 오버레이를 핵심 기능으로 사용하지 않습니다. 시스템 연락처 표시명을 미리 동기화합니다.

예시:

- `김민수 · 견적서 재발송`
- `고객 4396 · 금요일 오전 다시 전화`

기존 Google·삼성 연락처 이름을 직접 덮어쓰지 않고 콜태그 소유의 로컬 연락처 레이어를 같은 번호와 결합합니다. 기능을 끄면 콜태그 레이어만 제거합니다.

- 이미지 MMS 실제 발송
- 템플릿 라이브러리 저장·복제·삭제
- 회선별 이미지·문구 세트
- 고객 그룹·CSV·단체 순차발송
- 랜딩페이지 자동 첨부
- 원스토어 실제 정기결제
- 서버 구독 검증
- 웹 동기화
- 고객 상세 화면의 직접 문자 작성 버튼
- 발송 성공 이후 관련 `자료 보내기` 일정 자동 완료

## 삼성 리마인더와의 차별점

> 리마인더는 할 일을 알려줍니다. 콜태그는 전화가 끝난 뒤 해야 할 일을 실제로 처리합니다.

콜태그는 전화 이벤트를 기준으로 고객 상태, 통화 메모, 일정, 부재중 자동문자, 통화 후 자동문자와 조건부 후속문자를 하나의 흐름으로 실행합니다.

## 운영 주의

- 기본 전화 앱을 대체하지 않아 에이닷 통화녹음·AI 요약과 공존합니다.
- SMS·통화기록 권한은 스토어 정책 심사 대상입니다.
- 자동문자 규칙과 템플릿은 사용자가 직접 설정해야 합니다.
- 통신사 SMS·MMS 요금은 콜태그 월 구독료에 포함되지 않습니다.
- GitHub Actions 빌드 성공은 컴파일·패키징 성공이며 실제 문자 발송은 Android 실기기에서 최종 확인해야 합니다.
