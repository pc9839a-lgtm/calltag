## 구현 완료 범위

### 전화·고객·일정

- 통화 전 고객 핵심 맥락 표시 기반
- 통화 종료 큰 정리창
- 고객 상태·통화 결과·메모 저장
- 다음 할 일과 일정
- 고객 상세 `전화 / 일정 추가 / 문자`
- 통화·상태·메모·일정·문자 타임라인 연결

### 문자 템플릿과 안전 정책

- 템플릿 저장·수정·복제·삭제·검색·즐겨찾기·최근 사용
- 수신·발신·부재중·후속 기본 템플릿
- 고객·통화·계정·일정 변수 치환
- 미지원·미치환 변수 발송 차단
- 자동·전체·유형별 발송 제외
- 통화·일정·캠페인·템플릿·본문 기반 중복발송 방지

지원 변수:

```text
{고객명}
{전화번호}
{통화일자}
{통화시간}
{내이름}
{상호명}
{다음일정}
```

### 일정 연결 후속문자

```text
없음
지금 안내문자
일정 하루 전
일정 시간
일정 완료 후
```

일정 변경·완료·삭제·다시 열기와 통화에 의한 자동 완료까지 연결 문자 상태를 동기화합니다. 실제 발송 직전에도 일정 상태를 다시 검사합니다.

### 이미지 템플릿

- 앱 전용 이미지 저장·압축·복제·정리
- 수동 문자 이미지 추가·교체·제거
- 예약 이미지 문자 알림
- 메시지별 이미지 스냅샷과 `FileProvider` 공유

이미지 문자는 기본 메시지 앱 작성창을 열고 사용자가 최종 전송합니다. 콜태그가 확인할 수 없는 실제 전송 완료를 허위로 표시하지 않습니다. 자동발송 기본 템플릿과 단체문자는 현재 텍스트 전용입니다.

### 그룹·단체문자 캠페인

- 수동 그룹과 스마트 그룹
- 고객 상태·미접촉 기간·미완료 일정·거래 여부 조건
- 캠페인 실행 직전 최신 고객 데이터 재계산
- 캠페인당 최대 500명
- 수신자별 변수 치환과 4초 간격 순차 예약
- 중복번호·제외·번호 오류·변수 오류 개별 `SKIPPED`
- 수신자별 예정·진행·완료·실패·건너뜀·취소 상태
- 남은 예약 취소와 실패 대상 재시도

### 앱 상태 진단

경로:

```text
계정 및 개인정보
→ 앱 상태 진단
```

권한, 활성 SIM, 선택 회선, 문자 작업, 캠페인 상태 불일치, 연결 작업 누락, 이미지 파일 누락과 실제 단말 E2E 체크리스트를 확인합니다. 복사 가능한 진단 정보에는 고객명·전화번호·문자 본문이 포함되지 않습니다.

### 예약문자 복구 — 11차

앱 시작, 휴대전화 재부팅, 앱 업데이트 후 미완료 문자 작업을 다시 점검합니다.

- 미래 `SCHEDULED` 작업: 원래 예약시각으로 알람 재등록
- 예약시각 경과 30분 이내: 현재 시각부터 5초 간격으로 순차 재등록
- 예약시각 경과 30분 초과: 늦은 오발송 방지를 위해 `SKIPPED`
- 멈춘 `READY`: `SCHEDULED`로 안전 복구 후 재등록
- 불명확한 `SENDING`: 자동 재발송하지 않고 `FAILED`로 전환해 중복 방지
- 완료·실패·건너뜀·취소 작업: 재등록하지 않음
- 변경된 캠페인 수신자와 집계: 문자 작업 기준으로 동기화
- 복구 실행: 직렬화해 앱 시작·부팅 이벤트 중복 처리 방지
- 고객명·전화번호·문자 본문 없이 비식별 복구 결과 기록

실제 제조사별 절전 정책과 재부팅·앱 업데이트 후 발송은 물리 단말에서 추가 검수해야 합니다.
