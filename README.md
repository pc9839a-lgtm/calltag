# 콜태그 (CallTag)

전화가 오면 고객 상태와 최근 메모를 보여주고, 통화가 끝나면 고객 할 일과 캘린더까지 연결하는 페이지로 CRM 서비스입니다.

## 제품 한 문장

> 전화 전에는 고객 상황을 확인하고, 전화 후에는 다음 할 일을 남긴다.

## 페이지로 서비스 관계

- `페이지로 콜링크`: 통화 후 문자·이미지·템플릿·발송 이력
- `페이지로 콜태그`: 고객 상태·메모·통화·할 일·캘린더·통계
- 공통 체계: 페이지로 계정·고객 식별자·통화 식별자·웹 관리

권장 공개 도메인은 `https://calltag.pagero.kr`이다. 향후 통합 포털은 `https://app.pagero.kr`, 공통 API는 `https://api.pagero.kr`을 기준으로 한다.

## 현재 개발 버전

- Android 버전: `v0.14.0`
- 패키지명: `kr.pagero.calltag`
- 최소 Android: API 26
- 수신 고객정보 표시: Android 10 이상 권장
- 개발 브랜치: `agent/calltag-foundation`

## v0.14.0 핵심 변경

### 고객 탭 압축

고객 목록이 첫 화면에서 바로 보이도록 상단 영역을 축소했다.

- 제목 28sp → 24sp
- 전체 폭 고객 추가 버튼 → 제목 옆 `+ 추가` 버튼
- `목록 / 통계` 탭 높이 40dp
- 검색창 높이 44dp
- 상태 필터·기간 필터·상태 편집을 한 줄에 배치
- 상단 좌우 여백 20dp → 16dp
- 고객 카드 간격과 내부 여백 축소
- 검색·필터 아래에서 바로 고객 카드 노출

### 고도화 통계

단순 누적 숫자가 아니라 실제 영업자가 바로 확인해야 할 관리 지표를 제공한다.

- 전체 고객
- 오늘 실제 통화 고객
- 기한 초과 할 일
- 확인이 필요한 부재중·거절·미연결 통화
- 30일 이상 미접촉 고객
- 예정된 할 일이 없는 고객
- 첫 상태이지만 다음 할 일이 없는 고객
- 최근 30일 할 일 완료율
- 최근 7일 일별 통화 추이
- 최근 7일 수신·발신·부재중·거절 통화 수
- 고객 상태별 인원과 비율
- 일정 종류별 남은 할 일 수

### 앱 종료 상태 수신 팝업

기존 전체 화면 알림과 Activity 실행 방식은 Android 백그라운드 제한 때문에 앱이 열려 있을 때만 보일 수 있었다.

v0.14.0부터 `다른 앱 위에 표시` 권한을 사용해 전화 앱 위에 직접 고객정보 오버레이를 표시한다.

표시 내용:

- 고객명과 전화번호
- 현재 고객 상태 색상 태그
- 최근 메모 최대 3줄
- 최근 연락 시각
- 고객 상세 보기 버튼
- 닫기 버튼

동작 기준:

- 콜태그가 화면에 없어도 표시
- 다른 앱을 사용 중이어도 표시
- 전화 화면 위에 표시
- 통화 종료 시 자동 닫힘
- 60초 후 자동 닫힘
- 오버레이 권한이 없으면 메모 포함 알림으로 대체

설정 화면 필수 항목:

1. 연락처 권한
2. 알림 권한
3. 콜태그 수신정보 앱 설정
4. `다른 앱 위에 표시` 허용

`고객정보 팝업 테스트`도 실제 오버레이 방식으로 표시한다.

## 선택 UX 기준

글자 목록에 클릭 기능만 붙인 화면을 사용하지 않는다.

- 고객 선택
- 고객 상태 선택
- 고객 상태 필터
- 최근 연락일 필터
- 일정 종류 선택
- 일정 변경 메뉴
- 통화 후 다음 할 일 종류

주요 실행은 채워진 버튼, 보조 실행은 테두리 버튼으로 구분한다. 고객 카드 전체에는 숨은 클릭 기능을 두지 않는다.

## 고객 상태

기본 고객 상태는 세 개다.

1. 신규
2. 진행 중
3. 완료

기본 세 개도 이름과 색상을 수정할 수 있다. 추가 상태는 사용자가 직접 만들고 수정·삭제할 수 있다. 순서 변경 기능은 제공하지 않는다.

## 할 일과 일정 종류

`다음 연락`이라는 고정 개념 대신 실제 `다음 할 일`을 관리한다.

기본 할 일 종류:

1. 전화하기
2. 미팅
3. 자료 보내기

기본 종류도 이름과 색상을 수정할 수 있다. 사용자 일정 종류를 추가·수정·삭제할 수 있다.

종류별 실행 문구:

- 전화하기: `전화하기`
- 자료 보내기: `자료 보냄`
- 미팅: `미팅 완료`
- 사용자 할 일: 종류명 또는 `처리 완료`

## 통화 자동 처리

- 연결된 발신·수신 통화는 미처리 목록에 계속 쌓지 않는다.
- 부재중·거절·연결되지 않은 발신만 홈의 `확인할 통화`에 표시한다.
- 확인할 통화에는 `다시 전화`와 `할 일 등록` 버튼만 표시한다.
- 전화하기 일정이 있는 고객과 연결된 통화가 감지되면 가장 가까운 미완료 전화 일정을 자동 완료한다.
- 같은 번호의 기존 부재중·거절·연결 안 됨 항목은 연결된 통화 후 자동 처리한다.

## 캘린더

- 월 헤더와 달력 전체를 하나의 카드로 구성
- 선택 날짜는 파란 배경과 흰 글자
- 오늘 날짜는 테두리
- 일정 점 대신 일정 제목 표시
- 첫 일정 제목과 추가 일정 개수 표시
- 선택 날짜 아래에 전체 일정 카드 표시
- `+ 일정 추가`를 전체 폭 주요 버튼으로 표시
- 일정 색상은 일정 종류 색상을 사용

## 회원 기능

콜태그는 페이지로 콜링크와 같은 회원가입·로그인 서버를 사용한다.

- 로그인
- 회원가입
- 이메일 인증
- 비밀번호 재설정
- 개인정보 수집·이용 동의
- 이용약관 동의
- 계정정보
- 로그아웃
- 2단계 회원탈퇴

## 핵심 원칙

1. 고객 목록은 고객 탭을 열자마자 보여야 한다.
2. 통계는 누적 숫자보다 놓친 고객과 처리해야 할 업무를 우선 보여준다.
3. 클릭 가능한 요소와 읽기 전용 텍스트를 같은 모양으로 만들지 않는다.
4. 고객 상태와 일정 종류는 이름과 색상을 수정할 수 있어야 한다.
5. 고객 카드 전체에 숨은 클릭 기능을 넣지 않는다.
6. 연결된 통화는 전화 할 일과 미처리 통화를 자동 처리한다.
7. 수신 고객정보는 앱이 닫혀 있어도 전화 화면 위에서 보여야 한다.
8. 통화 후 정리는 10초 안에 끝나야 한다.
9. 캘린더에는 일정 점이 아니라 일정 제목을 표시한다.
10. 360dp 화면과 큰 글자 환경에서 좌우·상단 잘림을 허용하지 않는다.
