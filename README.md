# 콜태그 (CallTag)

통화가 끝나면 신규 고객, 기존 고객, 상담 상태와 다음 할 일이 자동으로 정리되는 Android 기반 통화 고객관리 앱입니다.

## 제품 한 문장

> 전화가 오면 고객을 알아보고, 통화가 끝나면 고객 상태와 다음 행동을 기록한다.

## 현재 단계

- 제품 기획 및 데이터 구조 문서화
- Android MVP 기능 개발
- 통화 종료 후 고객 분류·상담 결과 저장
- 고객 상세·메모·상태 변경·활동 이력
- 월간 캘린더와 날짜별 일정 관리
- 일정 추가·변경·완료·다시 열기·삭제
- 고객 추가 시 최근 통화 목록에서 번호·이름 불러오기
- 일정 종류·고객 선택창을 명확한 버튼형 UI로 구분
- 홈 빠른 메뉴를 주 행동 1개와 보조 행동 2개로 재배치
- 패키지명: `kr.pagero.calltag`
- 최소 Android: API 26
- 개발 브랜치: `agent/calltag-foundation`
- 최근 빌드: `v0.7.0`

## 핵심 원칙

1. 고객과 상담건을 분리한다.
2. 휴대폰 연락처 등록 여부만으로 기존 고객을 판단하지 않는다.
3. 통화 종료 후 10초 안에 처리가 끝나야 한다.
4. 고객 상태는 등록 후 언제든 변경할 수 있어야 한다.
5. 일정은 월간 캘린더와 고객 상세에서 함께 확인한다.
6. 상태 변경·일정 등록·변경·완료는 활동 기록에 남긴다.
7. 고객 추가의 기본 진입은 최근 통화 목록으로 한다.
8. 전체 UI는 페이지로 콜링크의 실제 화면 구조를 기준으로 사용한다.
9. 클릭 가능한 요소와 읽기 전용 정보를 같은 모양으로 만들지 않는다.
10. 360dp 화면과 큰 글자 환경에서 좌우 잘림을 허용하지 않는다.
