# 콜태그 (CallTag)

통화가 끝나면 신규 고객, 기존 고객, 상담 상태와 다음 할 일이 정리되는 통화 기반 고객관리 서비스입니다.

## 제품 한 문장

> 전화가 오면 고객을 알아보고, 통화가 끝나면 고객 상태와 다음 행동을 기록한다.

## 서비스 구성

- Android 앱: 통화 감지, 통화 직후 고객 분류, 상담 결과와 다음 행동 등록
- 운영 웹서비스: 고객, 상담, 후속업무, 일정·캘린더 관리
- 공개 홍보페이지: 제품 소개, 사용 흐름, 주요 기능, 개인정보 원칙 안내
- 공개 도메인: `https://calltag.pagero.kr`
- Cloudflare Pages 배포 디렉터리: `web`

## 현재 단계

- 제품 기획 및 데이터 구조 문서화
- Android MVP 기반 구축
- 공개 홍보 랜딩페이지 1차 구축
- 운영 웹서비스 UI는 제품 기능 검증 뒤 별도 경로로 분리 예정
- 패키지명: `kr.pagero.calltag`
- 최소 Android: API 26
- Android 개발 브랜치: `agent/calltag-foundation`
- 웹 배포 브랜치: `main`

## 홍보페이지 구성

- 통화 후 고객관리 문제를 설명하는 공감형 히어로
- Android 앱과 웹서비스 화면을 조합한 제품 미리보기
- 통화 종료 → 결과 선택 → 다음 행동 등록의 3단계 사용 흐름
- 상담 이력, 후속업무, 캘린더, 앱·웹 동기화 기능 소개
- 사용 전·후 비교
- 통화 녹음과 자동 수집을 하지 않는 개인정보 원칙
- 주요 사용자군과 FAQ
- 페이지로 도입 문의 연결

```text
프로덕션 분기: main
프레임워크: 없음
빌드 명령: exit 0
빌드 출력 디렉터리: web
사용자 설정 도메인: calltag.pagero.kr
```

## 핵심 원칙

1. 고객과 상담건을 분리한다.
2. 휴대폰 연락처 등록 여부만으로 기존 고객을 판단하지 않는다.
3. 통화 종료 후 10초 안에 처리가 끝나야 한다.
4. 다음 행동이 없는 상담을 자동으로 찾아낸다.
5. 초기 버전은 1인 영업자용으로 제한한다.
6. 웹의 일정은 고객 후속업무와 연결한다.
7. Android 앱과 웹은 같은 고객·상담 데이터를 사용한다.
