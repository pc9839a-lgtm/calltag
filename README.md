## 구현 완료 범위

### 전화·고객·일정

- 통화 전 고객 핵심 맥락 표시 기반
- 통화 종료 큰 정리창
- 고객 상태·통화 결과·메모·다음 할 일
- 고객 상세 `전화 / 일정 추가 / 문자`
- 통화·상태·메모·일정·문자 타임라인 연결

### 문자 템플릿과 안전 정책

- 템플릿 저장·수정·복제·삭제·검색·즐겨찾기·최근 사용
- 수신·발신·부재중·후속 기본 템플릿
- 고객·통화·계정·일정 변수 치환
- 미지원·미치환 변수 발송 차단
- 자동·전체·유형별 발송 제외
- 통화·일정·캠페인·템플릿·본문 기반 중복발송 방지

### 일정 연결 후속문자

```text
없음
지금 안내문자
일정 하루 전
일정 시간
일정 완료 후
```

일정 변경·완료·삭제·다시 열기와 통화에 의한 자동 완료까지 연결 문자 상태를 동기화합니다. 실제 발송 직전에도 일정 상태를 다시 검사합니다.

### 이미지 템플릿

- 앱 전용 이미지 저장·압축·복제·정리
- 수동 문자 이미지 추가·교체·제거
- 예약 이미지 문자 알림
- 메시지별 이미지 스냅샷과 `FileProvider` 공유

이미지 문자는 기본 메시지 앱 작성창을 열고 사용자가 최종 전송합니다. 콜태그가 확인할 수 없는 실제 전송 완료를 허위로 표시하지 않습니다. 자동발송 기본 템플릿과 단체문자는 현재 텍스트 전용입니다.

### 그룹·단체문자 캠페인

- 수동 그룹과 스마트 그룹
- 캠페인당 최대 500명
- 고객별 변수 치환과 수신자별 순차 예약
- 중복번호·제외·번호 오류·변수 오류 개별 처리
- 수신자별 예정·진행·완료·실패·건너뜀·취소 상태
- 남은 발송 취소와 실패 대상 재시도

### 앱 상태 진단과 예약 복구

- 권한·활성 SIM·선택 회선·문자 작업·캠페인 상태 진단
- 비식별 진단 이벤트와 실제 단말 E2E 체크리스트
- 앱 시작·재부팅·앱 업데이트 후 미완료 예약 복구
- 30분 이내 지연 작업 순차 복구
- 30분 초과 지연 작업 자동 발송 차단
- 불명확한 `SENDING` 자동 재발송 금지

### 캠페인 SIM 안전 제어 — 12차

- 캠페인 생성 시 선택한 SIM ID 저장
- 발송 예약 실행 시 캠페인 상태와 활성 SIM 1차 검사
- 실제 `SmsManager` 호출 직전 2차 SIM 검사
- 지정 SIM 제거·비활성화 또는 선택 회선 변경 시 캠페인 자동 일시정지
- 사용자가 캠페인을 직접 일시정지·재개
- 일시정지 시 남은 예약 알람 해제, 문자 작업은 `SCHEDULED`로 보존
- 재개 시 현재 선택한 활성 SIM으로 남은 작업만 다시 시간 배치
- 통신 오류가 3회 연속 발생하면 남은 발송 자동 일시정지
- 성공 발송이 발생하면 연속 실패 횟수 초기화
- 미완료 캠페인이 있으면 새 캠페인 시작 차단
- 동시에 실행되는 구버전 캠페인이 감지되면 후순위 캠페인 일시정지
- 재부팅·앱 업데이트 복구 시 일시정지 캠페인의 알람 재등록 금지
- Campaign DB `v1→v2` 보존 마이그레이션

이미 `SENDING`인 문자 한 건은 일시정지 시점에 통신사로 넘어갔을 수 있어 강제로 되돌리지 않습니다.

## 저장소와 작업 규칙

```text
calltag.db             고객·통화·상태·일정
calltag_messages.db    문자 작업·발송내역
calltag_groups.db      수동·스마트 그룹
calltag_campaigns.db   캠페인·수신자·SIM·일시정지 상태
```

- 기존 데이터를 초기화하거나 파괴하지 않습니다.
- DB 변경 시 보존 마이그레이션을 작성합니다.
- 발송 제외·중복방지·일정 상태·SIM 상태 검사는 실제 발송 직전까지 유지합니다.
- 사용자가 명시적으로 지시하기 전 `main`에 병합하지 않습니다.
- 개발 PR은 Draft 상태를 유지합니다.
- Build 성공과 실기기 검증 성공을 구분합니다.
- 백업·복원과 데이터 내보내기를 합치지 않습니다.
- CSV·XLSX·외부 반출 기능은 현재 구현하지 않습니다.
