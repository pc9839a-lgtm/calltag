# 콜태그 (CallTag)

전화가 오면 시스템 연락처 이름에 반영된 최근 고객 메모를 확인하고, 통화가 끝나면 고객 상태·할 일·캘린더까지 연결하는 페이지로 CRM 서비스입니다.

## 현재 개발 버전

- Android 버전: `v0.18.0`
- 패키지명: `kr.pagero.calltag`
- 최소 Android: API 26
- 필수 설정 화면: Android 10 이상
- 개발 브랜치: `agent/calltag-foundation`

## 전화 수신 메모 표시

v0.18.0의 기본 방식은 전화 앱 위 오버레이가 아니라 **시스템 연락처 표시명 동기화**다.

예시:

- `김민수 · 견적서 재발송`
- `고객 4396 · 금요일 오전 다시 전화`

동작 원칙:

1. 콜태그 고객명과 최근 메모를 짧은 연락처 표시명으로 만든다.
2. Google·삼성 계정의 기존 RawContact를 직접 수정하지 않는다.
3. 콜태그가 소유한 로컬 RawContact를 같은 번호에 추가하고 기존 연락처와 결합한다.
4. 콜태그 이름 행을 우선 표시하도록 설정한다.
5. 기능을 끄면 콜태그가 만든 RawContact만 삭제해 원래 이름으로 복원한다.
6. 메모가 없으면 고객명만 표시한다.
7. `이름없는고객`은 전화번호 끝 네 자리 기준 `고객 4396`처럼 구분한다.

시스템 연락처를 읽는 삼성 전화·에이닷·기타 전화 앱에서 같은 표시명을 사용할 수 있도록 설계했다. 전화 앱 자체 정책에 따라 표시 길이나 형식은 달라질 수 있다.

## 최초 실행 필수 설정

로그인 또는 회원가입 후 아래 항목을 완료해야 CRM 화면으로 들어간다.

1. 연락처 읽기
2. 연락처 이름 수정
3. 전화 상태
4. 통화기록
5. 알림
6. 연락처에 최근 메모 표시 사용
7. 통화 종료 알림 채널 허용

수신정보 앱 역할과 `다른 앱 위에 표시`는 상세 오버레이를 위한 **선택 기능**이다. 연락처 메모 표시는 이 선택 기능과 무관하게 동작한다.

## 자동 동기화

- 앱 시작 시 전체 고객 동기화
- 앱 사용 중 5초 간격 변경 확인
- 화면 전환·앱 백그라운드 이동 시 즉시 동기화
- 고객 메모, 통화 후 메모, 고객명 변경이 반영됨
- 동일 표시명이면 연락처 Provider를 다시 수정하지 않음

## 연락처 원본 보호

콜태그는 기존 계정 연락처의 이름 필드를 직접 덮어쓰지 않는다. 콜태그 전용 로컬 연락처 레이어에 다음 데이터를 저장한다.

- 콜태그 고객 표시명
- 전화번호
- 고객 ID 기반 소유 표식

기능을 끄면 `calltag:` 소유 표식이 붙은 콜태그 연락처만 제거한다.

## 상세 수신 오버레이 · 선택 기능

지원되는 전화 앱에서는 고객명·상태·최근 메모가 포함된 상세 오버레이를 추가로 시험할 수 있다. 전화 앱이 외부 오버레이를 가리거나 제한할 수 있으므로 핵심 표시 방식으로 사용하지 않는다.

## 통화 종료 관리

- 수신·발신·부재중·거절·미연결 통화 감지
- 고객명과 최근 메모가 포함된 통화 종료 알림
- 통화 결과·메모·다음 할 일 저장
- 전화하기 일정 자동 완료
- 부재중·미연결 통화 확인 목록

## 고객 상태

기본 상태는 `신규 / 진행 중 / 완료` 세 개다. 이름과 색상을 수정할 수 있고 사용자 상태를 추가·수정·삭제할 수 있다.

## 할 일과 일정 종류

기본 종류:

1. 전화하기
2. 미팅
3. 자료 보내기

기본 종류도 이름과 색상을 수정할 수 있으며 사용자 종류를 추가·수정·삭제할 수 있다.

## 캘린더

- 일정 점 대신 일정 제목 표시
- 첫 일정과 추가 일정 개수 표시
- 일정 종류별 색상 사용
- 고객을 선택해 일정 등록

## 핵심 원칙

1. 전화 앱의 오버레이 허용 여부에 핵심 가치를 의존하지 않는다.
2. 전화가 울리기 전에 시스템 연락처 이름에 짧은 메모를 미리 반영한다.
3. 기존 연락처 원본은 직접 덮어쓰지 않는다.
4. 기능을 끄면 콜태그가 만든 연락처만 제거한다.
5. 통화 후 정리는 10초 안에 끝낼 수 있어야 한다.
6. 고객 상태와 일정 종류는 사용자가 수정할 수 있어야 한다.
7. 클릭 가능한 요소는 명확한 버튼 형태로 표시한다.
8. 360dp 화면과 큰 글자 환경에서 잘림을 허용하지 않는다.
