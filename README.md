# 콜태그 (CallTag)

전화가 오기 전 고객의 핵심 메모를 확인하고, 통화가 끝난 뒤 고객 상태·메모·일정·문자 발송까지 연결하는 Android 고객관리 앱입니다.

## 최종 제품 방향

기존 `페이지로 콜링크`의 문자 기능은 별도 앱으로 운영하지 않고 콜태그의 **문자자동화 모듈**로 통합합니다.

하나의 앱에서 다음 월 구독 상품을 제공합니다.

| 상품 | 월 구독료 | 제공 범위 |
|---|---:|---|
| 전화관리 | 1,900원 | 고객·통화·상태·메모·일정·통계 |
| 문자자동화 | 990원 | 템플릿·자동·수동·예약 문자·발송내역 |
| 통합 이용 | 2,500원 | 전화관리와 문자자동화 전체 및 통합 처리 |

상세 기획:

- [`docs/CALLTAG_UNIFIED_PRODUCT_PLAN_KO.md`](docs/CALLTAG_UNIFIED_PRODUCT_PLAN_KO.md) — 최종 통합 제품·구독·자동문자·차별화 기획
- [`docs/PRODUCT_SPEC_KO.md`](docs/PRODUCT_SPEC_KO.md) — 현재 제품 정의 요약
- [`docs/CALLLINK_INTEGRATION_ARCHITECTURE_KO.md`](docs/CALLLINK_INTEGRATION_ARCHITECTURE_KO.md) — 기존 콜링크 기능 이전 구조

## 현재 개발 상태

- Android 구현 버전: `v0.18.0`
- 패키지명: `kr.pagero.calltag`
- 최소 Android: API 26
- 개발 브랜치: `agent/calltag-foundation`
- 문자자동화 통합과 모듈 구독은 다음 개발 단계이며 현재 v0.18.0에 전부 구현된 상태가 아님

## 전화 수신 메모 표시

현재 기본 방식은 전화 앱 위 오버레이가 아니라 **시스템 연락처 표시명 동기화**입니다.

예시:

- `김민수 · 견적서 재발송`
- `고객 4396 · 금요일 오전 다시 전화`

동작 원칙:

1. 콜태그 고객명과 최근 메모를 짧은 연락처 표시명으로 만듭니다.
2. Google·삼성 계정의 기존 RawContact를 직접 수정하지 않습니다.
3. 콜태그 소유의 로컬 RawContact를 같은 번호에 추가하고 기존 연락처와 결합합니다.
4. 기능을 끄면 콜태그가 만든 RawContact만 삭제해 원래 이름으로 복원합니다.
5. 메모가 없으면 고객명만 표시합니다.
6. `이름없는고객`은 전화번호 끝 네 자리 기준 `고객 4396`처럼 구분합니다.

시스템 연락처를 읽는 삼성 전화·에이닷·기타 전화 앱에서 같은 표시명을 사용할 수 있도록 설계했습니다. 전화 앱 자체 정책에 따라 표시 길이나 형식은 달라질 수 있습니다.

## 목표 초기 실행 UX

현재의 긴 `전화 고객정보 표시` 설명 화면은 제거할 계획입니다.

```text
앱 실행
→ 로그인
→ Android 시스템 권한창 순차 표시
→ 사용자가 허용
→ 연락처 핵심 메모 표시 활성화
→ 홈 진입
```

앱이 권한을 자동 승인할 수는 없으며 사용자가 Android 시스템창에서 허용해야 합니다. 권한 거절 시 별도 설명 페이지가 아니라 홈 상단의 `권한 허용` 버튼으로 다시 진행합니다.

## 전화관리 목표 기능

- 수신·발신·부재중·거절·미연결 통화 감지
- 고객명과 핵심 메모 표시
- 고객 상태 `신규 / 진행 중 / 완료` 및 사용자 상태 편집
- 통화 결과·메모·다음 할 일 저장
- 신규 고객의 첫 일정 생성 시 `진행 중` 자동 변경
- 고객별 통화·메모·상태·문자·일정 타임라인
- 1일·7일·14일·30일 통계
- 실제 처리 가능한 관리공백 행동 목록

## 문자자동화 목표 기능

기존 `call-auto-sms-android`에서 실기기 검증된 핵심 로직을 모듈 단위로 이전합니다.

- 연결 통화 종료 후 자동 또는 수동 문자
- 부재중·거절 후 자동 문자
- 연결된 발신 통화 종료 후 문자
- 템플릿으로 시작·자유롭게 작성
- SMS·LMS·이미지 MMS
- SIM·eSIM 회선 선택
- 업무시간·중복 발송 방지
- 제외번호·수신거부
- 특정 날짜·시간 예약 발송
- 통화 종료 N분·N시간·N일 뒤 발송
- 예: 견적 통화 3일 뒤 검토 여부 확인 문자
- 예약 목적이 사라졌을 때 자동 취소
- 발송 성공·실패·건너뜀 기록
- 재부팅 후 예약 복구

## 통합 이용 핵심 흐름

```text
통화 종료
→ 통화 결과 선택
→ 고객 상태 변경
→ 메모 저장
→ 다음 할 일 생성
→ 즉시 문자 발송
→ 3일 뒤 후속 문자 예약
→ 고객 타임라인 반영
```

주요 버튼은 `저장만 하기`와 `저장하고 문자 보내기`로 단순화합니다.

## 메인 메뉴 목표

1. 홈
2. 고객
3. 메시지
4. 일정

계정·구독·권한·회선·자동화 설정은 우측 상단 설정에서 관리합니다.

## 삼성 리마인더와의 차별점

콜태그는 단순히 다시 전화할 시간을 알려주는 리마인더가 아닙니다.

> 리마인더는 할 일을 알려줍니다. 콜태그는 전화가 끝난 뒤 해야 할 일을 실제로 처리합니다.

- 통화 이벤트 자동 감지
- 고객 상태와 상담 이력
- 부재중 자동 문자
- 통화 직후 자동 문자
- 3일 뒤 조건부 후속 문자
- 고객 상태 변경 시 예약 자동 취소
- 통화·문자·메모·일정 통합 타임라인
- 누락 원인별 관리공백 행동 목록

## 개발 원칙

1. 기본 전화 앱을 대체하지 않고 에이닷 통화녹음·AI 요약과 공존합니다.
2. 수신 전 정보는 연락처 표시명 동기화를 기본으로 합니다.
3. 통화 후 정리는 10초 안에 끝나야 합니다.
4. 자동 문자는 사용자가 직접 규칙과 템플릿을 설정한 경우에만 실행합니다.
5. 예약 발송은 이유·예정시각·취소 방법을 보여줍니다.
6. 전화·문자·메모·일정은 하나의 고객 타임라인을 사용합니다.
7. 전화관리와 문자자동화는 각각 결제할 수 있어야 합니다.
8. 기존 검증된 문자 발송 로직을 불필요하게 재작성하지 않습니다.
9. 클릭 가능한 요소는 명확한 버튼 형태로 표시합니다.
10. 360dp 화면과 큰 글자 환경에서 잘림을 허용하지 않습니다.

## 스토어 정책 주의

자동 문자와 통화기록 기능은 Android 민감 권한을 사용합니다. Google Play 배포 시 SMS·Call Log Permissions Declaration과 허용 사용 사례 심사가 필요합니다.

1차 배포는 원스토어 또는 직접 APK를 우선 검토하며, Google Play 등록 가능성을 정책 승인 전 확정적으로 표현하지 않습니다.

통신사 SMS·MMS 요금은 콜태그 구독료에 포함되지 않습니다.
