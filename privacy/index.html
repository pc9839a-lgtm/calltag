콜태그 개인정보처리방침

시행일: 2026-09-11

수집·처리하는 정보

콜태그는 회원 식별과 서비스 제공을 위해 이름, 이메일, 휴대폰번호, 브랜드명, 업종 및 로그인 정보를 처리할 수 있습니다. 사용자가 기능을 켠 경우 통화기록, 연락처, 고객명·전화번호, 상담메모, 일정, 문자 발송 관련 정보와 외부 문의 연동 데이터를 처리합니다.

이용 목적

  • 회원가입, 로그인, 계정 관리
  • 통화 후 고객관리, 후속 업무 및 사용자가 설정한 문자 자동화
  • PageRo·Meta Lead Ads·Google Forms·Webhook·Direct API를 통한 문의 수신
  • 고객지원, 장애 대응, 보안 및 부정 사용 방지

보관 및 삭제

회원탈퇴 시 계정과 연결된 서비스 데이터를 삭제합니다. 앱 내 로컬 고객·상담·일정 데이터도 삭제됩니다. 추천 혜택의 반복 악용 방지를 위해 원본 전화번호를 복원할 수 없는 HMAC 식별값만 보안·부정사용 방지 목적으로 유지할 수 있으며, 원본 전화번호·이름·이메일·상담내용은 이 식별값에 포함되지 않습니다. 법령상 보관이 필요한 거래 기록은 해당 법정 기간 동안 보관될 수 있습니다.

삭제 방법: 계정 및 데이터 삭제 안내

권한 사용

READ_CALL_LOG는 사용자가 활성화한 통화 후 업무 자동화에서 실제 통화 완료 내역을 확인하고 중복 없이 고객관리 작업을 생성하기 위해 사용합니다. SEND_SMS는 사용자가 직접 설정한 통화 조건과 문자 자동화 규칙에 따라 메시지를 전송하는 데 사용합니다. FOREGROUND_SERVICE_SPECIAL_USE는 사용자가 켠 통화 감지·후속관리 자동화를 안정적으로 유지하기 위해 사용하며 지속 알림을 표시합니다.

보안

네트워크 통신은 HTTPS를 사용하며 앱 로그인 세션은 Android Keystore 기반 암호화 저장소에 보관합니다. 외부 연동 API Key와 Webhook 비밀값은 발급 직후 한 번만 표시하며 앱 로컬 저장소에 원문으로 저장하지 않습니다.
