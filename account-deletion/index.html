콜태그 계정 및 데이터 삭제

콜태그(kr.pagero.calltag) 계정과 연결된 데이터를 삭제할 수 있습니다.

앱에서 바로 삭제

콜태그 앱에서 더보기 → 계정 → 회원탈퇴 → 계정 삭제를 선택하면 서버 계정 삭제가 확인된 뒤 이 휴대전화의 고객정보·통화 후 상담기록·일정·문자 발송기록과 로그인 세션도 삭제됩니다.

앱에 접근할 수 없는 경우

등록 이메일 주소에서 아래 메일로 “콜태그 계정 삭제 요청”을 보내주세요. 계정 소유 확인 후 삭제를 처리합니다.

계정 삭제 요청 메일 보내기

삭제되는 데이터

  • 이름, 이메일, 휴대폰번호 등 계정 프로필
  • 콜태그 서버 동기화 데이터 및 외부 문의 연동 데이터
  • 결제·이용권 연결 정보 중 서비스 운영용 계정 연결 데이터
  • 기기에 저장된 콜태그 고객·상담·일정·문자 발송 데이터

예외적으로 남는 정보

추천 혜택의 반복 악용을 방지하기 위해 원본 전화번호를 복원할 수 없는 HMAC 식별값만 유지할 수 있습니다. 이 값에는 원본 전화번호, 이름, 이메일 또는 상담 내용이 포함되지 않으며 계정 콘텐츠로 사용하지 않습니다. 법령상 보관 의무가 있는 결제·거래 기록이 있는 경우 해당 법정 기간 동안 별도로 보관될 수 있습니다.

처리 기준

계정 삭제 요청이 완료되면 삭제 대상 데이터는 서비스에서 제거되며, 삭제된 계정은 다시 로그인할 수 없습니다. 문의: support@pagero.kr
