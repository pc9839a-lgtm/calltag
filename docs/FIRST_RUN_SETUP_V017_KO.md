# 콜태그 v0.17.0 최초 실행 필수 설정

## 목적

콜태그의 핵심 기능은 등록 고객의 전화가 올 때 전화 화면 위에 고객명, 상태, 최근 메모를 표시하는 것이다. 권한이 빠진 상태로 홈 화면부터 보여주면 사용자는 기능이 준비됐다고 오해할 수 있으므로 최초 설정을 필수 단계로 처리한다.

## 진입 흐름

1. 앱 실행
2. 로그인 상태 확인
3. 미로그인 사용자는 로그인·회원가입
4. 로그인 완료 후 필수 설정 상태 검사
5. 설정 미완료면 `CallerIdSetupActivity`를 전체 작업의 시작 화면으로 표시
6. 실제 오버레이 확인 완료 후 `MainActivity` 진입

## 필수 항목

- `READ_CONTACTS`: 연락처 및 등록 고객 번호 확인
- `READ_PHONE_STATE`: 통화 상태 감지
- `READ_CALL_LOG`: 종료된 수신·발신·부재중·거절 통화 확인
- `POST_NOTIFICATIONS`: 통화 종료 정리 및 오버레이 실패 대체 알림
- `ROLE_CALL_SCREENING`: Android가 수신 시 콜태그 서비스를 호출하도록 설정
- `SYSTEM_ALERT_WINDOW`: 전화 앱 위 고객정보 카드 표시
- 통화 종료 알림 채널: 높은 중요도로 유지
- 실제 오버레이 테스트 통과

## 설정 순서

설정 버튼은 현재 미완료 항목에 맞춰 다음 행동만 보여준다.

1. `필수 권한 모두 허용`
2. `콜태그를 수신정보 앱으로 선택`
3. `다른 앱 위 표시 허용`
4. `통화 종료 알림 허용`
5. `실제 수신 화면 테스트`
6. `설정 완료 · 앱 시작`

## 실제 오버레이 테스트

- 실제 고객 데이터가 없어도 테스트할 수 있도록 가상 고객을 사용한다.
- 테스트 시작 시 앱을 뒤로 보낸다.
- 1.2초 후 `TYPE_APPLICATION_OVERLAY` 고객정보 카드를 표시한다.
- 테스트 카드에는 고객명, 진행 상태, 전화번호, 최근 메모가 표시된다.
- 사용자가 `정상적으로 보입니다 · 앱 시작`을 눌러야 테스트 완료 상태를 저장한다.
- 확인 버튼을 누르면 통화 감지 서비스를 시작하고 홈 화면으로 이동한다.
- 오버레이가 실제로 생성되지 않으면 완료 버튼도 나타나지 않으므로 설정이 완료되지 않는다.

## 건너뛰기 방지

- 필수 설정 진입 시 뒤로가기 버튼을 숨긴다.
- 시스템 뒤로가기를 누르면 홈으로 우회하지 않고 앱을 백그라운드로 보낸다.
- `AuthGateActivity`와 로그인 성공 흐름은 설정 완료 여부에 따라 홈 또는 필수 설정 화면을 선택한다.
- `CallTagApplication`은 홈, 고객, 일정, 계정 등 CRM 화면이 다시 활성화될 때 설정 상태를 재검사한다.
- 권한, 수신정보 역할, 오버레이 권한 또는 통화 종료 알림이 해제되면 오버레이 테스트 완료 기록을 무효화하고 필수 설정 화면으로 이동한다.

## 저장 상태

`calltag_required_setup` SharedPreferences에 실제 오버레이 테스트 통과 여부를 저장한다. 단순 저장값만으로 완료 처리하지 않고 현재 권한과 역할 상태를 항상 함께 검사한다.

## QA 항목

1. 신규 로그인 후 홈 대신 필수 설정 화면이 표시되는지
2. 여러 런타임 권한을 한 번에 요청하는지
3. 일부 권한 거절 시 홈으로 들어가지 않는지
4. 수신정보 앱 선택 취소 시 설정 화면에 머무르는지
5. 다른 앱 위 표시 허용 후 설정 화면 상태가 갱신되는지
6. 고객이 한 명도 없어도 실제 오버레이 테스트가 가능한지
7. 테스트 카드를 확인하지 않고 앱을 다시 열면 설정 화면이 다시 나타나는지
8. 테스트 확인 후 통화 감지 서비스가 자동 시작되는지
9. 설정 완료 후 권한 하나를 해제하면 CRM 화면에서 다시 설정 화면으로 이동하는지
10. 실제 등록 고객 수신 시 오버레이가 닫기 또는 통화 종료 전까지 유지되는지

## 제한

GitHub Actions에서는 컴파일과 APK 생성만 검증한다. 수신정보 역할 부여, 제조사 전화 앱 위 오버레이 위치, 잠금화면, 듀얼 SIM, 절전 정책은 실제 Android 기기에서 검증해야 한다.
