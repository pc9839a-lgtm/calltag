# 고객 자동분류 기준

## 1. 기본 원칙

콜태그는 `고객 관계 상태`와 `상담건 상태`를 분리한다.

예시:

- 김민수는 지난해 홈페이지를 구매한 `기존 고객`이다.
- 오늘 광고대행을 처음 문의했으므로 현재 상담건은 `신규 문의`다.

한 사람을 신규 또는 기존 중 하나로만 분류하면 이 상황을 표현할 수 없다.

## 2. 고객 관계 상태

### 신규 고객

- 콜태그 고객 DB에 처음 등록됨
- 완료된 거래 이력이 없음

### 상담 고객

- 한 번 이상 상담 이력이 있음
- 완료된 거래 이력은 없음

### 기존 고객

다음 중 하나가 한 번 이상 완료됨:

- 계약 완료
- 결제 완료
- 방문·시술 완료
- 상품 구매
- 서비스 제공 완료

### VIP 고객

사용자가 직접 지정한다. 초기 MVP에서는 자동 점수화를 하지 않는다.

### 휴면 고객

사용자가 정한 기간 동안 상담과 거래가 없는 고객이다. 기본값은 90일이다.

### 수신거부

고객이 연락 거부를 요청한 상태다. 전화·문자 실행 전 경고한다.

### 제외

가족, 지인, 택배, 음식점, 스팸 등 업무 고객목록에 포함하지 않을 번호다.

## 3. 상담건 상태

- 신규 문의
- 상담 중
- 자료 발송 필요
- 견적 발송
- 검토 중
- 재연락 예정
- 계약 예정
- 계약 완료
- 장기 보류
- 실패·종료

## 4. 통화 종료 후 신규번호 처리

고객 DB에 없는 번호와 통화가 끝나면 다음 선택지를 제공한다.

- 신규 문의로 등록
- 기존 고객으로 연결
- 거래처
- 개인·업무 외 전화
- 스팸·제외

번호를 자동으로 고객으로 확정하지 않는다.

## 5. 기존 고객 처리

고객 DB에 번호가 있으면 다음 정보를 표시한다.

- 고객명
- 고객 관계 상태
- 마지막 상담일
- 마지막 상담 요약
- 진행 중인 상담건
- 다음 행동과 날짜
- 수신거부 여부

## 6. 자동 상태 추천

- 최초 등록: `신규 고객`
- 두 번째 상담 또는 견적 발송: `상담 고객` 추천
- 계약·결제·서비스 완료: `기존 고객` 자동 전환
- 기존 고객의 새로운 문의: 고객은 `기존`, 새 상담건은 `신규 문의`
- 기본 휴면기간 초과: `휴면 고객` 추천

자동 추천은 사용자에게 표시하고, 수신거부·제외를 제외한 상태는 수정할 수 있다.

## 7. 번호 정규화

아래 번호는 동일하게 처리한다.

- `010-1234-5678`
- `01012345678`
- `+82 10-1234-5678`

원본 표시번호와 비교용 정규화 번호를 함께 저장한다.

## 8. 오분류 방지

- 휴대폰 연락처에 있다는 이유만으로 기존 고객으로 확정하지 않는다.
- 짧은 통화만으로 자동 고객 등록하지 않는다.
- 사용자가 제외한 번호는 다시 신규 후보로 표시하지 않는다.
- 동일 번호에 여러 고객을 만들지 않는다.
- 고객 병합은 자동 실행하지 않고 사용자 확인을 받는다.
