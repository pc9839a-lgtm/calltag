# 콜태그 계정·개인정보·회원탈퇴 기준

기준 제품: 페이지로 콜링크 Android 앱  
공통 계정: 페이지로 비즈니스 계정  
콜태그 앱 패키지: `kr.pagero.calltag`

## 1. 기본 원칙

콜태그는 별도의 회원체계를 만들지 않는다. 페이지로 콜링크와 같은 회원가입·로그인·이메일 인증·비밀번호 재설정·회원탈퇴 API를 사용한다.

- 콜링크에서 가입한 계정으로 콜태그 로그인 가능
- 콜태그에서 가입한 계정으로 콜링크 로그인 가능
- 앱별 로컬 세션은 각 앱의 Android Keystore로 별도 암호화 저장
- 서버의 회원 식별자와 계정 상태는 공통 사용
- 회원탈퇴는 콜태그만 해지하는 기능이 아니라 공유 페이지로 계정 삭제

## 2. 최초 실행 흐름

1. `AuthGateActivity` 진입
2. 암호화된 로그인 세션 확인
3. 세션이 없으면 로그인·회원가입 화면 이동
4. 세션이 있으면 서버 상태 새로고침
5. 서버 연결 실패 시 기기에 유효 세션이 남아 있으면 오프라인 진입
6. 세션이 손상되었거나 없으면 로그인 화면 이동

## 3. 로그인

입력 항목:

- 이메일
- 비밀번호

동작:

- 페이지로 공통 로그인 API 호출
- 성공 시 세션과 회원 프로필 암호화 저장
- 메인 화면 진입
- 로그인 버튼 연속 클릭과 중복 네트워크 요청 차단

## 4. 회원가입

입력 항목:

- 이름
- 휴대폰번호
- 이메일
- 이메일 인증번호
- 브랜드명
- 업종
- 비밀번호

가입 절차:

1. 필수 개인정보 수집·이용 동의
2. 필수 서비스 이용약관 동의
3. 이메일 인증번호 요청
4. 인증번호와 가입정보 입력
5. 공통 회원가입 API 호출
6. 가입 성공과 동시에 로그인 세션 저장
7. 콜태그 메인 진입

## 5. 개인정보 수집·이용 동의

회원가입 화면에 다음 내용을 숨기지 않고 직접 표시한다.

- 수집 항목: 이름, 휴대폰번호, 이메일, 브랜드명, 업종
- 이용 목적: 회원 식별, 로그인, 서비스 제공 및 고객지원
- 보유 기간: 회원탈퇴 시까지 또는 관계 법령에 따른 기간

필수 체크 항목:

- `[필수] 개인정보 수집·이용에 동의합니다.`
- `[필수] 서비스 이용약관에 동의합니다.`

두 항목 중 하나라도 선택하지 않으면 인증번호 요청과 회원가입을 진행하지 않는다.

상세 문서:

- 개인정보처리방침: `https://call.pagero.kr/privacy/`
- 서비스 이용약관: `https://call.pagero.kr/terms/`

콜태그 전용 웹이 배포되면 같은 정책 원문을 `calltag.pagero.kr`에서도 제공하고 공통 정책 문서로 연결한다.

## 6. 로컬 고객 데이터

콜태그가 휴대전화에 저장하는 고객·상담·일정 데이터는 회원 프로필과 구분한다.

- 고객 이름과 전화번호
- 고객 상태
- 상담 메모와 상담 결과
- 다음 연락과 일정
- 제외번호

로그아웃 시 로컬 고객 데이터는 유지한다. 회원탈퇴 시에는 모두 삭제한다.

서버 동기화가 도입되기 전까지 로컬 CRM 데이터가 자동으로 외부 서버에 전송된다고 표시하지 않는다.

## 7. 계정 화면

`전체 → 계정 및 개인정보`에서 제공한다.

- 회원 프로필 확인
- 회원정보 서버 새로고침
- 개인정보처리방침
- 서비스 이용약관
- 로그아웃
- 회원탈퇴

## 8. 로그아웃

로그아웃 시:

- 통화 감지 서비스 중지
- 통화 감지 설정 끄기
- 앱의 암호화 세션 삭제
- 로그인 화면 이동
- 로컬 고객·상담·일정 데이터 유지

## 9. 회원탈퇴

회원탈퇴는 두 단계로 확인한다.

1차 경고:

- 콜링크와 콜태그가 사용하는 공유 페이지로 계정이 삭제됨
- 콜태그의 고객정보·상담기록·일정이 삭제됨
- 되돌릴 수 없음

2차 확인:

- `공유 계정과 콜태그 앱 데이터를 영구 삭제합니다.`
- 최종 버튼: `계정 삭제`

완료 처리:

1. 서버 회원탈퇴 API 성공 확인
2. 통화 감지 서비스 중지
3. 콜태그 설정 삭제
4. 암호화 로그인 세션 삭제
5. 콜태그 SQLite 데이터베이스 삭제
6. 로그인 화면으로 이동

서버 탈퇴가 실패하면 로컬 데이터부터 임의로 삭제하지 않는다. 사용자가 다시 시도할 수 있도록 오류를 표시한다.

## 10. 보안 기준

- 세션 평문 저장 금지
- Android Keystore AES-GCM 암호화 사용
- 네트워크 요청 HTTPS만 사용
- 로그인·가입·탈퇴 처리 중 버튼 중복 입력 차단
- 회원탈퇴 완료 전 로컬 DB 삭제 금지
- 로그에 비밀번호·인증번호·세션 출력 금지

## 11. QA 기준

- 콜링크 기존 계정으로 콜태그 로그인 가능
- 콜태그 신규 계정으로 콜링크 로그인 가능
- 필수 동의 없이 인증번호 요청 불가
- 필수 동의 없이 회원가입 불가
- 로그인 실패 메시지가 화면에 표시됨
- 앱 재실행 시 유효 세션으로 자동 진입
- 로그아웃 후 통화 감지 서비스가 중지됨
- 회원탈퇴 경고가 두 번 표시됨
- 탈퇴 실패 시 로컬 데이터가 유지됨
- 탈퇴 성공 후 로컬 고객·일정이 삭제됨
- 탈퇴한 공유 계정으로 콜링크와 콜태그 모두 로그인 불가
