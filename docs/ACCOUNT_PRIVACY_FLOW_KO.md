# 콜태그 계정·개인정보·회원탈퇴 기준

기준 제품: 콜태그 Android 앱  
공통 계정: 페이지로 비즈니스 계정  
콜태그 앱 패키지: `kr.pagero.calltag`

## 1. 기본 원칙

콜태그는 페이지로 계정 체계와 연동하여 회원가입·로그인·이메일 인증·비밀번호 재설정·회원탈퇴 API를 사용한다.

- 동일 계정 체계로 콜태그 로그인 가능
- 앱 로컬 세션은 Android Keystore 기반 암호화 저장
- 서버의 회원 식별자와 계정 상태를 공통 사용
- 회원탈퇴는 콜태그 앱 로컬 데이터뿐 아니라 콜태그와 연결된 서버 계정/서비스 데이터를 함께 삭제하는 절차다.

## 2. 최초 실행 흐름

1. `AuthGateActivity` 진입
2. 암호화된 로그인 세션 확인
3. 세션이 없으면 로그인·회원가입 화면 이동
4. 세션이 있으면 서버 상태 새로고침
5. 서버 연결 실패 시 기기에 유효 세션이 남아 있으면 오프라인 진입
6. 세션이 손상되었거나 없으면 로그인 화면 이동

## 3. 로그인

입력 항목:

- 이메일
- 비밀번호

동작:

- 공통 로그인 API 호출
- 성공 시 세션과 회원 프로필 암호화 저장
- 메인 화면 진입
- 로그인 버튼 연속 클릭과 중복 네트워크 요청 차단

## 4. 회원가입

입력 항목:

- 이름
- 휴대폰번호
- 이메일
- 이메일 인증번호
- 브랜드명
- 업종
- 비밀번호

가입 절차:

1. 필수 개인정보 수집·이용 동의
2. 필수 서비스 이용약관 동의
3. 이메일 인증번호 요청
4. 인증번호와 가입정보 입력
5. 공통 회원가입 API 호출
6. 가입 성공과 동시에 로그인 세션 저장
7. 콜태그 메인 진입

## 5. 개인정보 수집·이용 동의

회원가입 화면에 다음 내용을 숨기지 않고 직접 표시한다.

- 수집 항목: 이름, 휴대폰번호, 이메일, 브랜드명, 업종
- 이용 목적: 회원 식별, 로그인, 서비스 제공 및 고객지원
- 보유 기간: 회원탈퇴 시까지 또는 관계 법령에 따른 기간

필수 체크 항목:

- `[필수] 개인정보 수집·이용에 동의합니다.`
- `[필수] 서비스 이용약관에 동의합니다.`

두 항목 중 하나라도 선택하지 않으면 인증번호 요청과 회원가입을 진행하지 않는다.

공개 정책 문서:

- 개인정보처리방침: `https://calltag.pagero.kr/privacy/`
- 서비스 이용약관: `https://calltag.pagero.kr/terms/`
- 계정 및 데이터 삭제: `https://calltag.pagero.kr/account-deletion/`

## 6. 고객·상담·외부문의 데이터

콜태그는 기능에 따라 아래 데이터를 기기 또는 인증된 서버에 저장·동기화할 수 있다.

- 고객 이름과 전화번호
- 고객 상태
- 상담 메모와 상담 결과
- 다음 연락과 일정
- 제외번호
- PageRo 및 외부 문의 연동을 통해 사용자가 연결한 문의 데이터

서버 전송은 사용자가 로그인하고 해당 동기화/외부연동 기능을 사용하는 범위에서 HTTPS 인증 API로 수행한다. FCM은 문의 PII의 정본으로 사용하지 않고, 실제 문의 내용은 인증된 API pull로 가져온다.

로그아웃 시 로컬 고객 데이터는 유지한다. 회원탈퇴 성공 시에는 로컬 데이터도 삭제한다.

## 7. 계정 화면

`더보기 → 계정`에서 제공한다.

- 회원 프로필 확인
- 회원정보 서버 새로고침
- 로그아웃
- 회원탈퇴

개인정보처리방침과 이용약관은 `더보기 → 앱 정보`에서 제공한다.

## 8. 로그아웃

로그아웃 시:

- 통화 감지 서비스 중지
- 통화 감지 설정 끄기
- 앱의 암호화 세션 삭제
- 로그인 화면 이동
- 로컬 고객·상담·일정 데이터 유지

## 9. 회원탈퇴

회원탈퇴는 두 단계로 확인한다.

1차 경고:

- 콜태그 계정 및 연결된 서버 데이터가 삭제됨
- 콜태그의 고객정보·상담기록·일정·문자 발송기록이 삭제됨
- 되돌릴 수 없음

2차 확인:

- `콜태그 계정과 앱 데이터를 영구 삭제합니다.`
- 최종 버튼: `계정 삭제`

완료 처리:

1. 서버 회원탈퇴 API 성공 확인
2. 서버의 콜태그 외부연동, 문의, Push, 이용권/구독 연결 및 프로필 관련 데이터 삭제
3. 계정 프로필 식별정보 제거 및 삭제 상태 전환
4. 통화 감지 서비스 중지
5. 콜태그 설정 삭제
6. 암호화 로그인 세션 삭제
7. 콜태그 SQLite 데이터베이스 삭제
8. 로그인 화면으로 이동

서버 탈퇴가 실패하면 로컬 데이터부터 임의로 삭제하지 않는다. 사용자가 다시 시도할 수 있도록 오류를 표시한다.

### 추천 혜택 악용 방지 예외

추천 혜택의 삭제→재가입 반복 악용을 막기 위해 원본 전화번호를 복원할 수 없는 HMAC 식별값만 tombstone으로 유지할 수 있다.

- 원본 전화번호 저장 금지
- 이름/이메일/상담내용 저장 금지
- 삭제된 account id와 직접 연결하지 않음
- 용도는 추천 혜택 중복 방지로 제한

관계 법령상 보관이 필요한 거래 기록이 있는 경우 해당 법정 기간 동안 별도 보관될 수 있다.

## 10. 보안 기준

- 세션 평문 저장 금지
- Android Keystore AES-GCM 암호화 사용
- 네트워크 요청 HTTPS만 사용
- 로그인·가입·탈퇴 처리 중 버튼 중복 입력 차단
- 회원탈퇴 완료 전 로컬 DB 삭제 금지
- 로그에 비밀번호·인증번호·세션 출력 금지
- Webhook endpoint 및 Direct API raw key의 앱 로컬 영구 저장 금지
- 외부연동 비밀값은 발급 직후 1회 표시 후 Activity 종료/대화상자 닫힘 시 메모리 참조 제거

## 11. Play Data Safety 정합성

현재 구현 기준 Play Console에서는 계정 및 데이터 삭제를 **지원함**으로 선언해야 한다.

- 앱 내 삭제 경로 존재
- 외부 삭제 안내 URL 존재
- 서버 연결 데이터 삭제 구현 존재
- 로컬 데이터 삭제 구현 존재
- 비가역 HMAC 악용 방지 식별값 보존 예외 공개

`데이터 삭제가 지원되지 않습니다`라는 선언은 현재 구현과 맞지 않는다.

## 12. QA 기준

- 필수 동의 없이 인증번호 요청 불가
- 필수 동의 없이 회원가입 불가
- 로그인 실패 메시지가 화면에 표시됨
- 앱 재실행 시 유효 세션으로 자동 진입
- 로그아웃 후 통화 감지 서비스가 중지됨
- 회원탈퇴 경고가 두 번 표시됨
- 탈퇴 실패 시 로컬 데이터가 유지됨
- 탈퇴 성공 후 로컬 고객·일정·문자 기록이 삭제됨
- 탈퇴 성공 후 서버 외부연동/문의/Push/이용권 연결 데이터가 제거됨
- 삭제 계정의 원본 전화번호가 추천 악용방지 ledger에 남지 않음
- 탈퇴한 계정으로 콜태그 로그인 불가
