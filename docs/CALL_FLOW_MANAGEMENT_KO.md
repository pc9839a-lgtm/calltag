# 콜태그 통화 흐름 관리 기준

## 목적

콜태그는 수신 통화만 기록하는 앱이 아니다. 영업자가 놓치기 쉬운 다음 네 가지 통화를 모두 고객 흐름으로 관리한다.

1. 수신 후 연결된 통화
2. 내가 먼저 건 발신 통화
3. 상대 전화를 받지 못한 부재중 통화
4. 사용자가 직접 거절한 통화

## 전화가 올 때 고객정보 표시

홈의 `수신 고객정보 표시 켜기` 버튼에서 다음 설정을 진행한다.

1. 연락처 읽기 권한 허용
2. Android 수신정보 앱 역할에서 콜태그 선택
3. 콜태그 알림 허용

등록된 고객에게 전화가 오면 상단 알림에 다음 정보를 표시한다.

- 고객명
- 현재 사용자 지정 영업 단계
- 최근 통화 메모
- 고객 상세 바로가기

최근 메모 우선순위는 다음과 같다.

1. 가장 최근 통화 기록에 저장된 메모
2. 고객 상세에 저장된 고객 메모
3. 둘 다 없으면 `저장된 최근 메모 없음`

잠금화면 알림은 개인정보 보호를 위해 비공개 알림으로 게시한다. 잠금화면에 실제 메모가 보이는지는 사용자의 Android 알림 개인정보 설정을 따른다.

## 통화 종료 후 분류

### 연결된 수신·발신 통화

- 앱이 화면에 열려 있으면 통화 정리 화면을 연다.
- 앱이 백그라운드면 통화 후 처리 알림을 보낸다.
- 통화 정리 화면 상단에 기존 고객의 영업 단계와 최근 메모를 먼저 표시한다.
- 저장하면 상담 결과·이번 통화 메모·다음 연락 일정이 기록된다.
- 저장 완료와 동시에 홈의 `처리할 통화`에서 제거한다.

### 부재중 통화

- 통화 정리 화면을 강제로 열지 않는다.
- 통화 후 처리 알림과 홈의 `처리할 통화`에 남긴다.
- 기존 고객이면 단계와 최근 메모를 함께 표시한다.

### 거절 통화

- 부재중과 별도 유형으로 기록한다.
- 홈에서 거절한 전화라는 사실을 명확하게 표시한다.
- 전화·정리·완료 중 하나를 선택할 수 있다.

### 발신했지만 연결되지 않은 통화

- 발신 통화이며 통화시간이 0초인 경우 `발신 · 연결 안 됨`으로 표시한다.
- 홈의 미처리 목록에 남겨 재통화 또는 다음 연락 일정을 등록할 수 있게 한다.

## 홈 `처리할 통화`

각 카드는 읽기 전용 텍스트와 실제 버튼을 명확하게 분리한다.

표시 정보:

- 고객명 또는 전화번호
- 통화 유형
- 현재 영업 단계
- 최근 메모 최대 2줄
- 통화 시각과 통화시간

실행 버튼:

- `전화`: 휴대전화 전화 앱 실행
- `정리`: 고객 등록·통화 결과·메모·다음 연락 입력
- `완료`: 별도 기록 없이 미처리 목록에서 제거

카드 전체에는 클릭 기능을 넣지 않는다. 사용자는 실제 버튼을 눌러야만 동작한다.

## 중복 방지

- 시스템 통화기록 ID를 미처리 통화의 기본키로 사용한다.
- 같은 통화기록 ID는 한 번만 저장한다.
- 통화 정리를 저장하거나 제외 처리하면 해당 통화를 완료 처리한다.
- 완료된 미처리 통화 데이터는 30일 후 자동 정리한다.

## 데이터 저장

- 기존 CRM 고객·상담·일정: `calltag.db`
- 미처리 통화 대기열: `calltag_pending.db`
- 로그아웃 시 두 데이터베이스는 유지한다.
- 회원탈퇴 시 앱 데이터베이스 전체를 삭제한다.

## 실기기 QA

1. 등록 고객 수신 시 고객명·단계·최근 메모 표시
2. 연락처에 저장된 고객 수신 시 동일하게 표시
3. 잠금화면에서 메모 노출 수준 확인
4. 수신 연결 후 통화 정리 저장 및 미처리 목록 제거
5. 발신 연결 후 통화 정리 기록
6. 발신 0초 통화를 `연결 안 됨`으로 표시
7. 부재중과 거절 통화를 서로 다르게 표시
8. 동일 통화 중복 생성 방지
9. 정리 저장 후 고객 활동 이력·캘린더 반영
10. 알림을 꺼도 홈 미처리 목록에는 통화가 남는지 확인

## 플랫폼 제약

수신 중 고객정보 표시는 Android 10 이상에서 수신정보 앱 역할을 허용한 경우를 기준으로 한다. 제조사 알림 정책, 방해금지 모드, 잠금화면 개인정보 설정에 따라 상단 알림 방식과 노출 범위가 달라질 수 있다.
