# 콜태그 v0.13.0 UX 안정화 기준

## 목적

v0.13.0은 화면마다 제각각이던 선택 방식과 통화·일정 처리 흐름을 하나의 규칙으로 통일한다.

## 클릭 요소 규칙

- 글자 목록에 클릭 이벤트만 붙인 선택 화면을 사용하지 않는다.
- 고객 선택, 상태 선택, 일정 종류 선택, 일정 변경 메뉴는 모두 배경·간격·화살표가 있는 카드 버튼으로 표시한다.
- 주요 실행은 채워진 버튼, 보조 실행은 테두리 버튼으로 구분한다.
- 읽기 전용 텍스트에는 배경·화살표·눌림 효과를 넣지 않는다.
- 고객 카드 전체에는 숨은 클릭을 넣지 않는다.
- 고객 상세 이동, 상태 변경, 전화, 일정 변경은 각각 이름이 표시된 버튼으로 제공한다.

## 상단 잘림

- Android 15에서 상태바 아래 콘텐츠가 겹치지 않도록 앱 테마의 edge-to-edge 적용을 해제한다.
- 모든 주요 화면은 상태바 아래에서 시작해야 한다.
- 헤더 상단 여백과 좌우 20dp 기준을 유지한다.

## 고객 탭

고객 탭 상단에는 다음 두 하위 탭을 둔다.

1. 고객 목록
2. 통계

### 고객 목록

- 고객명·전화번호 검색
- 고객 상태 필터
- 최근 연락일 필터: 전체 기간, 오늘, 최근 7일, 최근 30일
- 고객 추가 버튼
- 고객 상태·색상 편집 버튼
- 고객 카드에서 상태 변경과 고객 상세를 별도 버튼으로 제공

### 통계

- 전체 고객 수
- 오늘 할 일
- 기한이 지난 할 일
- 상태별 고객 수
- 오늘 연락한 고객 수
- 최근 7일 연락 고객 수
- 예정된 전체 할 일 수

## 고객 상태 색상

- `고객 추가` 주요 버튼은 페이지로 기본 파란색을 사용한다.
- 신규 고객 기본 상태가 같은 파란색이면 구분되지 않으므로 신규 상태 기본색은 보라색으로 변경한다.
- 사용자가 이미 신규 상태 색상을 수정했다면 사용자 색상을 유지한다.

## 캘린더

- 월 이동 헤더와 달력 전체를 하나의 카드로 묶는다.
- 날짜마다 불필요한 개별 카드 테두리를 반복하지 않는다.
- 선택 날짜는 파란 배경과 흰 글자로 표시한다.
- 오늘 날짜는 테두리로 표시한다.
- 일정이 있는 날짜에는 점이 아니라 일정 제목을 표시한다.
- 한 날짜의 첫 번째 일정 제목과 추가 일정 개수를 표시한다.
- 선택 날짜 아래에는 일정 카드와 실제 실행 버튼을 표시한다.
- `+ 일정 추가`는 텍스트 링크가 아니라 전체 폭 주요 버튼으로 표시한다.

## 일정 종류

기본 일정 종류는 다음 세 개다.

1. 전화하기
2. 미팅
3. 자료 보내기

기본 일정 종류도 이름과 색상을 수정할 수 있다. 사용자는 새로운 일정 종류를 추가할 수 있으며, 사용자 일정 종류는 수정·삭제할 수 있다. 순서 변경 기능은 제공하지 않는다.

일정 종류 색상은 다음 위치에 동일하게 적용한다.

- 홈 할 일 카드
- 캘린더 날짜 일정 제목
- 선택 날짜 일정 카드
- 고객 상세 일정 카드
- 일정 종류 선택 카드

## 통화와 할 일 자동 연결

- 연결된 발신·수신 통화는 홈의 미처리 통화 목록에 쌓지 않는다.
- 부재중, 거절, 연결되지 않은 발신만 `확인할 통화`에 표시한다.
- `완료`라는 모호한 버튼은 제거한다.
- 확인할 통화에는 `다시 전화`와 `할 일 등록`만 표시한다.
- 전화하기 일정이 있는 고객과 연결된 통화가 감지되면 가장 가까운 미완료 전화 일정을 자동 완료한다.
- 같은 번호의 기존 부재중·거절·연결 안 됨 항목은 연결된 통화 후 자동 처리한다.
- 자료 보내기, 미팅, 사용자 할 일은 실제 종류에 맞는 완료 버튼 문구를 사용한다.

## 통화 후 정리

- `다음 연락` 문구를 `다음 할 일`로 변경한다.
- 다음 할 일 종류를 카드 버튼으로 선택한다.
- 선택 가능한 일정 종류는 사용자가 편집한 이름과 색상을 그대로 사용한다.
- 할 일이 없는 경우 `없음`을 선택한다.

## 수신 고객정보 팝업

- 수신정보 서비스에서 고객정보 화면 실행을 직접 요청한다.
- 전체 화면 실행이 차단될 경우 메모가 포함된 높은 중요도 알림으로 대체한다.
- 설정 화면에 최근 수신 감지 결과와 시각을 표시한다.
- 다음 원인을 구분해 표시한다.
  - 수신정보 서비스 미호출
  - 전화번호 미전달
  - 미등록 고객
  - 제외번호
  - 전용 화면 실행 차단
  - 알림 차단

## QA

1. 모든 주요 화면의 헤더가 상태바 아래에서 시작하는지 확인
2. 고객 추가 버튼과 신규 상태 색상이 구분되는지 확인
3. 고객 검색과 전화번호 검색이 동작하는지 확인
4. 최근 연락일 필터가 고객 목록에 반영되는지 확인
5. 고객 목록·통계 탭 전환 시 화면이 겹치지 않는지 확인
6. 고객 선택·상태 선택·일정 종류 선택이 모두 카드 버튼인지 확인
7. 캘린더 일정 추가 버튼이 명확한 주요 버튼인지 확인
8. 기본 일정 종류 이름·색상 수정이 기존 일정 카드에 반영되는지 확인
9. 연결된 통화 후 전화하기 일정이 자동 완료되는지 확인
10. 수신 전화 후 설정 화면의 최근 수신 확인 결과가 갱신되는지 확인
