# 콜태그 디자인 시스템

기준 제품: 페이지로 콜링크 Android 앱  
기준 저장소: `pc9839a-lgtm/call-auto-sms-android`

## 1. 기준 원칙

콜태그는 별도의 디자인 언어를 만들지 않는다. 페이지로 콜링크의 실제 화면 구조, 시각 위계, 간격, 카드, 버튼, 하단 내비게이션을 기준으로 사용하고 기능과 문구만 콜태그에 맞게 바꾼다.

색상만 비슷하게 적용하는 것은 동일 디자인으로 인정하지 않는다. 다음 항목까지 콜링크 구조를 따라야 한다.

- 화면 제목과 주요 상태의 배치
- 카드와 목록 행의 구분
- 주요 버튼과 보조 버튼의 강조 차이
- 클릭 가능한 요소의 화살표·상태·눌림 효과
- 하단 내비게이션의 높이와 안전 여백
- 작은 화면에서 잘리지 않는 반응형 배치

## 2. 색상

- Primary: `#4389FF`
- Primary dark: `#276FE8`
- Primary soft: `#16263A`
- Background: `#111214`
- Surface: `#1D1F22`
- Surface soft: `#18191C`
- Border: `#32353A`
- Text primary: `#F5F6F7`
- Text secondary: `#A7ABB2`
- Text muted: `#6E737B`
- Danger: `#FF7D7D`

새 브랜드 색상, 과한 그라데이션, 임의의 밝은 배경을 추가하지 않는다.

## 3. 공통 규격

- 상단 헤더: `66dp`
- 본문 좌우 여백: `20dp`
- 본문 상단 여백: `18~24dp`
- 화면 제목: `28sp Bold`
- 섹션 제목: `18sp Bold`
- 본문: `14~16sp`
- 카드 모서리: `16dp`
- 버튼 모서리: `12dp`
- 카드 내부 여백: `16~20dp`
- 카드 간격: `12dp`
- 기본 터치 높이: 최소 `48dp`
- 설정 목록 행: `58~68dp`
- 하단 내비게이션: 최소 `82dp`
- 하단 아이콘: `28dp`
- 하단 메뉴 글자: `12sp`

## 4. 정보와 행동의 시각적 구분

같은 모양으로 정보 카드와 클릭 메뉴를 만들지 않는다.

### 4.1 주요 행동 CTA

한 화면에서 가장 중요한 행동 한 개에만 사용한다.

- Primary 배경
- 높이 `52~56dp`
- 흰색 Bold 글자
- 화면 전체 폭 또는 명확한 중심 배치
- 예: 고객 추가, 저장

### 4.2 필터

필터는 작은 선택 칩으로 표현한다.

- 선택: Primary 또는 Primary soft
- 비선택: Surface + Border
- 높이 `40~44dp`
- 글자 `14~15sp`
- 버튼처럼 과도하게 크지 않게 한다.
- 탭, 설정 메뉴, CTA와 같은 모양으로 만들지 않는다.

### 4.3 설정·관리 메뉴

설정 메뉴는 카드 여러 개가 아니라 목록 행으로 표현한다.

- 행 전체가 클릭 영역
- 좌측: 제목, 필요 시 짧은 보조값
- 우측: 현재 상태와 chevron
- Ripple 또는 pressed 상태 필수
- 클릭할 수 없는 정보는 chevron을 사용하지 않는다.
- 설명문은 최대 한 줄이며 없어도 이해되면 넣지 않는다.

### 4.4 정보 카드

- 통계, 고객 정보, 빈 상태 등 읽기 전용 정보에 사용한다.
- 클릭이 불가능하면 chevron과 ripple을 넣지 않는다.
- 클릭 가능한 고객 카드는 우측 chevron 또는 명확한 액션을 제공한다.

## 5. 하단 내비게이션

루트 메뉴는 네 칸을 유지한다.

1. 홈
2. 고객
3. 상담
4. 전체

- 선택 메뉴는 Primary 색상
- 비선택 메뉴는 Text muted
- 루트 화면에만 표시
- 고객 상세, 통화 후 처리 등 하위 화면에서는 상단 뒤로가기를 사용
- 콘텐츠가 하단 내비게이션에 가려지지 않도록 본문 하단에 최소 `100dp` 안전 여백 적용

## 6. 짤림 방지 규칙

다음 규칙은 예외 없이 적용한다.

- 가로 그룹에서 고정 폭 합계가 화면 폭을 넘지 않게 한다.
- 화면 너비에 의존하는 버튼은 `0dp + weight` 또는 `wrap_content`를 사용한다.
- 네 개 이상의 선택지는 무조건 한 줄에 억지로 넣지 않는다.
- 고객 필터는 기본적으로 `2×2` 그리드로 표시한다.
- 항목이 늘어날 경우에만 가로 스크롤 칩을 사용한다.
- 가로 스크롤 사용 시 마지막 항목 뒤에 우측 여백 `20dp`를 보장한다.
- 글자 크기 확대, 긴 한국어 문구, 360dp 폭에서 잘림을 확인한다.
- 화면 밖으로 일부만 보이는 버튼은 금지한다.
- 시스템 상태바·내비게이션바 inset을 고려한다.

## 7. 화면별 고정 구조

### 7.1 홈

콜링크 홈의 위계를 그대로 따른다.

1. 작은 상단 라벨
2. 큰 상태 제목 + 스위치
3. 3분할 현황 카드
4. 빠른 메뉴 3개
5. 다음 연락 목록

설명문을 반복하지 않는다. 상태는 제목과 스위치만으로 이해되게 한다.

### 7.2 고객

1. 제목 `고객`
2. 주요 CTA `고객 추가`
3. `2×2` 필터: 전체 / 신규 / 상담 중 / 기존
4. 고객 목록 또는 간결한 빈 상태

금지:

- 필터 네 개를 한 줄에 강제로 배치
- 우측 버튼이 잘린 상태
- 의미 없는 긴 설명문
- 클릭 가능한 고객 카드가 단순 정보 카드처럼 보이는 구조

고객 카드는 고객명, 전화번호, 상태 배지, 최근 연락, chevron 또는 명확한 터치 피드백을 제공한다.

### 7.3 상담

- 상단에는 상담 상태 요약만 표시한다.
- 최근 상담은 목록 행으로 제공하며 고객 상세로 연결한다.
- 안내용 대형 카드와 장문의 개념 설명은 넣지 않는다.

### 7.4 전체

상단의 의미 불명확한 `콜 / 콜태그` 선택 영역은 사용하지 않는다.

구조:

1. 제목 `전체`
2. 섹션 라벨 `관리`
3. 하나의 설정 카드 안에 목록 행 배치

기본 메뉴:

- 통화 후 처리 테스트
- 통화 감지
- 제외번호
- 데이터 및 앱 정보

각 행은 제목, 현재 상태 또는 짧은 보조값, chevron, ripple을 갖는다. 단순한 큰 박스 세 개를 쌓는 방식은 금지한다.

### 7.5 고객 상세

- 상단: 고객명, 상태, 전화번호
- 핵심 액션: 전화 / 다음 연락
- 상태 변경은 명확한 선택 컨트롤
- 메모와 상담이력은 별도 섹션
- 저장 버튼은 한 개만 Primary로 사용

### 7.6 통화 후 처리

통화 종료 후 10초 안에 저장할 수 있어야 한다.

- 고객 구분: 한 줄 선택
- 상담 결과: 2열 선택
- 다음 연락: 한 줄 선택
- 메모: 선택 입력
- 저장: 하단 Primary 버튼

세로로 긴 버튼을 반복하거나 설명문을 삽입하지 않는다.

## 8. 빈 상태

빈 상태는 큰 빈 박스만 보여주지 않는다.

- 짧은 제목 한 줄
- 필요한 경우에만 주요 행동 버튼
- 불필요한 설명문 금지
- 높이는 콘텐츠에 맞추며 화면을 과도하게 차지하지 않는다.

예시:

- `등록된 고객이 없습니다`
- `예정된 다음 연락이 없습니다`

## 9. 클릭 가능성 검수

사용자가 설명 없이 눌러야 할 위치를 알 수 있어야 한다.

다음 중 하나 이상이 없으면 클릭 요소로 인정하지 않는다.

- chevron
- 스위치 또는 선택 상태
- 명확한 버튼 배경
- Ripple 또는 pressed 상태
- 아이콘과 액션 라벨

클릭할 수 있는 카드와 클릭할 수 없는 카드를 같은 모양으로 만들지 않는다.

## 10. QA 기준

패치 완료 전 다음을 모두 확인한다.

- 360dp 폭에서 고객 필터와 메뉴가 잘리지 않는다.
- 시스템 글자 크기 기본 및 크게에서 핵심 버튼이 잘리지 않는다.
- 모든 설정 행은 행 전체를 눌러 동작한다.
- 클릭 가능한 행에는 chevron과 ripple이 있다.
- 클릭 불가능한 정보에는 chevron이 없다.
- 하단 내비게이션이 본문을 가리지 않는다.
- 설명 없이도 고객 추가, 필터, 상세 진입, 설정 진입이 가능하다.
- 콜링크와 비교했을 때 동일한 앱 제품군으로 보인다.

## 11. 금지사항

- 화면 밖으로 잘리는 고정 폭
- 필터 네 개를 한 줄에 강제
- 정보형 카드와 클릭형 카드의 동일 스타일
- 의미가 불명확한 토글·세그먼트
- 설정 메뉴를 대형 카드 여러 개로 표현
- 긴 설명문 반복
- 클릭 영역이 텍스트에만 한정되는 구조
- 그림자, 그라데이션, 장식 위주의 AI형 대시보드

## 12. 현재 우선순위

1. 고객 필터 짤림 제거
2. 전체 탭의 `콜 / 콜태그` 영역 삭제
3. 전체 탭을 목록형 설정 행으로 교체
4. 모든 클릭 요소에 chevron·ripple·상태 표시 적용
5. 고객 빈 상태와 카드 높이 축소
6. 360dp 및 큰 글자 QA
