# 콜태그 디자인 시스템

## 1. 제품 원칙

콜태그는 통화 직후 고객을 정리하고, 다음 할 일과 문자를 연결하는 업무 앱이다. 화면은 설명보다 행동을 먼저 보여주며 사용자가 3초 안에 현재 위치와 다음 행동을 이해해야 한다.

- 파란색 하나와 무채색 중심
- 한 화면 Primary CTA 최대 1개
- 정보 카드와 클릭 메뉴를 다른 모양으로 표현
- 긴 설명문 대신 현재 값과 다음 행동 표시
- 360dp 폭과 큰 글자에서 가로 잘림 금지
- 장식성 그래프·그라데이션·과한 그림자 금지

## 2. 색상

- Primary: `#4389FF`
- Primary dark: `#2F73E8`
- Primary soft: `#17263B`
- Background: `#101113`
- Surface: `#1C1E22`
- Surface soft: `#16181B`
- Border: `#292C31`
- Text primary: `#F4F5F7`
- Text secondary: `#A8ADB5`
- Text muted: `#747A84`
- Danger: `#FF7A7A`

성공·경고 상태를 무분별한 초록·주황·보라색 카드로 표현하지 않는다. 상태는 텍스트와 필요한 최소 색상만 사용한다.

## 3. 공통 규격

- 상단 앱바: `56dp`
- 본문 좌우 여백: `16dp`
- 본문 상단 여백: `10~16dp`
- 화면 제목: `21~22sp Bold`
- 섹션 제목: `16~17sp Bold`
- 본문: `14sp`
- 보조문구: `12~13sp`, 최대 한 줄
- 카드 모서리: `14dp`
- 버튼 모서리: `12dp`
- 카드 내부 여백: `12~16dp`
- 카드 간격: `8~12dp`
- 기본 터치 높이: `48dp` 이상
- 설정 목록 행: `54dp`
- 하단 내비게이션: `76dp`
- 하단 아이콘: `24~29dp`
- 하단 라벨: `11~13sp`

## 4. 행동 위계

### Primary CTA

화면의 가장 중요한 행동 한 개에만 파란색 배경을 사용한다.

예:
- 고객 추가
- 지금 보내기
- 단체문자 만들기
- 저장

### 보조 행동

보조 행동은 무채색 버튼 또는 목록 행으로 표현한다. 같은 화면에 파란색 버튼 여러 개를 나열하지 않는다.

### 설정·관리 메뉴

- 하나의 카드 안에 목록 행 배치
- 행 전체가 클릭 영역
- 우측 chevron 표시
- 화면에 불필요한 설명을 노출하지 않음
- 검색 키워드는 내부에서만 사용 가능

### 정보 카드

읽기 전용 정보만 표시한다. 클릭할 수 없는 카드에는 chevron을 넣지 않는다.

## 5. 하단 내비게이션

왼쪽부터 다음 다섯 메뉴를 유지한다.

1. 고객
2. 캘린더
3. 홈
4. 통계
5. 더보기

- 홈은 중앙 배치
- 홈을 원형 FAB처럼 과도하게 확대하지 않음
- 홈 아이콘과 라벨만 다른 메뉴보다 한 단계 강조
- 선택 메뉴 Primary, 비선택 Text muted
- 하위 화면에서는 하단 메뉴를 숨기고 56dp 상단 앱바 사용

## 6. 화면별 구조

### 홈

1. 통화 감지 상태
2. 오늘 할 일·기한 지남·신규 고객
3. 빠른 메뉴: 고객 추가 / 고객 목록 / 문자
4. 확인할 통화
5. 오늘 할 일

앱 상단의 콜태그 제목과 중복되는 `홈` 제목은 사용하지 않는다.

### 고객

- 상단 compact 탭: 고객 / 문자
- 검색
- 상태 / 기간 필터
- 고객 목록
- 고객 카드 전체 터치로 상세 진입
- 정보 순서: 이름·상태 → 연락처·페이지로 → 메모 → 최근 연락
- 행동: 문자 / 상태 변경
- 직접 등록·전화 유입 배지는 표시하지 않음

### 고객 문자

- Primary CTA: 고객 선택 후 문자
- 관리 목록: 템플릿 / 통화 후 자동문자 / 그룹·단체문자 / 발송 내역
- 독립 빈 번호 문자 작성을 중심 기능으로 두지 않음

### 캘린더

- 월 이동
- 날짜 선택
- 선택 날짜 일정 목록
- 일정 추가
- 날짜 셀에 긴 일정명을 여러 줄 표시하지 않음

### 통계

- 상단 필터: 오늘 / 7일 / 30일 / 전체
- 핵심 지표 4개
- 통화 유형
- 지금 처리할 일
- 장식성 그래프와 긴 상태 설명 금지

### 더보기

- 설정 검색
- 문자
- 고객·일정
- 앱·계정
- 섹션당 카드 하나, 목록 행 54dp

### 고객 상세

- 고객명·전화번호·상태
- 전화 / 일정 / 문자
- 문자 발송 설정 한 줄
- 일정
- 메모와 저장
- 활동 기록
- 빈 상태 높이 64dp 내외

### 문자 작성

- 고객 연결 시 고객명·번호 읽기 전용 표시
- 템플릿 선택 한 줄
- 문자 내용
- 이미지 한 줄
- Primary CTA 지금 보내기
- 후속 예약은 필요할 때만 일수 입력

### 템플릿

- 이름·본문 2줄·이미지 여부·자동문자 사용 여부
- 선택 모드는 카드 전체 터치
- 관리 모드는 수정 / 더보기
- 편집 입력: 이름 / 문자 내용 / 이미지
- 분류와 즐겨찾기 별표를 사용자 화면에 표시하지 않음

### 자동문자

- 자동문자 사용
- 통화 후
- 부재중
- 후속 예약
- 공통 발송 설정
- 행 전체는 템플릿 선택, 스위치는 사용 여부만 제어

### 통화 종료 정리

- 56dp 앱바
- 통화·고객 정보 compact 카드
- 고객명·상태
- 통화 결과 3열 2행
- 메모
- 다음 할 일
- 문자
- 저장 / 저장하고 문자 하단 고정

### 단체문자

- 생성 화면: 이름 → 그룹 → 템플릿 → 내용 → 발송 시점 → 만들기
- 목록: 이름·상태·그룹·시각·핵심 결과
- 상세: 요약 / 발송 제어 / 수신자 상태
- 일시정지·재개·취소·재시도 정책은 화면 최적화와 분리해 유지

### 계정·진단·백업

- 계정 화면은 내 계정 / 앱 및 데이터 / 약관 / 계정 관리로 구분
- 진단은 상태와 복구 행동만 우선 표시
- 진단 원문과 실기기 체크리스트는 접어서 제공
- 백업은 최근 상태 / 백업 / 복원 / 교체 경고 순서

## 7. 짤림 방지

- 긴 이름·전화번호·템플릿명·메모는 한 줄 말줄임
- 가로 그룹은 `0dp + weight` 사용
- 고정 공백으로 좌우 정렬하지 않음
- 네 개 선택지를 한 줄에 배치할 때 12sp와 360dp 폭을 확인
- 키보드 표시 시 Primary CTA와 입력칸이 겹치지 않게 함
- 본문이 하단 내비게이션에 가리지 않게 안전 여백 확보

## 8. 금지사항

- 카드 안에 카드와 버튼을 반복 중첩
- 화면마다 다른 앱바 높이와 제목 크기
- 텍스트만 눌리는 좁은 클릭 영역
- 의미 없는 별표·색 막대·세그먼트
- 설정 메뉴를 대형 카드 여러 개로 나열
- 같은 기능을 서로 다른 이름으로 반복 노출
- 화면 첫 영역에 진단 원문이나 장문 정책 설명 노출
- 기능 검증 없이 빌드 성공만으로 실기기 동작 통과 주장

- 긴 고객명·템플릿명·메모
