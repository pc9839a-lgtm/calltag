# 콜태그 디자인 시스템

기준 제품: 페이지로 콜링크 Android 앱  
기준 저장소: `pc9839a-lgtm/call-auto-sms-android`

## 1. 기본 원칙

콜태그는 별도의 신규 디자인 언어를 만들지 않는다. 페이지로 콜링크의 전체 UI 구조와 시각 규칙을 그대로 사용하고, 화면의 기능과 문구만 콜태그에 맞게 변경한다.

다음 항목을 임의로 변경하지 않는다.

- 다크 배경과 파란색 포인트
- 상단 헤더 높이와 좌우 여백
- 카드 모서리·테두리·내부 여백
- 버튼 높이·모서리·색상
- 하단 내비게이션 높이와 아이콘 크기
- 화면 제목 크기와 본문 위계
- 입력창 스타일

## 2. 색상

페이지로 콜링크의 색상값을 동일하게 사용한다.

- Primary: `#4389FF`
- Primary dark: `#276FE8`
- Primary soft: `#16263A`
- Background: `#111214`
- Surface: `#1D1F22`
- Surface soft: `#18191C`
- Border: `#32353A`
- Text primary: `#F5F6F7`
- Text secondary: `#A7ABB2`
- Text muted: `#6E737B`
- Danger: `#FF7D7D`

## 3. 공통 레이아웃

- 상단 헤더: `66dp`
- 헤더 좌우 여백: `20dp`
- 화면 본문 좌우 여백: `20dp`
- 화면 상단 본문 여백: `24dp`
- 화면 제목: `28sp Bold`
- 헤더 앱명: `22sp Bold`
- 카드 모서리: `16dp`
- 버튼 모서리: `12dp`
- 기본 카드 내부 여백: `16~20dp`
- 카드 간격: `12dp`
- 하단 내비게이션 최소 높이: `82dp`
- 하단 아이콘: `28dp`
- 하단 메뉴 글자: `12sp`

## 4. 화면 구조

콜태그의 루트 메뉴는 페이지로 콜링크와 동일한 네 칸 하단 내비게이션을 사용한다.

1. 오늘
2. 고객
3. 상담
4. 전체

루트 화면에만 하단 내비게이션을 표시한다. 고객 상세, 상담 등록, 통화 후 처리 등 하위 화면에서는 상단 뒤로가기 구조를 사용한다.

## 5. 카드

- 배경: Surface
- 테두리: Border 1dp
- 모서리: 16dp
- 그림자와 과한 그라데이션 사용 금지
- 한 카드에 핵심 정보만 배치
- 카드 안에서 다시 여러 개의 카드가 중첩되지 않도록 한다.

## 6. 버튼

### 주요 버튼

- Primary 색상
- 높이 52dp 전후
- 흰색 굵은 글자
- 한 화면에서 가장 중요한 행동 한 개에만 사용

### 보조 버튼

- Surface 배경
- Border 1dp
- 주요 버튼과 같은 12dp 모서리

## 7. 상태 표시

- 신규: Primary
- 수신거부·오류·기한 지남: Danger
- 상담 중·기존·휴면: Text secondary
- 상태는 작은 배지로 표시하고 카드 전체를 색칠하지 않는다.

## 8. 금지사항

- 흰색 배경의 별도 화면
- 페이지로 콜링크와 다른 브랜드 색상 추가
- 과도한 아이콘·일러스트·그라데이션
- 화면마다 다른 카드 모서리
- 좁은 화면에서 좌우가 잘리는 고정 너비
- 긴 설명문을 카드마다 반복
- AI 대시보드처럼 의미 없는 통계 그래프 배치

## 9. 현재 적용 상태

개발 브랜치 `agent/calltag-foundation`에 다음이 반영되어 있다.

- 동일한 색상 리소스
- 동일한 Theme 구조
- 66dp 상단 헤더
- 20dp 본문 좌우 여백
- 16dp 카드
- 12dp 버튼
- 82dp 하단 내비게이션
- 28dp 아웃라인 아이콘
