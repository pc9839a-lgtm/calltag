# 콜태그 이용권·결제·추천인 앱 구현 명세

- 작성일: 2026-08-04
- 기준 브랜치: `agent/calltag-foundation`
- 서버 정본: `pc9839a-lgtm/inlet/docs/CALLTAG_PAGERO_UNIFIED_BILLING_REFERRAL_ARCHITECTURE_KO.md`
- 상태: 구현 전 제품·화면 명세

## 1. 제품 경계

콜태그와 페이지로는 연결되는 별도 서비스다.

- 콜태그는 전화관리·문자자동화 중심 Android 앱이다.
- 페이지로는 랜딩페이지 제작·문의 수집 웹서비스다.
- 페이지로 문의를 콜태그 고객으로 가져오는 기능은 선택 연동이다.
- 페이지로 단독 사용자는 콜태그 앱을 설치하지 않아도 된다.

콜태그 앱은 페이지로 웹 결제를 대체하지 않는다. 콜태그에서는 콜태그 상품과 통합권을 Google Play Billing으로 판매하고, 페이지로 단독 결제는 페이지로 웹에서 처리한다.

## 2. 앱 판매 상품

모든 가격은 부가세 별도 정책을 기준으로 표시한다.

| 상품 코드 | 상품명 | 월 이용료 | 권한 |
|---|---:|---:|---|
| `call_monthly` | 전화관리 | 1,900원 | 전화관리 기능 |
| `message_monthly` | 문자자동화 | 990원 | 문자자동화 기능 |
| `all_monthly` | 통합권 | 6,000원 | 전화관리·문자자동화·페이지로 |

페이지로 단독 상품 월 3,500원은 앱의 주 결제 상품으로 노출하지 않는다. 페이지로 연결 화면에서는 페이지로 이용권 보유 여부만 보여준다.

## 3. 더보기 메뉴 변경

현재 더보기의 `앱·계정` 영역에 다음 메뉴를 추가한다.

```text
이용권·결제
현재 이용권과 다음 결제일 확인

친구 초대·파트너
추천인 코드와 무료 혜택 확인
```

권장 순서:

1. 계정 및 개인정보
2. 이용권·결제
3. 친구 초대·파트너
4. 페이지로 문의 연결
5. 백업 및 복원

검색 키워드:

- 이용권, 요금제, 결제, 구독, 무료, 체험, 복원
- 추천인, 추천코드, 친구초대, 파트너, 수익, 공유

## 4. 이용권·결제 화면

### 4.1 상단 상태 카드

표시 항목:

- 현재 이용 상태
- 사용 중인 상품
- 무료 이용 또는 유료 이용
- 남은 무료기간
- 다음 결제일
- 결제 경로

상태 예시:

```text
무료 이용 중
통합 기능을 6일 더 사용할 수 있어요.
무료 이용 종료일 2026.08.10
```

```text
통합권 이용 중
다음 결제일 2026.09.04
Google Play에서 결제 중
```

```text
페이지로에서 통합권 이용 중
현재 앱에서 추가 결제할 필요가 없습니다.
```

### 4.2 결제 경로별 처리

#### Google Play 구독

- 앱에서 상품 변경·구독 관리 진입 제공
- 구매 복원 제공
- Play 구매 토큰을 서버로 전송
- 서버 확인 후 이용권 반영

#### 페이지로 웹 구독

- 앱에서 중복 구매 버튼 숨김
- `페이지로에서 결제 중` 표시
- 다음 결제일 표시
- 웹 구독을 앱 내 Play 결제로 즉시 중복 생성하지 않음

#### 무료 이용

- 결제수단 없이 이용
- 종료 후 자동 결제 없음
- 사용자가 직접 상품을 선택했을 때만 결제창 표시

### 4.3 상품 선택 카드

추천 노출 순서:

1. 통합권 월 6,000원 — 추천
2. 전화관리 월 1,900원
3. 문자자동화 월 990원

각 카드에 포함할 정보:

- 상품명
- 월 이용료
- 핵심 포함 기능 3~5개
- 현재 사용 중 여부
- 결제 또는 변경 버튼

페이지로 단독 상품은 하단 안내로만 표시한다.

```text
랜딩페이지만 필요하신가요?
페이지로 웹에서 이용할 수 있습니다.
```

외부 결제 유도 문구와 링크는 Google Play 정책 및 적용 가능한 외부 결제 프로그램을 확인한 뒤 노출한다.

## 5. 무료 이용 정책

- 기본 무료 이용 3일
- 추천인 코드 등록 시 최초 1회 +5일
- 최대 8일
- 무료기간 종료 후 자동 결제 없음
- 추천 보너스는 계정 전체에서 한 번만 지급

앱은 무료기간을 로컬 시간으로 계산하지 않는다. 서버가 내려주는 시작일·종료일·남은 일수를 표시한다.

필수 서버 응답 예시:

```json
{
  "trial": {
    "active": true,
    "scope": "all",
    "baseDays": 3,
    "referralBonusDays": 5,
    "startsAt": "2026-08-04T00:00:00Z",
    "endsAt": "2026-08-12T00:00:00Z",
    "remainingDays": 8
  }
}
```

## 6. 친구 초대·파트너 화면

### 6.1 추천인 코드 카드

표시 항목:

- 내 추천인 코드
- 복사 버튼
- 공유 버튼
- 추천 링크

예시:

```text
내 추천인 코드
DYOON7K
[복사] [공유]
```

복사 완료 문구:

```text
추천인 코드를 복사했습니다.
```

공유 문구 예시:

```text
콜태그 또는 페이지로 가입 시 추천인 코드를 등록하면 무료 이용기간이 5일 더 늘어나요.
추천인 코드: DYOON7K
```

### 6.2 추천인 코드 등록

- 한 계정에서 한 번만 등록
- 본인 코드 입력 금지
- 등록 완료 후 변경 불가
- 첫 유료 결제 이후 등록 제한
- 서버 확인 성공 후 +5일 반영

등록 전 문구:

```text
추천인 코드가 있나요?
등록하면 무료 이용기간이 5일 더 늘어납니다.
```

등록 완료 문구:

```text
추천 혜택이 적용되었습니다.
무료 이용기간이 5일 늘어났습니다.
```

이미 등록된 경우 입력창 대신 다음을 표시한다.

```text
추천인 등록 완료
추천 혜택 +5일 적용
```

### 6.3 파트너 요약

초기 앱에서는 복잡한 정산 기능을 넣지 않고 요약만 제공한다.

- 추천 회원 수
- 유료 이용 중 회원 수
- 이번 달 예상 수익
- 누적 확정 수익
- 파트너센터 열기

정산 계좌·세금정보·명세서는 모바일 웹 파트너센터에서 관리한다.

## 7. 파트너 수익 표시 기준

서버가 계산한 값만 표시하며 앱에서 20%를 직접 계산하지 않는다.

정책:

- 직접 추천 1단계만 인정
- 유료 결제 확정금액의 20%
- 부가세·할인·환불 제외
- 무료기간 수익 없음
- 환불 시 취소 또는 차감
- 추천 회원이 유료 구독을 유지하는 동안 적립

표시 예시:

```text
이번 달 예상 수익 12,000원
확정 전 결제가 포함되어 금액이 달라질 수 있습니다.
```

## 8. 서버 API 연동

### 이용권

- `GET /api/billing/entitlements`
- `GET /api/billing/subscriptions`
- `POST /api/billing/google/verify`
- `POST /api/billing/google/restore`

### 추천인

- `GET /api/referrals/me`
- `POST /api/referrals/apply`
- `GET /api/referrals/summary`

모든 요청은 현재 콜태그 인증 세션과 `ownerId`를 기준으로 한다.

## 9. 앱 저장 데이터

로컬에는 화면 표시를 위한 최소 캐시만 저장한다.

권장 캐시:

- 이용권 상태
- 상품 코드
- 무료기간 종료일
- 다음 결제일
- 결제 경로
- 내 추천인 코드
- 추천인 적용 여부
- 마지막 서버 확인 시각

저장 금지:

- Google Play 구매 토큰 원문 장기 저장
- 웹 PG 결제 식별자 원문
- 파트너 계좌·세금정보
- 다른 회원의 개인정보

최종 권한 판정은 항상 서버 응답을 우선한다.

## 10. 중복결제 차단

앱은 결제창을 열기 전에 서버 이용권을 새로 확인한다.

차단 조건:

- 동일 상품이 웹 PG에서 활성 상태
- 통합권이 다른 채널에서 활성 상태
- 결제 채널 변경 예약 중
- 환불·취소 처리 중으로 서버 확인 필요

차단 문구:

```text
이미 이용 중인 구독이 있습니다.
현재 결제정보를 확인한 뒤 다시 시도해주세요.
```

웹 결제 중인 경우:

```text
페이지로에서 구독 중입니다.
현재 앱에서 다시 결제하지 않아도 됩니다.
```

## 11. Google Play Billing 준비

구현 항목:

- BillingClient 연결
- 상품정보 조회
- 구독 구매 흐름
- 구매 완료 수신
- 서버 구매 검증
- 구매 승인 처리
- 구매 복원
- 연결 해제·재연결
- 보류·유예·취소·만료 상태 표시

앱에서 구매 성공 메시지를 표시하기 전에 서버 검증 완료 여부를 확인한다.

## 12. 권한 게이트

기능별 이용권 판정 예시:

- 전화관리 기능 → `call` 또는 `all`
- 문자자동화 기능 → `message` 또는 `all`
- 페이지로 연결 상태 → `pagero` 또는 `all`

무료 이용 중에는 체험 범위에 맞는 기능을 허용한다.

이용권 만료 후:

- 고객 데이터 삭제 금지
- 기존 데이터 열람 정책 별도 확정
- 신규 자동화·새 작업 실행 제한
- 결제 화면으로 안내

## 13. 사용자 문구 원칙

사용자 화면에서 다음 내부 용어를 표시하지 않는다.

- entitlement
- billing source
- purchase token
- webhook
- subscription ID
- verification failed 원문

사용자용 표현:

- 이용권
- 결제 경로
- 다음 결제일
- 무료 이용
- 구독 확인 중
- 구매 복원
- 추천 혜택

## 14. 구현 순서

### P0

1. 더보기 메뉴 두 개 추가
2. 이용권·추천인 읽기 전용 화면
3. 기본 3일·추천 +5일 상태 표시
4. 추천 코드 복사·공유
5. 추천 코드 등록
6. 웹 결제 이용자의 앱 중복결제 차단

### P1

1. Google Play 상품 조회
2. 구독 구매
3. 서버 검증
4. 구매 복원
5. 상태별 기능 게이트
6. 통합권의 페이지로 권한 반영 확인

### P2

1. 파트너 수익 요약
2. 파트너센터 로그인 연결
3. 결제 채널 변경 안내
4. 만료 전 안내
5. 결제 실패·유예 상태 안내

## 15. 완료 기준

- 더보기에 추천인 코드가 표시되고 복사·공유 가능
- 추천인 등록 후 서버에서 +5일이 한 번만 지급
- 기본 무료 이용이 3일로 표시
- 페이지로 웹 통합권 사용자는 앱에서 다시 결제되지 않음
- Google Play 통합권 구매 후 페이지로 권한도 활성화
- 전화관리·문자자동화 상품을 각각 구매 가능
- 결제 취소·만료 시 서버 상태가 앱에 반영
- 앱 삭제·재설치 후 로그인하면 이용권과 추천 상태 복원
- 이용권 만료가 고객 데이터 삭제로 이어지지 않음
- 사용자 화면에 결제 내부 식별자나 원문 오류가 노출되지 않음

## 16. 비변경 범위

이 문서는 구현 명세이며 다음 작업을 실행하지 않는다.

- 실제 Google Play 상품 생성
- 운영 결제 승인
- 페이지로 웹 PG 선정
- D1 migration 적용
- 파트너 현금 지급
- 세무 처리 확정
- CallTag `main` 병합
