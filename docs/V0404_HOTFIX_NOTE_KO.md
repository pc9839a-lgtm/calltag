# 콜태그 v0.40.4 긴급 복구 기준

- 통화 종료 팝업은 한 번만 연다.
- 통화 종료 팝업은 초기 설정 라우팅 대상에서 제외한다.
- 전화 수신 오버레이는 Telecom 상태 폴링으로 자동 종료하지 않는다.
- 통화 종료가 확인된 시점에 CallMonitorService가 수신 오버레이를 닫는다.
- 수신 고객은 콜태그 DB의 고객명, 상태, 전화번호, 최근 메모를 그대로 표시한다.
- 수신정보 역할 또는 오버레이 권한이 빠지면 다음 앱 진입 때 설정으로 복귀시킨다.
- 실제 삼성 전화 수신 검증 전에는 단말 성공으로 기록하지 않는다.
