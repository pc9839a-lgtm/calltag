# 콜태그 3차 UI·UX 패치 명세

작성일: 2026-07-30  
대상 브랜치: `agent/calltag-foundation`  
기준 APK: `v0.4.0`

## 1. 패치 목적

현재 화면은 다음 문제가 있다.

- 고객 필터 마지막 항목이 화면 밖으로 잘린다.
- 클릭 가능한 메뉴와 읽기 전용 정보가 같은 모양이다.
- 전체 탭의 `콜 / 콜태그` 영역이 무엇을 선택하는지 이해하기 어렵다.
- 설정 메뉴가 눌리는 행이 아니라 큰 정보 카드처럼 보인다.
- 빈 상태 카드가 필요 이상으로 크다.
- 작은 화면과 큰 글자 환경에 대한 대응이 부족하다.

이번 패치는 디자인 장식이 아니라 사용자가 어디를 눌러야 하는지 즉시 알 수 있도록 정보 구조를 바로잡는 작업이다.

## 2. 고객 탭

### 변경 전 문제

- 전체 / 신규 / 상담 중 / 기존 필터를 한 줄에 배치해 우측이 잘린다.
- 필터가 큰 버튼처럼 보여 주요 CTA와 구분되지 않는다.
- 빈 상태가 큰 카드만 차지한다.

### 변경 구조

1. 제목 `고객`
2. Primary 버튼 `고객 추가`
3. 필터 `2×2` 그리드
   - 1행: 전체 / 신규
   - 2행: 상담 중 / 기존
4. 고객 목록
5. 고객이 없으면 간결한 빈 상태

### 필터 규격

- 두 칸 각각 `0dp + weight=1`
- 행 간격 `8dp`
- 열 간격 `8dp`
- 높이 `44dp`
- 선택 필터: Primary soft 배경 + Primary 글자
- 비선택 필터: Surface 배경 + Border + Text secondary
- 필터 영역 전체는 화면 좌우 `20dp` 안에서 끝나야 한다.

### 고객 카드

- 행 전체 클릭
- 고객명 / 상태 배지 / 전화번호 / 최근 연락 표시
- 우측 chevron 추가
- Ripple 적용
- 카드 클릭 시 고객 상세 이동

### 빈 상태

- 문구: `등록된 고객이 없습니다`
- 높이 고정 대형 카드 금지
- 필요 시 `고객 추가` 버튼 한 개만 제공

## 3. 전체 탭

### 삭제

- 상단 `콜 / 콜태그` 선택 영역 전부 삭제

### 변경 구조

1. 제목 `전체`
2. 섹션 라벨 `관리`
3. 하나의 카드 안에 설정 목록 행 배치

### 메뉴 행

1. 통화 후 처리 테스트
2. 통화 감지
3. 제외번호
4. 데이터 및 앱 정보

각 행은 다음 구조를 사용한다.

- 좌측: 제목
- 제목 아래: 필요할 때만 짧은 상태 또는 보조값
- 우측: 상태값 + chevron
- 높이 `58~68dp`
- 행 전체 클릭
- Ripple 적용
- 행 사이 `1dp` 구분선

통화 감지는 현재 상태를 `켜짐` 또는 `꺼짐`으로 표시한다.

## 4. 상담 탭

- 대형 안내 카드 제거
- 신규 / 상담 중 / 기존 현황은 3분할 카드 한 개로 표시
- 다음 연락 건수는 별도 한 줄 카드
- 최근 상담은 목록 행으로 표시
- 최근 상담 행 클릭 시 고객 상세 이동
- 클릭 행에는 chevron과 Ripple 적용

## 5. 홈

- 현재 콜링크형 구조 유지
- 빠른 메뉴 세 개는 아이콘 + 라벨 + 전체 터치 영역 적용
- 다음 연락 카드는 고객 상세로 이동 가능하게 표시
- 다음 연락 카드에는 전화 / 완료 버튼을 명확히 분리
- 카드 전체 클릭과 내부 버튼 클릭이 충돌하지 않게 처리

## 6. 고객 상세

- 상단 뒤로가기와 제목이 잘리지 않게 한다.
- 전화 / 다음 연락은 같은 높이의 두 개 액션으로 표시한다.
- 상태 선택과 메모 입력을 정보 카드와 명확히 구분한다.
- 상담기록 행에는 날짜, 결과, 메모를 표시한다.
- 상담기록이 없으면 작은 빈 상태만 표시한다.

## 7. 통화 후 처리

- 고객 구분은 한 줄 선택
- 상담 결과는 2열
- 다음 연락은 한 줄 선택
- 설명문 제거
- 저장 버튼은 화면 하단에서 명확하게 표시
- 360dp 폭에서도 버튼 문구가 잘리지 않아야 한다.

## 8. 공통 클릭 규칙

클릭 가능한 요소는 반드시 다음을 갖는다.

- Ripple 또는 pressed 상태
- 버튼, chevron, 스위치 중 하나 이상의 시각적 단서
- 최소 터치 높이 `48dp`
- 텍스트만 클릭되는 좁은 영역 금지

클릭 불가능한 정보 카드에는 chevron을 사용하지 않는다.

## 9. 짤림 방지 규칙

- 가로 배치는 `0dp + weight` 우선
- 여러 선택지를 한 줄에 강제하지 않는다.
- 가로 스크롤을 사용할 경우 마지막 항목 뒤 `20dp` 여백을 둔다.
- 하단 내비게이션 위 본문 패딩 최소 `100dp`
- 360dp 폭 기준으로 검수한다.
- 큰 글자 설정에서도 제목과 버튼이 겹치지 않아야 한다.

## 10. 완료 조건

다음 조건을 모두 만족해야 패치 완료로 본다.

- 고객 필터 네 개가 전부 화면 안에 표시된다.
- 전체 탭의 `콜 / 콜태그` 영역이 제거된다.
- 설정 항목이 눌리는 메뉴 행으로 보인다.
- 모든 메뉴 행 전체를 눌러 동작한다.
- 고객 카드를 눌러 상세로 이동한다는 점이 명확하다.
- 정보 카드와 액션 카드가 육안으로 구분된다.
- 360dp 화면에서 좌우 잘림이 없다.
- 하단 메뉴가 본문을 가리지 않는다.
- 페이지로 콜링크와 같은 제품군으로 보인다.

## 11. 작업 순서

1. 고객 필터 `2×2` 교체
2. 전체 탭 상단 선택 영역 삭제
3. 전체 탭 목록 행 컴포넌트 적용
4. 고객 카드 chevron·Ripple 적용
5. 상담 목록 행 적용
6. 빈 상태 축소
7. 360dp·큰 글자 QA
8. APK 빌드 및 실기기 확인
