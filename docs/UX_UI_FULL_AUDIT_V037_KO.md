# 콜태그 0.37.0 전체 UX/UI 재검토

## 목표

화면별로 누적된 개별 스타일을 제거하고, 콜태그 전 화면을 하나의 제품처럼 보이게 통일한다. 기능을 추가하지 않고 사용자가 3초 안에 현재 위치와 다음 행동을 이해하도록 정보량과 행동 수를 줄인다.

## 공통 규격

- 색상: 파란색 1개, 무채색, 위험 빨강만 사용
- 화면 좌우 여백: 16dp
- 상단 앱바: 56dp
- 화면 제목: 22sp Bold
- 섹션 제목: 16~17sp Bold
- 본문: 14sp
- 보조문구: 12~13sp, 최대 1줄
- 카드 모서리: 14dp
- 버튼 모서리: 12dp
- 기본 터치 높이: 48dp 이상
- 카드 간격: 8~12dp
- 한 화면 Primary CTA: 최대 1개
- 보조 행동은 테두리 박스 반복 대신 목록 행 또는 텍스트 버튼 사용
- 클릭 가능한 행은 chevron 또는 명확한 버튼 상태를 표시
- 긴 이름·번호·메모는 한 줄 말줄임 처리
- 360dp 폭과 큰 글자에서 가로 잘림 금지

## 화면별 재검토

### 메인 내비게이션

- 고객 / 캘린더 / 홈 / 통계 / 더보기 5개 유지
- 홈은 원형 FAB가 아니라 아이콘과 라벨만 한 단계 강조
- 모든 아이콘과 라벨 기준선 통일
- 본문 하단 안전 여백을 하단 메뉴 높이에 맞춤

### 홈

- 통화 감지 상태, 오늘 핵심 숫자, 빠른 메뉴, 오늘 할 일 순서
- 앱 제목과 중복되는 화면 제목 제거
- 큰 빈 카드와 반복 설명 제거
- 빠른 메뉴는 고객 추가 / 고객 목록 / 문자만 유지

### 고객

- 고객 / 문자 탭은 compact 세그먼트로 유지
- 검색과 필터 높이 통일
- 카드 전체 터치로 상세 진입
- 고객 카드 정보 순서: 이름·상태 → 연락처·페이지로 → 메모 → 최근 연락
- 카드 행동은 문자 / 상태 변경만 유지
- 직접 등록·전화 유입 배지는 표시하지 않음

### 캘린더

- 월 이동, 날짜 선택, 선택 날짜 일정 목록을 한 화면에 배치
- 날짜 셀 높이와 상태 점 표시 통일
- 긴 설명과 대형 요약 카드 제거
- 일정 행은 시간, 고객, 종류, 상태만 표시

### 통계

- 상단 오늘 / 7일 / 30일 / 전체 필터 유지
- 핵심 지표 4개, 통화 유형, 지금 처리할 일만 표시
- 장식성 그래프와 긴 설명 제거
- 숫자와 라벨 대비 강화

### 더보기

- 검색 + 문자 / 고객·일정 / 앱·계정 섹션
- 섹션당 하나의 카드 안에 54dp 목록 행 배치
- 행 전체 클릭, chevron 표시
- 설명은 검색 키워드로만 사용하고 화면에 노출하지 않음

### 문자 작성

- 고객과 연결된 경우 고객명·번호를 읽기 전용으로 표시
- 번호 입력, 템플릿, 이미지, 예약을 각각 큰 카드로 분리하지 않음
- 템플릿·이미지는 한 줄 선택 행
- 문자 본문과 지금 보내기를 중심 행동으로 구성
- 후속 예약 일수는 예약을 누를 때만 입력
- 선택한 템플릿명과 수정 진입을 명확히 표시

### 템플릿

- 선택 화면은 카드 전체 터치로 즉시 선택
- 관리 화면은 수정 / 더보기만 표시
- 이름, 본문 2줄, 자동문자 사용 중, 이미지 여부만 표시
- 분류 입력과 즐겨찾기 별표는 사용하지 않음
- 이미지 추가·교체·삭제 지원 유지

### 자동문자

- 통화 후 / 부재중 / 후속 예약 3개만 표시
- 행 전체는 템플릿 선택, 우측 스위치는 사용 여부만 제어
- 발송 시간·중복 방지·회선·후속 일수는 공통 발송 설정 하나로 묶음
- 요금제 카드와 반복 설명 제거

### 통화 종료 정리

- 10초 안에 저장 가능한 구성
- 상단 고객·통화 정보 compact 표시
- 결과 6개는 3열 2행
- 상태, 메모, 다음 할 일, 문자 순서
- 저장 / 저장하고 문자 버튼은 하단 고정
- 장문 설명과 중복 카드 제거

### 캠페인·그룹·발송내역

- 목록은 상태, 대상 수, 예약 시각, 결과만 표시
- 생성 CTA 하나만 Primary
- 상세는 요약, 수신자, 일시정지·재개·취소 행동을 분리
- 실패·건너뜀·취소 상태를 같은 색으로 혼동하지 않음
- 발송 안전 정책과 상태 계산은 변경하지 않음

### 계정·진단·백업

- 정보와 행동을 분리
- 위험 행동은 하단 별도 섹션
- 진단 원문을 첫 화면에 길게 노출하지 않음
- 백업·복원은 현재 상태와 두 개 행동만 우선 표시

## 안전 조건

- DB 구조와 기존 데이터는 변경하지 않는다.
- 문자 발송 제외, 중복 방지, SIM, 업무시간, 생명주기 검사를 우회하지 않는다.
- 이미지 문자는 기본 메시지 앱에서 사용자가 최종 전송한다.
- 캠페인 일시정지·재개·취소 정책을 변경하지 않는다.
- main 브랜치에 병합하지 않고 Draft PR을 유지한다.

## 검증 기준

- Java 컴파일과 Debug APK 패키징
- 360dp 폭에서 가로 잘림 확인
- 큰 글자에서 제목·버튼 말줄임 확인
- 키보드 표시 시 하단 CTA 겹침 여부
- 고객명·메모·템플릿명이 긴 경우 확인
- 실제 통화 종료 Activity 직접 실행 여부는 실기기에서 별도 확인
