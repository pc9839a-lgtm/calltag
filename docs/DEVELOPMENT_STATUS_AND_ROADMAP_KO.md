## 1. 현재 핵심 동작

### 전화 수신 메모

- Android Contacts Provider 기반 표시가 주 기능이다.
- 콜태그 전용 RawContact를 생성해 동일 번호의 Google·삼성 연락처와 결합한다.
- 기존 원본 연락처 행은 직접 수정하거나 삭제하지 않는다.
- 표시 형식은 `고객명 · 최근 메모`다.
- 최근 메모는 최대 16자다.
- 이름없는고객은 `고객 + 전화번호 끝 4자리`로 표시한다.
- 앱 사용 중 5초마다 변경 내용을 동기화한다.
- 기능을 끄면 콜태그가 만든 연락처만 삭제한다.

### 통화 종료 정리

- 통화기록 확인 후 전화 앱 종료 전환이 끝난 다음 소형 팝업을 한 번만 실행한다.
- 팝업은 가로 최대 420dp, 세로 최대 560dp다.
- 긴 내용은 팝업 내부에서 스크롤한다.
- 바깥 영역 터치로 닫히지 않는다.
- 사용자가 닫기·저장·제외를 선택하기 전 자동 종료하지 않는다.

### v0.40.7 사용자 화면 정리

- 전화 화면 메모 설정에서 상세 오버레이 테스트와 종료 알림 테스트를 제거했다.
- 수신 진단 시간, 내부 동기화 상태, CallScreening·오버레이 기술 상태를 사용자 화면에서 제거했다.
- 사용자에게 필요한 설정 상태와 켜기·끄기 기능만 남겼다.
- 앱 시작 시 콜태그 로고·서비스 문구·진행 표시가 있는 로딩 화면을 표시한다.
- 로딩 화면은 최소 750ms 유지해 화면이 순간적으로 깜박이지 않게 한다.
- 메인 화면 뒤로가기는 다른 탭에서 홈으로 이동한다.
- 홈에서 다시 뒤로가면 `앱을 닫을까요?` 확인창을 표시한다.
- Android 13 이상은 OnBackInvokedCallback, Android 12 이하는 Window 단계 키 이벤트로 처리한다.

## 2. 사용자 화면 노출 기준

사용자 화면에 노출하지 않는다.

- 테스트 고객
- 테스트 팝업
- 수신 서비스 호출 여부
- 마지막 진단 시각
- RawContact·Provider·CallScreeningService 같은 내부 용어
- 개발용 상태값과 예외 메시지
- 빌드·브랜치·커밋·서버 응답 원문

사용자 화면에는 다음만 표시한다.

- 현재 기능이 켜졌는지
- 사용자가 해야 할 조치
- 실패했을 때 다시 시도할 방법
- 기존 연락처와 데이터가 어떻게 보존되는지

내부 진단은 별도 개발 문서와 로그에서만 관리한다.

## 3. 남은 패치 우선순위

### P0 — 실제 전화 핵심 회귀 검증

1. 삼성 연락처 앱에서 `고객명 · 메모` 생성 확인
2. 에이닷·삼성 전화 실제 수신 화면 표시 확인
3. 저장 번호·미저장 번호·이름없는고객 각각 확인
4. 메모 수정 후 5초 이내 연락처 표시 갱신 확인
5. 같은 번호의 Google·삼성 연락처 중복 결합 여부 확인
6. 기능 해제 후 콜태그 연락처만 제거되는지 확인
7. 통화 종료 소형 팝업이 30초 이상 유지되는지 확인
8. 화면 잠금·홈·다른 앱·에이닷 화면에서 각각 확인

### P1 — 통화 종료 팝업 UX 마감

1. 작은 화면과 큰 글자에서 팝업 잘림 제거
2. 키보드 표시 시 저장 버튼 접근성 확인
3. 통화 결과·메모·다음 할 일의 첫 화면 밀도 축소
4. 저장 중 중복 탭과 Activity 중복 실행 재검증
5. 미응답·거절·발신 실패별 문구와 기본값 정리

### P1 — 전체 사용자 화면 개발 흔적 제거
