## 2. 확정된 제품·운영 기준

### 2.1 단일 제품

- 제품명: `콜태그(CallTag)`
- 대표 도메인: `https://calltag.pagero.kr`
- 앱과 계정은 하나다.
- 전화관리와 문자자동화는 콜태그 내부 기능군이다.
- `콜링크`, `페이지로 콜링크`는 레거시 소스 설명에서만 사용한다.

### 2.2 가격

| 상품 | 월 구독료 | 범위 |
|---|---:|---|
| 전화관리 | 1,900원 | 고객·통화·상태·메모·일정·통계 |
| 문자자동화 | 990원 | 템플릿·자동·수동·예약·그룹·단체문자 |

### 2.3 데이터 정책

- 앱 데이터 **백업·복원은 필수 패치로 구현한다.**
- 백업은 같은 콜태그 앱으로 장애·기기 변경·데이터 손상을 복구하는 기능이다.
- **CSV·XLSX·외부 CRM용 데이터 내보내기는 현재 구현하지 않는다.**
- 데이터 내보내기는 추후 별도 유료 기능으로 기획한다.
- 백업 파일을 고객 목록이나 캠페인 결과표처럼 일반적으로 활용 가능한 파일로 만들지 않는다.

### 11차 — 앱 종료·재부팅·앱 업데이트 후 예약 복구

버전: `0.30.0` / versionCode `32`  
기능 HEAD: `16f8360d0e8bca2ad92919c26c4db0b90eca3e64`

구현:

- 앱 프로세스 시작 시 미완료 문자 작업 점검
- `BOOT_COMPLETED` 후 예약 알람 재등록
- `MY_PACKAGE_REPLACED` 후 예약 알람 재등록
- 부팅 브로드캐스트에서 `goAsync()`로 복구 완료까지 처리
- 완료·실패·건너뜀·취소 작업 재등록 방지
- 동일 문자 작업 ID 기반 PendingIntent 재사용으로 중복 알람 방지
- 앱 시작과 부팅 복구가 겹쳐도 복구 실행을 직렬화
- 변경된 캠페인 상태와 집계 동기화
- 최근 복구 결과를 비식별 진단 이벤트에 저장

예약시각 경과 정책:

| 작업 상태·지연 | 처리 |
|---|---|
| 미래 `SCHEDULED` | 원래 시각으로 재등록 |
| 30분 이내 지난 `SCHEDULED` | 현재부터 5초 간격 순차 재등록 |
| 30분 초과 지난 `SCHEDULED` | 늦은 오발송 방지를 위해 `SKIPPED` |
| 멈춘 `READY` | `SCHEDULED`로 되돌려 위 정책 적용 |
| 불명확한 `SENDING` | 자동 재발송 금지, `FAILED` 전환 |
| `SENT / FAILED / SKIPPED / CANCELLED` | 재등록하지 않음 |

`SENDING`을 자동 재발송하지 않는 이유는 실제 통신사 전송은 완료됐지만 콜백만 유실됐을 가능성이 있어 중복문자 위험이 더 크기 때문이다. 사용자는 발송내역을 확인한 뒤 명시적으로 재시도한다.

가격·권한·개인정보 경고·다운로드 만료·감사 로그를 별도 기획하고 사용자가 다시 승인한 뒤 개발한다.

### 웹 동기화·웹 관리자

현재 Android 로컬 데이터와 마케팅 웹사이트는 별개다. 실시간 동기화 완료로 표현하지 않는다. 서버 모델·인증·암호화·충돌 해결·삭제 정책을 별도 설계해야 한다.

### 이미지 단체문자

현재 이미지 템플릿은 수동 문자와 사용자 확인형 예약 문자에서만 사용한다. 사용자 확인 없는 자동 대량 MMS는 구현하지 않았다.

## 7. 다음 작업자 필수 규칙

1. 작업 전 PR `#1` 최신 HEAD와 대상 파일 SHA를 다시 확인한다.
2. `main`의 웹 변경과 Android 개발 범위를 분리한다.
3. 같은 파일을 병렬 수정하지 않는다.
4. 사용자의 명시적 지시 전 `main`에 병합하지 않는다.
5. 개발 PR은 Draft 상태를 유지한다.
6. Build 성공과 실제 단말 검증을 구분한다.
7. 기존 고객·문자·템플릿·그룹·캠페인 데이터를 초기화하지 않는다.
8. DB 변경 시 보존 마이그레이션을 작성한다.
9. 발송 제외·중복방지·일정 상태 검사는 발송 직전까지 유지한다.
10. 실제 전송 완료를 확인하지 못한 이미지 문자를 `SENT`로 표시하지 않는다.
11. `SENDING` 복구 시 자동 재발송하지 않는다.
12. 30분 초과 지연 예약은 자동 발송하지 않는다.
13. 백업·복원과 데이터 내보내기를 합치지 않는다.
14. CSV·XLSX·외부 반출은 사용자가 다시 승인하기 전 구현하지 않는다.
15. 진단 정보에 고객명·전화번호·문자 본문을 넣지 않는다.
16. 공개 제품명은 콜태그로 통일한다.
