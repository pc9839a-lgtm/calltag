- 고객이 9명 이상이면 검색창 표시

### 뒤로가기

- 고객·캘린더·통계·더보기에서 뒤로가기 → 홈

### 통계

기간 필터:

```text

```

- 직접 선택은 시작일·종료일을 같은 화면에서 확인 후 적용
- 미래 날짜 선택 제한
- 시작일 > 종료일 차단
- 최대 365일
- 7일·30일 또는 직접 선택 2~30일에 일별 추이 차트 표시
- 차트: 일별 통화 + 일별 페이지로 유입

화면 위계:

1. 선택 기간 전체 통화

## 4. 제품·운영 기준

| 상품 | 월 구독료 | 범위 |
|---|---:|---|
| 전화관리 | 1,900원 | 고객·통화·상태·메모·일정·통계 |

| 통합 이용 | 2,500원 | 전화관리와 문자자동화 전체 |

실제 Play Billing 상품과 가격은 출시 전 사용자 최종 지시와 스토어 설정을 기준으로 다시 확정한다. UI에 개발용 요금제 안내를 임의로 노출하지 않는다.

### 데이터 정책

- `.ctbackup` 백업·복원은 같은 콜태그 앱의 복구 기능이다.
- CSV·XLSX·고객 목록·캠페인 결과표·연락처 파일·CRM 이전 형식은 구현하지 않는다.
- 외부 데이터 반출 기능과 앱 복구 기능을 합치지 않는다.
- 로그인 세션·결제 영수증·인증 토큰은 백업 대상이 아니다.

### 진단 개인정보 정책

- 앱·Android 버전
- 권한 상태

- 비식별 작업 ID

포함 금지:

## 7. 절대 지켜야 할 규칙

- `pc9839a-lgtm/calltag`만 작업한다.
- 개발 브랜치는 `agent/calltag-foundation`이다.
- 사용자 지시 전 `main`에 병합하지 않는다.
- PR `#1`은 Draft 상태를 유지한다.
- 기존 데이터를 초기화하지 않는다.
- DB 변경 시 보존 마이그레이션을 작성한다.
- 발송 직전 고객별 허용·발송 제외·중복방지·SIM·캠페인 상태를 확인한다.
- 불명확한 `SENDING` 작업을 자동 재발송하지 않는다.
- 일시정지 캠페인을 자동 재개하지 않는다.
- 누락 작업을 자동 생성하지 않는다.
- 고아 작업을 자동 발송하지 않는다.
- 이미지 문자는 시스템 메시지 앱에서 사용자가 최종 전송한다.
- 백업 복구 중 발송을 새로 시작하지 않는다.
- 페이지로 고객 여부를 고객명이나 전화 여부로 추정하지 않는다.
- 화면에서 안 보이는 호환 View ID를 코드 바인딩 확인 없이 삭제하지 않는다.
- Build 성공을 실제 단말 검증 성공으로 기록하지 않는다.
