# CallTag v0.43.7 통화 종료 실행·회원가입 화면 수정

- versionName: `0.43.7`
- versionCode: `75`

## 통화 종료 화면

- 통화 종료 알림과 백그라운드 실행을 `PostCallEntryActivity`가 먼저 받는다.
- 오래된 PendingIntent와 별도 task affinity를 재사용하지 않는다.
- 통화별 고유 진입 URI를 사용한다.
- 정리 화면이 표시되지 않으면 캐시 삭제 안내 대신 `통화 정리 다시 열기`와 `고객목록 열기`를 제공한다.
- `PostCallActivity`의 별도 task affinity와 `singleTask` 구성을 제거하고 `singleTop`으로 단순화했다.

## 회원가입 화면

필수:

- 이름
- 휴대폰번호
- 이메일
- 이메일 인증번호
- 비밀번호
- 개인정보 수집·이용 동의
- 서비스 이용약관 동의

선택:

- 브랜드명
- 업종

화면을 필수 정보, 선택 정보, 필수 동의로 나누고 입력별 오류 안내, 키보드 다음 이동, 버튼 높이와 여백을 정리했다.

## 서버 계약

브랜드명과 업종은 빈 문자열을 허용하도록 CallTag 가입 API와 함께 맞춰야 한다. 앱은 선택값을 비워서 전송할 수 있다.
