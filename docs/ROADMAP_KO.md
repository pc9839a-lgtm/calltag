## 출시 차단 조건

다음 항목이 검증되지 않으면 Android 정식 배포 또는 웹 공개를 진행하지 않는다.

### Android

- 기존 고객과 신규번호 오인식
- 통화 종료 후 다른 번호 연결
- 제외번호 처리 실패
- 수신거부 고객 재연락 경고 실패
- 고객 삭제 또는 초기화 실패
- 권한 미동의 상태에서 앱 반복 오류
- 작은 화면과 큰 글자에서 버튼 잘림

### 앱·웹 동기화

- 앱과 웹의 고객 상태 불일치
- 일정 완료·삭제 상태 불일치
- 같은 번호의 중복 고객 생성
- 다른 고객에게 통화·문자 이력 연결
- 오프라인 입력 유실
- 회원탈퇴 후 서버 데이터 잔존

### 콜링크 연동

- 문자 발송 결과 누락
- 발송 실패를 성공으로 표시
- 다른 고객 템플릿·번호로 발송
- 사용자 확인 없이 웹에서 문자 자동 발송
