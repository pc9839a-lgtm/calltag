# 콜태그 v0.20.0 통합 개발 상태

기준일: 2026-07-31

## 버전

- versionName: `0.20.0`
- versionCode: `22`
- 패키지명: `kr.pagero.calltag`
- 개발 브랜치: `agent/calltag-foundation`

## 이번 버전 목적

전화관리와 문자자동화가 같은 앱에 존재하는 수준을 넘어, 통화 종료 화면 한 곳에서 고객 상태·메모·일정·즉시문자·후속문자를 함께 처리한다.

## 완료 기능

### 통화 종료 화면

- 기존 `신규 / 기존 / 제외` 3버튼 구조 제거
- 고객명 직접 수정
- 이름 없는 번호는 `고객 4396` 형식으로 자동 구분
- 사용자 고객 상태 목록 드롭다운
- 사용자 일정 종류 드롭다운
- 통화 결과 6종 선택
- 통화 메모 다중행 입력
- 다음 할 일 없음·내일·3일 후·7일 후 선택
- 별도 고객관리 제외 버튼

### 상태 자동화

- 견적 발송·다시 연락·관심 있음 선택 시 진행 상태 제안
- 거래 완료·종료 선택 시 완료 상태 제안
- 신규 고객에게 첫 할 일이 생성되면 진행 상태로 자동 변경
- 상태 변경 이력을 고객 타임라인에 저장

### 즉시 문자

- 연결 통화와 부재중·거절 통화에 맞는 기본 템플릿 자동 선택
- 통화 종료 화면에서 발송 전 문구 수정
- `저장만 하기`와 `저장하고 문자 보내기` 분리
- 저장하고 보내기 선택 시 `SmsManager`로 실제 발송 요청
- 선택된 SIM·eSIM 회선 사용
- 실제 통화기록 ID와 고객 ID를 문자 작업에 연결

### 후속 문자

- 예약 안 함·1일·3일·7일 뒤 선택
- 후속 템플릿으로 예약 작업 생성
- 같은 번호의 이전 후속 예약을 취소하고 새 예약으로 교체
- 예약 이유와 고객 연결 유지

### 고객 타임라인

다음 이벤트를 `interactions`에 연결한다.

- 통화 결과와 메모
- 고객 상태 변경
- 다음 할 일 생성
- 즉시 문자 발송 요청
- 후속 문자 예약
- SMS 최종 성공
- SMS 최종 실패와 오류 사유

### 통화 연결

`CallMonitorService`가 `PostCallActivity`에 실제 `CallRecord.id`를 전달한다. 부재중 보관 ID와 실제 통화기록 ID를 구분해 문자 작업이 정확한 통화에 연결되도록 했다.

## 미포함 범위

- 이미지 MMS
- 사용자 템플릿 라이브러리
- 고객 상세 화면 직접 문자 작성
- 회선별 서로 다른 템플릿 세트
- 단체문자·CSV
- 원스토어 정기결제
- 서버 구독 검증
- 웹 동기화

## 실기기 검수

1. 기존 v0.19.0 위에 v0.20.0 설치
2. 로그인·고객·문자 설정 데이터 유지 확인
3. 등록 고객과 실제 통화 후 통화 종료 알림 선택
4. 현재 상태가 드롭다운에 표시되는지 확인
5. 통화 결과·메모·다음 할 일 저장
6. 신규 고객 첫 일정 생성 시 진행 중 변경 확인
7. 저장만 하기는 SMS를 발송하지 않는지 확인
8. 저장하고 문자 보내기는 선택 회선에서 실제 발송되는지 확인
9. 고객 타임라인에 문자 요청과 성공 결과가 표시되는지 확인
10. 3일 뒤 후속문자 생성 후 문자 메뉴의 예약 내역 확인
11. 같은 고객과 다시 통화했을 때 이전 후속문자 취소 확인
12. 문자 권한이 없을 때 고객 저장이 손실되지 않는지 확인
13. 부재중·거절 통화에서 부재중 기본 문구가 제안되는지 확인
14. 360dp 화면과 키보드 표시 상태에서 저장 버튼까지 스크롤 가능한지 확인
