## 당시 버전 목적

전화관리와 문자자동화가 같은 앱에 존재하는 수준을 넘어, 통화 종료 화면 한 곳에서 고객 상태·메모·일정·즉시문자·후속문자를 함께 처리하는 초기 통합 단계였다.

## 당시 완료 기능

### 통화 종료 화면

- 기존 `신규 / 기존 / 제외` 3버튼 구조 제거
- 고객명 직접 수정
- 이름 없는 번호는 `고객 4396` 형식으로 자동 구분
- 사용자 고객 상태 목록 드롭다운
- 사용자 일정 종류 드롭다운
- 통화 결과 6종 선택
- 통화 메모 다중행 입력
- 다음 할 일 없음·내일·3일 후·7일 후 선택
- 별도 고객관리 제외 버튼

### 상태 자동화

- 견적 발송·다시 연락·관심 있음 선택 시 진행 상태 제안
- 거래 완료·종료 선택 시 완료 상태 제안
- 신규 고객에게 첫 할 일이 생성되면 진행 상태로 자동 변경
- 상태 변경 이력을 고객 타임라인에 저장

### 즉시 문자

- 연결 통화와 부재중·거절 통화에 맞는 기본 템플릿 자동 선택
- 통화 종료 화면에서 발송 전 문구 수정
- `저장만 하기`와 `저장하고 문자 보내기` 분리
- 저장하고 보내기 선택 시 `SmsManager`로 실제 발송 요청
- 선택된 SIM·eSIM 회선 사용
- 실제 통화기록 ID와 고객 ID를 문자 작업에 연결
- 같은 통화 중복발송 1차 차단
- 실패 상태인 자동문자 수동 재시도

### 후속문자

- 예약 안 함·1일·3일·7일 뒤 선택
- 후속 템플릿으로 예약 작업 생성
- 같은 번호의 이전 후속 예약을 취소하고 새 예약으로 교체
- 예약 이유와 고객 연결 유지

### 고객 타임라인

- 통화 결과와 메모
- 고객 상태 변경
- 다음 할 일 생성
- 즉시 문자 발송 요청
- 후속문자 예약
- SMS 최종 성공
- SMS 최종 실패와 오류 사유

## 당시 미포함 범위

아래 항목은 v0.20 당시 미포함이었으나 일부는 이후 v0.21~v0.28 패치에서 구현됐다.

- 이미지 MMS
- 사용자 템플릿 라이브러리
- 고객 상세 화면 직접 문자 작성
- 그룹과 단체문자
- 문자 발송 제외
- 공통 중복발송 방지
- 일정과 후속문자 생명주기 연결

현재도 남은 항목:

- 실제 운영 결제·구독 검증
- 앱 종료·재부팅 후 예약 복구 실기기 검증
- 데이터 백업·복원
- 웹 데이터 동기화
- 출시 전 전체 QA

데이터 내보내기 CSV·XLSX는 현재 남은 기본 패치가 아니다. 추후 별도 유료 기능으로 보류한다.

## 당시 실기기 검수 항목

1. 기존 버전 위에 설치했을 때 로그인·고객·문자 설정 데이터 유지
2. 등록 고객과 실제 통화 후 통화 종료 정리창 진입
3. 상태·메모·다음 할 일 저장
4. 선택 회선에서 실제 SMS 발송
5. 고객 타임라인에 문자 요청과 결과 표시
6. 후속문자 예약 내역 확인
7. 같은 고객과 다시 통화했을 때 이전 예약 처리 확인
8. 같은 통화의 중복발송 차단
9. 문자 권한이 없어도 고객 저장 유지
10. 작은 화면과 키보드 표시 상태에서 저장 버튼 접근 가능

이 목록은 현재 v0.28 전체 검수표가 아니다. 최신 E2E 범위는 [`DEVELOPMENT_STATUS_AND_ROADMAP_KO.md`](DEVELOPMENT_STATUS_AND_ROADMAP_KO.md)의 10차 패치를 따른다.
