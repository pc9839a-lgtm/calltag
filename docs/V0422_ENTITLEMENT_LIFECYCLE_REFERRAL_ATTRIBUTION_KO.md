적용 항목:

9. 웹 결제 중복구독 사전 판정 API 준비

## 무료기간 만료 정책

무료 이용기간은 기본 3일이며 추천인 등록 시 최초 한 번 5일이 추가된다.

만료 후에도 유지되는 항목:

- 고객 목록과 고객 상세
- 상담 이력
- 기존 메모와 일정
- 문자 템플릿
- 기존 발송 내역
- 백업 및 복원

만료 후 제한되는 항목:

- 통화 종료 후 신규 고객 정리
- 신규 자동문자 실행
- 신규 그룹·단체문자 실행
- 신규 문자 발송 전송 단계

데이터 삭제나 DB 초기화는 수행하지 않는다.

## 서버 시각 판정

`GET /api/billing/entitlements` 응답의 `serverNow`를 앱에 저장한다.

앱은 다음 값을 함께 저장한다.

- 서버 확인 시각
- 서버 확인 당시 기기 시각
- 이용 종료 시각

이후 오프라인 상태에서는 서버 확인 이후 경과시간을 더해 예상 서버 시각을 계산한다. 사용자가 기기 날짜를 뒤로 돌려도 무료기간이 다시 늘어나지 않는다.

## 안내 화면

### 종료 24시간 이내

- 제목: `무료 이용이 곧 종료됩니다.`
- 고객·상담 기록이 유지됨을 안내
- 통화 후 정리와 문자 자동화만 중지됨을 안내
- 이용권 확인 버튼 제공

### 종료 후

- 제목: `무료 이용이 종료되었습니다.`
- 고객 기록 보기 가능
- 이용권 시작 시 자동화가 복구됨을 안내

같은 안내는 서버 기준 날짜당 한 번만 노출한다.

## 기능별 권한

- `call_monthly`: 전화관리
- `message_monthly`: 문자자동화
- `all_monthly`: 전화관리 + 문자자동화 + 페이지로

문자 설정 메뉴 중 템플릿과 발송 기록은 계속 열 수 있다. 자동문자와 그룹·단체문자 진입은 이용권이 없으면 이용권 안내를 표시한다.

실제 SMS 전송 단계도 `FeatureEntitlementStore.hasMessageAccess()`를 다시 검사하므로 화면 우회로 발송할 수 없다.

## 추천 링크 자동 귀속

공유 링크 형식:

```text
https://pagero.kr/r/{추천코드}
```

앱 딥링크 형식:

```text
calltag://referral?code={추천코드}
```

동작:

1. 추천 링크가 앱으로 열리면 추천코드를 로컬 pending 저장소에 보관한다.
2. 로그인 전이라도 최대 30일간 보관한다.
3. 로그인 완료 또는 앱 전면 진입 후 서버에 자동 등록한다.
4. 성공하면 pending 코드를 삭제한다.
5. 일시적인 네트워크 오류는 다음 실행에서 재시도한다.
6. 본인 추천·이미 등록·유료 전환 완료·존재하지 않는 코드는 재시도하지 않는다.

Play Console 미등록 상태에서는 설치 전 완전한 deferred deep link를 제공할 수 없다. 현재 단계는 설치된 앱 자동 귀속과 미설치 사용자의 코드 보관·수동 입력을 지원한다.

## 파트너센터 제외

이번 패치에서는 다음을 구현하지 않는다.

- 파트너센터 모바일 웹
- 파트너센터 열기 버튼
- 출금 신청
- 정산 계좌 등록
- 회원별 상세 수익 화면

추천 회원 수·유료 회원 수·예상 수익·확정 수익 요약은 기존 앱 화면에 유지한다.

## 웹 결제 준비

앱 API 클라이언트에 다음 계약을 추가했다.

- `GET /api/billing/readiness`
- `POST /api/billing/web/precheck`

실제 웹 checkout을 열기 전 서버가 기존 웹 또는 Google Play 활성 구독을 확인해야 한다. checkout과 webhook 자체는 아직 열지 않는다.

## Google Play 상태

Play Console 앱과 상품이 아직 등록되지 않았으므로 다음 조건은 계속 꺼진 상태다.

```text
GOOGLE_PLAY_PRODUCTS_READY=0
GOOGLE_PLAY_BILLING_ENABLED=0
```

앱은 결제 버튼을 `출시 준비 중`으로 유지하며 BillingClient 연결과 상품 조회를 실행하지 않는다.
