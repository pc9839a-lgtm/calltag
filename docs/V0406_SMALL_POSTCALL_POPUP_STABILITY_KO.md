# 콜태그 v0.40.6 통화 종료 소형 팝업 안정화

## 사용자 요구사항

- 통화 종료 후 콜태그 앱 전체 화면을 열지 않는다.
- 화면 중앙에 작은 정리 팝업만 표시한다.
- 팝업은 사용자가 닫기·저장·제외를 누르기 전에는 자동으로 사라지지 않는다.
- 전화 앱의 통화 종료 애니메이션이나 마지막 화면 전환 때문에 팝업이 뒤로 밀리거나 종료되지 않아야 한다.
- v0.40.5의 연락처 이름 메모 동기화 방식은 그대로 유지한다.

## 팝업 크기

- 가로: 화면 좌우 16dp 여백을 확보하고 최대 420dp
- 세로: 화면 높이의 약 66%, 최대 560dp
- 최소 세로 높이: 기기 공간이 허용되는 범위에서 420dp
- 화면 중앙 정렬
- 배경 어둡기 0.42
- 내부 내용은 팝업 안에서 스크롤

## 표시 안정화

1. 통화기록을 찾은 직후 바로 열지 않고 1.2초 대기한다.
2. 삼성 전화·에이닷의 통화 종료 화면 전환이 끝난 뒤 팝업을 한 번만 연다.
3. 같은 통화 ID는 8초 안에 중복 실행하지 않는다.
4. `CLEAR_TOP`과 `SINGLE_TOP` 실행 플래그로 기존 화면을 정리하지 않는다.
5. `PostCallActivity`는 콜태그 메인 화면과 분리된 전용 taskAffinity에서 실행한다.
6. 팝업 task는 최근 앱 목록에 표시하지 않지만 자동으로 제거하지 않는다.
7. Activity created·started·resumed 시마다 소형 창 크기를 다시 적용한다.
8. 바깥 영역 터치로 닫히지 않는다.

## 닫히는 조건

팝업은 다음 경우에만 종료한다.

- 사용자가 상단 닫기 버튼을 누름
- 저장만 하기 완료
- 저장하고 문자 보내기 완료
- 고객관리 제외 완료
- Android가 앱 프로세스를 강제 종료함

통화 상태 `IDLE`, 연락처 동기화, 앱 pause·stop만으로는 팝업을 종료하지 않는다.

## 유지 기능

- 콜태그 전용 RawContact 기반 `고객명 · 최근 메모` 표시
- 최근 메모 최대 16자
- 앱 사용 중 5초 주기 연락처 동기화
- 원본 Google·삼성 연락처 비수정
- 기능 해제 시 콜태그 연락처만 삭제
- 통화 종료 저장 후 연락처 이름 재동기화

## 실기기 QA

1. 10초 이상 통화 후 종료
2. 전화 앱 화면이 완전히 닫힌 뒤 중앙 소형 팝업이 표시되는지 확인
3. 팝업이 최소 30초 이상 그대로 유지되는지 확인
4. 홈 화면으로 이동했다가 팝업으로 돌아와도 같은 크기인지 확인
5. 바깥 영역을 눌러도 닫히지 않는지 확인
6. 닫기 버튼을 눌렀을 때만 닫히는지 확인
7. 저장 후 연락처 표시명이 최신 메모로 갱신되는지 확인

APK 빌드 성공은 실제 삼성·에이닷 단말 안정성 검증과 구분한다.
