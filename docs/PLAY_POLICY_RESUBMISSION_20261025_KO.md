# 콜태그 0.44.64 권한 동의 및 문의 자동문자 수정

대상: `kr.pagero.calltag`, versionName `0.44.64`, versionCode `2026102501`.
기준 코드: `a1783b4cfa610bb78ddfeb2c0609ef733d7adb3c` (0.44.63).

## 수정 내용

- `FeatureAccessGate`는 이용권과 전화 설정만 검사한다. 문자 화면을 여는 시점에는 SEND_SMS를 요청하지 않는다. 실제 즉시·예약·단체 발송 또는 자동화 저장에서 해당 기능의 설명 후 권한을 요청한다.
- 수동 문자에서 SMS 권한 승인 후 원래 선택한 즉시 발송 또는 예약 작업으로 돌아간다. 이미지 문자는 기존 기본 메시지 앱 작성 흐름을 유지한다.
- 페이지로 문의 자동문자는 문자 권한 승인 전에 ON으로 저장하지 않는다. 권한 승인 후 현재 입력값을 다시 검증해 저장한다. 취소 시 새 자동화를 활성화하지 않는다.
- 문의 자동문자의 지연 발송도 `SmsSender`의 실제 발송 직전에 현재 문의 자동문자 ON/OFF를 다시 확인한다. OFF이면 발송하지 않는다. 통화 자동문자와 문의 자동문자는 각각의 스위치를 따른다.
- 문의 자동문자 설정·템플릿·지연 시간은 로그인한 서버 계정별로 분리한다. 미로그인·계정 식별자 누락 상태에서는 실행하지 않는다.
- 최초 권한 안내에서 READ_CALL_LOG의 최근 통화 고객 선택 용도와 SMS의 즉시·예약·자동화 용도를 실제 기능에 맞게 설명한다.

## 업데이트 시 확인

옛 문의 자동문자 설정에는 계정 소유자 정보가 없다. 새 계정별 저장소로 자동 승계하지 않으며 기본 OFF로 시작한다. 업데이트 후 `문자 > 페이지로 문의접수문자`에서 사용할 문구·지연 시간을 확인하고 다시 켜서 저장해야 한다. 기존 문의 연동 자체와 고객 기록을 삭제하지 않는다.

## 권한 및 핵심 기능

READ_CALL_LOG와 SEND_SMS는 유지한다. 기본 전화 앱 변경이나 새 SMS 읽기 권한을 추가하지 않는다. 통화 후·부재중·후속 예약, 일정·문의 접수 자동문자, 사용자 즉시·예약·단체 발송 및 재발송 경로를 선언과 스토어 설명에 빠짐없이 적는다. 기능을 언급하는 것만으로 Google 정책 예외 승인이 확정되는 것은 아니다.

기존 영상 `https://www.youtube.com/watch?v=GcJ46iZJAos`는 0.44.63의 실제 통화 조건 → 통화 → SMS 결과를 보여준다. 이번 버전의 수동·문의 문자 권한 흐름을 촬영한 영상이라고 표기하지 않는다. 코드 수정이나 버전코드 증가만으로 기존 거부가 자동 해소됐다고 주장하지 않는다.

## 검증

- 기존 정책·외부문의·SQLite 보존·CRM 원자성·운영 API 원본 검사 실행.
- `calltag-sms-consent-runtime-check.py`: 실제 동의 저장소와 기능 진입 코드를 JVM에서 실행. 지연 문의 OFF, 계정 A/B/미로그인 분리, 통화·문의 스위치 독립, 문자 진입 시 권한 미요청, 만료 이용권·전화 설정 분기 유지 검사. Android 어댑터는 메모리 대체물이다.
- Debug APK 컴파일 및 기존 Play 업로드 인증서 SHA-256 고정 검증을 포함하는 서명 Release AAB 빌드.
- 실기기 SIM·통화·SMS 전송은 이 자동 검사로 확인되지 않는다.

## 출시 노트

문자 권한 요청 흐름을 개선했습니다. 문의 자동문자를 끄면 대기 중인 발송에서도 현재 설정을 확인하며, 문의 자동문자 설정을 계정별로 분리했습니다.

이 작업은 AAB를 준비하며 Play Console 업로드·심사 제출·프로덕션 출시는 실행하지 않는다.
