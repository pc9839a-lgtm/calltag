# 콜태그 v0.40.7 사용자 화면 정리

## 목적

사용자에게 필요하지 않은 테스트·진단·개발 상태를 제거하고 앱 시작과 종료 동작을 제품 수준으로 정리한다.

## 제거한 사용자 노출

전화 화면 메모 설정에서 다음 항목을 제거했다.

- 상세 오버레이 테스트
- 통화 종료 알림 테스트
- 수신 진단 시각과 진단 원문
- 동기화 내부 상태 원문
- CallScreeningService·오버레이 권한 상태
- 잠금화면 상세 오버레이 표시 범위
- 개발용 테스트 고객 생성 경로

설정 화면에는 기능 설명, 현재 준비 상태, 필수 권한 진행, 전화 화면 메모 켜기·끄기만 남긴다.

## 로딩 화면

- 앱 실행 시 콜태그 로고와 서비스 문구를 표시한다.
- 진행 표시를 제공한다.
- 최소 750ms 유지해 로그인 상태 확인이 빠르게 끝나도 화면이 깜박이지 않게 한다.
- 로그인 세션이 없으면 로그인 화면으로 이동한다.
- 세션이 있으면 필수 설정 또는 메인 화면으로 이동한다.
- 네트워크 확인 실패 시 저장된 유효 세션이 있으면 앱 진입을 허용한다.

## 뒤로가기 종료 방지

- 메인 화면의 고객·일정·더보기 탭에서 뒤로가면 오늘 탭으로 이동한다.
- 오늘 탭에서 뒤로가면 `앱을 닫을까요?` 확인창을 표시한다.
- 사용자가 `앱 닫기`를 선택하기 전에는 Activity task를 종료하지 않는다.
- Android 13 이상은 OnBackInvokedCallback을 사용한다.
- Android 12 이하는 Window.Callback 단계에서 뒤로가기 키를 가로챈다.
- 종료 확인창은 중복 표시하지 않으며 바깥 터치로 닫히지 않는다.

## 사용자 노출 원칙

사용자 화면에 노출하지 않는다.

- 테스트·데모·진단·디버그 문구
- 서버 응답 원문
- 내부 클래스·Provider·Service 명칭
- 브랜치·커밋·빌드 상태
- 마지막 진단 시각

사용자에게는 현재 상태, 필요한 조치, 재시도 방법, 데이터 보존 여부만 표시한다.
