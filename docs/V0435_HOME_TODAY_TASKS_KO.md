# CallTag v0.43.5 홈 오늘 할 일 범위 수정

## 버전

- versionName: `0.43.5`
- versionCode: `73`
- targetSdk: `36`

## 수정 내용

홈의 `오늘 할 일` 목록은 기기 현지 날짜를 기준으로 다음 범위만 표시합니다.

- 오늘 00:00 이상
- 내일 00:00 미만
- 상태가 `PENDING`인 미완료 일정만 표시

홈 목록에서 제외되는 항목:

- 어제까지의 기한 지난 일정
- 내일 이후의 미래 일정
- 이미 완료된 일정

기한 지난 일정의 개수는 홈의 `기한 지남` 요약 카드에서 계속 확인할 수 있습니다. 전체 일정과 날짜별 일정은 일정 캘린더에서 확인합니다.

## 유지 기능

- 통화 종료 신규 고객 자동등록
- 통화 종료 큰 정리 화면 및 알림 fallback
- 사진 포함 템플릿 자동 MMS 발송
- 선택 SIM 직접 MMS 발송
- MMS 실패 시 일반 SMS 대체발송
