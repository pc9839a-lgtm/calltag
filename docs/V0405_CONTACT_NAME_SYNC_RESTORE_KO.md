# 콜태그 v0.40.5 연락처 이름 메모 복구

## 목적

실제 삼성 전화·에이닷 수신 화면에서 안정적으로 메모가 보였던 연락처 Provider 방식을 주 기능으로 복구한다.

## 동작

- 전화가 오기 전에 콜태그 전용 RawContact를 생성한다.
- 같은 전화번호의 Google·삼성 원본 연락처와 결합한다.
- 원본 연락처 행은 수정하거나 삭제하지 않는다.
- 표시명은 `고객명 · 최근 메모` 형식이다.
- 최근 메모는 최대 16자, 전체 별칭은 최대 32자다.
- 이름없는고객은 `고객 + 전화번호 끝 4자리`로 표시한다.
- 메모가 없으면 고객명만 표시한다.
- 앱 사용 중 5초마다 동기화한다.
- 앱 일시정지·종료 시에도 마지막 동기화를 요청한다.
- 기능을 끄면 콜태그 계정의 RawContact만 삭제한다.

## 권한

- READ_CONTACTS
- WRITE_CONTACTS
- READ_PHONE_STATE
- READ_PHONE_NUMBERS
- READ_CALL_LOG
- POST_NOTIFICATIONS
- 문자 기능 사용 시 SEND_SMS

WRITE_CONTACTS는 콜태그 전용 연락처 행의 생성·갱신·삭제에만 사용한다.

## 선택 기능

CallScreeningService와 다른 앱 위 표시를 이용한 상세 오버레이는 선택 기능으로 유지한다. 수신 메모의 기본 경로는 연락처 표시명이다.

## 유지한 수정

v0.40.4의 통화 종료 팝업 이중 실행 제거와 즉시 종료 크래시 방지 코드는 유지한다.
