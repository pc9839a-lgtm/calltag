# 콜태그 고객 상태 커스텀 기준

## 1. 목적

콜태그의 고객 상태는 고객 등급이 아니라 영업자가 현재 고객의 진행 상황을 한눈에 구분하기 위한 태그다.

`VIP`, `우수 고객`처럼 기준이 불명확한 등급은 기본 상태로 제공하지 않는다.

## 2. 기본 상태

최초 설치 시 기본 상태는 3개만 제공한다.

1. 신규
2. 진행 중
3. 완료

기본 3개도 고정 문구가 아니다. 사용자가 이름과 색상을 직접 수정할 수 있다.

기본 3개는 삭제하거나 순서를 바꾸지 않는다. 화면을 복잡하게 만드는 순서 변경 기능은 제공하지 않는다.

## 3. 사용자 상태

기본 3개 외 상태가 필요하면 사용자가 직접 추가한다.

사용자가 할 수 있는 작업:

- 사용자 상태 추가
- 상태 이름 변경
- 상태 태그 색상 변경
- 사용자 상태 삭제

사용자 상태도 순서 변경 기능은 제공하지 않는다. 추가한 순서대로 기본 3개 뒤에 표시한다.

상태 이름은 최대 18자로 제한한다.

사용자 상태를 삭제하면 해당 상태의 고객은 첫 번째 기본 상태로 이동한다.

## 4. 상태 색상

상태마다 하나의 태그 색상을 저장한다.

기본 색상:

- 신규: 파란색
- 진행 중: 주황색
- 완료: 초록색

사용자는 기본 상태와 사용자 상태 모두 색상을 변경할 수 있다.

같은 색상은 다음 화면에 동일하게 적용한다.

- 고객 목록 상태 버튼
- 고객 카드 테두리
- 선택된 상태 필터
- 고객 상세 상태 태그
- 캘린더 일정 배지

색상은 장식이 아니라 고객 상태를 빠르게 식별하기 위한 정보 체계로 사용한다.

## 5. 고객 목록 UX

### 상단

- `+ 고객 추가`: 주요 행동 버튼
- `전체 상태 ▾`: 상태 필터 버튼
- `상태·색상 편집`: 상태 관리 버튼

상태 필터에는 기본 3개와 사용자가 추가한 상태를 표시한다.

### 고객 카드

고객 카드에는 다음을 표시한다.

- 고객명
- 전화번호
- 최근 연락일
- 현재 상태 버튼
- `고객 상세 보기` 버튼

현재 상태는 `상태명 ▾` 형태의 채워진 색상 버튼으로 표시한다.

고객 카드 테두리에도 같은 상태 색상을 적용해 목록에서 서로 다른 상태를 한눈에 구분한다.

카드 전체에 숨은 클릭 기능을 넣지 않는다. 상태 변경과 상세 이동은 각각 명확한 버튼으로 구분한다.

## 6. 상태 변경 기록

고객 상태를 변경하면 다음 정보를 활동 이력에 남긴다.

- 변경 전 상태
- 변경 후 상태
- 변경 시각

상태 이름이 변경되면 해당 상태를 사용 중인 고객의 상태명도 함께 변경한다.

## 7. 통화 후 처리 원칙

새 고객은 첫 번째 기본 상태에 등록한다.

통화 결과나 일정 등록만으로 고객 상태를 강제로 변경하지 않는다.

`거래 완료` 결과를 직접 선택한 경우에는 세 번째 기본 상태로 이동한다. 기본 상태명이 수정되어 있어도 세 번째 기본 상태를 완료 상태로 사용한다.

## 8. 캘린더 표시 규칙

일정이 있는 날짜를 점으로 표시하지 않는다.

날짜 셀 안에 예시 화면처럼 일정 내용을 작은 색상 배지로 직접 표시한다.

배지 표시 내용:

- 고객명
- 일정명

표시 기준:

- 한 날짜에 최대 2줄 표시
- 공간을 초과하면 `+N개 일정`으로 축약
- 일정 배지 색상은 해당 고객 상태 색상과 동일하게 사용
- 완료 일정은 회색으로 표시
- 선택 날짜는 파란 테두리
- 오늘 날짜는 얇은 파란 테두리
- 날짜 셀 외곽과 일정 배지가 잘리지 않도록 내부 여백 확보

모바일 월간 달력에서는 긴 일정명을 말줄임 처리하고, 선택한 날짜 아래 목록에서 전체 내용을 확인한다.

## 9. 데이터 마이그레이션

DB 버전 3에서 기존 6개 기본 단계를 3개로 단순화한다.

- `신규 문의` → `신규`
- `요구 확인`, `견적·자료 발송`, `검토 중`, `계약 예정` → `진행 중`
- `계약 완료` → `완료`

사용자가 직접 만든 기존 사용자 상태는 삭제하지 않고 기본 3개 뒤에 유지한다.

## 10. v0.11.0 패치 범위

- 영업 단계 순서 변경 UI 완전 제거
- 기본 상태 3개로 축소
- 기본 상태 이름·색상 수정 허용
- 사용자 상태 추가·수정·삭제
- 고객 카드 상태 색상 테두리 적용
- 고객 목록 상태 버튼을 채워진 색상 태그로 변경
- 카드 전체 숨은 클릭 제거
- 고객 상세 이동을 실제 버튼으로 분리
- 캘린더 일정 점 제거
- 날짜 셀 내부 일정명 색상 배지 적용
- DB 버전 3 마이그레이션
