# 콜태그 v0.16.0 전화 수신 오버레이 기준

## 목적

전화가 울리는 순간 영업자가 전화 앱을 벗어나지 않고 고객명, 현재 상태, 최근 메모를 확인할 수 있어야 한다.

## 기본 표시 방식

수신 고객정보의 기본 방식은 Android 알림이 아니라 `TYPE_APPLICATION_OVERLAY` 기반 화면 위 카드다.

표시 항목:

- 콜태그 등록 고객 표시
- 고객명
- 고객 상태와 사용자 지정 상태 색상
- 전화번호
- 최근 메모 최대 4줄
- 최근 연락 시각
- 고객 상세 보기
- 닫기

## 유지와 종료

- 임의 시간 제한으로 자동 종료하지 않는다.
- 사용자가 `닫기`를 누르면 즉시 제거한다.
- 통화 상태가 `IDLE`로 바뀌면 자동 제거한다.
- 새 고객 전화가 들어오면 기존 오버레이를 제거하고 새 정보로 교체한다.

## 전화 앱과 충돌 방지

- 화면 상단에 배치한다.
- 전화 받기·거절 버튼이 있는 하단 영역을 가리지 않는다.
- `FLAG_NOT_FOCUSABLE`, `FLAG_NOT_TOUCH_MODAL`을 사용해 기본 전화 앱 조작을 유지한다.
- 오버레이 안의 닫기와 고객 상세 버튼만 직접 누를 수 있다.

## 권한과 설정

필수 항목:

1. `READ_CONTACTS`
2. `READ_PHONE_STATE`
3. Android 수신정보 앱 역할
4. `SYSTEM_ALERT_WINDOW`의 다른 앱 위에 표시 허용
5. 통화 종료 정리용 알림 권한

설정 화면은 각 항목을 `완료 / 필요`로 표시한다.

## 실패 처리

오버레이 권한이 없거나 `WindowManager.addView`가 실패하면 수신 고객정보 알림을 게시한다. 알림은 기본 방식이 아니라 대체 수단이다.

진단 문구는 다음을 구분한다.

- 전화 화면 위 고객정보 표시 성공
- 오버레이 권한 없음, 알림으로 대체
- 오버레이와 알림 모두 실패
- 미등록 번호
- 제외번호
- 전화번호 미전달

## 테스트

`수신 화면 테스트`를 누르면:

1. 첫 번째 등록 고객을 불러온다.
2. 앱을 뒤로 보낸다.
3. 2초 후 실제 오버레이를 표시한다.
4. 사용자가 닫기 버튼으로 직접 종료한다.

실제 통화가 아닌 테스트에서는 통화 상태 감시를 시작하지 않는다.

## 실기기 QA

- 앱이 전면에 있을 때
- 홈 화면에 있을 때
- 다른 앱 사용 중일 때
- 기본 전화 앱 수신 화면 위
- 화면 잠금 상태
- 삼성 `다른 앱 위에 표시` 허용 상태
- 통화 받기 후에도 유지되는지
- 통화 종료 시 자동 제거되는지
- 닫기 버튼 동작
- 오버레이 권한 제거 후 알림 대체
