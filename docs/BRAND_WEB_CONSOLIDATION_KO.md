# 콜태그 브랜드·웹사이트 통합 기준

기준일: 2026-07-31  
정식 서비스명: **콜태그(CallTag)**  
대표 도메인: `https://calltag.pagero.kr`

## 1. 결정 사항

전화관리 제품과 문자자동화 제품을 서로 다른 서비스로 운영하지 않는다.

```text
정식 앱: 콜태그
정식 웹사이트: 콜태그
정식 스토어 등록명: 콜태그
정식 고객 안내명: 콜태그
```

문자자동화는 콜태그 안의 기능군이며 별도 앱명이나 별도 브랜드명을 사용하지 않는다.

## 2. 레거시 명칭 처리

`페이지로 콜링크`와 `콜링크`는 다음 범위에서만 사용할 수 있다.

- 이전 저장소와 코드 이력 설명
- 문자 모듈 이전·마이그레이션 문서
- 기존 사용자 데이터 호환 설명
- 과거 스토어 심사나 배포 기록

다음 위치에서는 사용하지 않는다.

- 앱 이름과 앱바
- 공개 웹사이트
- 스토어 제목과 소개문
- 요금제 이름
- 회원가입·결제·고객지원 화면
- 광고와 홍보물
- 알림 제목과 문자 발신 안내

사용자에게 보이는 명칭은 항상 `콜태그`다.

## 3. 제품 표현 방식

콜태그의 제품 구조는 두 개의 앱이 아니라 하나의 앱 안에 있는 세 가지 이용권이다.

| 이용권 | 월 요금 | 기능군 |
|---|---:|---|
| 전화관리 | 1,900원 | 고객·통화·메모·상태·일정·통계 |
| 문자자동화 | 990원 | 템플릿·자동·수동·예약·단체문자 |
| 통합 이용 | 2,500원 | 두 기능군 전체와 연결 자동화 |

공개 문구는 다음 구조를 사용한다.

> 전화관리 + 문자자동화, 하나의 콜태그

`콜링크가 콜태그에 포함된다`, `콜링크 요금제`, `콜태그와 콜링크 통합`처럼 두 브랜드가 현재도 병존하는 표현은 공개 화면에서 사용하지 않는다.

## 4. 웹사이트 단일화

### 대표 페이지

- canonical: `https://calltag.pagero.kr/`
- 소스 기준: `web/index.html`
- 메타 사이트명: `콜태그`
- 구조화 데이터 이름: `콜태그`
- 영문 보조명: `CallTag`

### 공개 정보 구조

1. 통화 후 고객관리 핵심 가치
2. 고객 확인·상태·일정·문자 네 단계
3. 수신·발신·부재중·후속 문자자동화
4. 저장형 템플릿과 변수 치환
5. 발송 제외·중복방지·상태 재검사
6. 그룹·단체문자와 일정 연동 후속문자
7. 전화관리·문자자동화·통합 이용 요금
8. 현재 기능이 순차 적용 중이라는 안내
9. FAQ와 도입 문의

### 배포 경로

루트 배포와 `web` 디렉터리 배포가 혼재해도 사용자에게는 같은 콜태그 페이지가 보여야 한다.

- 루트 요청은 `web/index.html`로 내부 rewrite
- `/web/`를 외부 대표 URL로 사용하지 않음
- canonical은 항상 루트 도메인
- 이전 공개 도메인이 남아 있다면 Cloudflare Redirect Rule로 대표 도메인에 301 이동

권장 이전 도메인 규칙:

```text
call.pagero.kr/*
→ https://calltag.pagero.kr/$1
상태 코드 301
```

DNS나 Cloudflare 대시보드의 도메인 연결은 저장소 코드만으로 변경되지 않으므로 운영 설정에서 별도로 적용한다.

## 5. 구현 상태 표현

웹사이트는 최종 제품 방향을 설명하지만 현재 v0.20에 모든 기능이 구현된 것처럼 표현하지 않는다.

반드시 포함할 고지:

```text
통합 기능 순차 적용 중
베타와 출시 시점의 실제 제공 범위는 앱 내 안내와 개발 현황을 기준으로 합니다.
```

다음 기능은 구현 완료 여부를 개발 상태 문서와 대조한다.

- 다수 저장형 템플릿 보관함
- 공통 발송 제외 정책
- 통화·일정·캠페인 공통 중복 엔진
- 그룹·단체문자 캠페인
- 일정과 후속문자 생명주기 연결
- 웹 동기화

## 6. 앱과 코드 기준

- Android Application ID: `kr.pagero.calltag`
- Java 패키지: `kr.pagero.calltag`
- 앱 표시명: `콜태그`
- 계정과 APK: 하나
- 구매 권한에 따라 기능 활성화

레거시 데이터 키나 마이그레이션 코드에 과거 명칭이 남는 것은 허용하되 사용자 화면에는 노출하지 않는다.

## 7. 점검 체크리스트

- [ ] 앱 런처 이름이 콜태그인가
- [ ] 앱바·설정·결제·알림에 콜링크가 노출되지 않는가
- [ ] 웹 title·description·OG·구조화 데이터가 콜태그인가
- [ ] 웹 canonical이 `calltag.pagero.kr`인가
- [ ] 요금제는 전화관리·문자자동화·통합 이용으로 표현되는가
- [ ] 문자 기능이 별도 앱처럼 설명되지 않는가
- [ ] 이전 도메인이 대표 도메인으로 301 이동하는가
- [ ] 현재 미구현 기능에 순차 적용 안내가 있는가
- [ ] 스토어와 개인정보처리방침의 서비스명이 콜태그로 일치하는가
