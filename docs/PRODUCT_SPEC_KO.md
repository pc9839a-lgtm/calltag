# 콜태그 제품 정의

기준일: 2026-07-31  
저장소: `pc9839a-lgtm/calltag`

상세 기획서: [`CALLTAG_UNIFIED_PRODUCT_PLAN_KO.md`](CALLTAG_UNIFIED_PRODUCT_PLAN_KO.md)

> 이 문서는 제품의 현재 기준을 요약한다. 과거의 `콜링크·콜태그 별도 앱` 전제는 폐기됐으며, 상세 기능·구독·문자 자동화·개발 순서는 통합 제품 기획서를 따른다.

---

## 1. 제품명과 정의

최종 앱명은 **콜태그(CallTag)**다.

콜태그는 전화가 오기 전 고객 맥락을 보여주고, 통화가 끝난 뒤 고객 상태·메모·일정·문자 발송까지 이어주는 Android 고객관리 앱이다.

기존 페이지로 콜링크의 문자 기능은 별도 앱으로 운영하지 않고 콜태그의 `문자자동화` 모듈로 이전한다.

제품 설명:

> 전화 한 통을 고객 상태, 메모, 다음 할 일, 문자 발송까지 연결합니다.

---

## 2. 구독 상품

| 상품 | 월 구독료 | 제공 범위 |
|---|---:|---|
| 전화관리 | 1,900원 | 고객·통화·상태·메모·일정·통계 |
| 문자자동화 | 990원 | 템플릿·자동·수동·예약 문자·발송내역 |
| 통합 이용 | 2,500원 | 전화관리와 문자자동화 전체 및 통합 흐름 |

하나의 APK 안에서 구매 권한으로 기능을 구분한다. 앱을 별도로 설치하거나 계정을 다시 만들지 않는다.

내부 기능 권한:

```text
PHONE_CRM_ENABLED
MESSAGE_AUTOMATION_ENABLED
WEB_SYNC_ENABLED
```

## 3. 핵심 사용자 흐름

```text
전화 수신 전
→ 연락처 이름에서 고객명 + 핵심 메모 확인
→ 통화
→ 통화 종료 감지
→ 고객 상태·메모·다음 할 일 저장
→ 즉시 문자 또는 예약 문자 발송
→ 고객 타임라인에 통화·문자·일정 기록
```

기본 전화 앱은 교체하지 않는다. 에이닷의 통화녹음·AI 요약과 공존한다.

수신 전 고객정보는 일반 오버레이가 아니라 연락처 표시명 동기화를 기본으로 한다.

예:

```text
김민수 · 견적서 재발송
고객 4396 · 금요일 다시 전화
```

---

## 4. 전화관리 기능

- 수신·발신·부재중·거절·미연결 통화 감지
- 전화번호 기준 고객 조회
- 이름 없는 고객을 번호 끝 네 자리로 구분
- 고객 상태 `신규 / 진행 중 / 완료` 및 사용자 상태 편집
- 통화 종료 후 결과·메모 저장
- 다음 할 일과 캘린더
- 신규 고객에게 첫 일정을 추가하면 `진행 중` 자동 변경
- 고객별 통화·메모·상태·문자·일정 타임라인
- 1일·7일·14일·30일 통계
- 실제 처리 가능한 관리공백 목록

---

## 5. 문자자동화 기능

- 템플릿으로 시작
- 자유롭게 작성
- SMS·LMS·이미지 MMS
- 통화 종료 후 자동 발송
- 부재중·거절 후 자동 발송
- 연결된 발신 통화 종료 후 발송
- 수동 발송
- 특정 날짜·시간 예약
- 통화 종료 N분·N시간·N일 뒤 발송
- 예: 견적 통화 3일 뒤 검토 여부 확인 문자
- SIM·eSIM 회선 선택
- 업무시간
- 중복 발송 방지
- 제외번호·수신거부
- 발송 성공·실패·건너뜀 기록
- 재부팅 후 예약 복구

문자자동화만 구매한 사용자에게도 자동발송 트리거에 필요한 최소 통화 감지는 제공한다. 고객 CRM·상태·통계는 전화관리 권한이 있어야 한다.

---

## 6. 통합 이용 핵심 화면

통화 종료 후 하나의 화면에서 아래를 처리한다.

- 통화 결과
- 고객 상태
- 통화 메모
- 다음 할 일
- 즉시 발송 템플릿
- 이미지 첨부
- 3일 뒤 등 후속 문자

주요 버튼:

```text
[저장만 하기]
[저장하고 문자 보내기]
```

저장 결과는 하나의 고객 타임라인으로 연결한다.

---

## 7. 메인 메뉴

하단 메뉴는 네 개다.

1. 홈
2. 고객
3. 메시지
4. 일정

계정·구독·권한·회선·자동화 설정은 우측 상단 계정 또는 설정 버튼으로 진입한다.

고객 화면의 `목록 / 통계` 탭은 크게 표시하며, 스크롤 시 `상태 / 기간 / 편집`만 고정한다.

---

## 8. 초기 설정 UX

현재의 긴 `전화 고객정보 표시` 설명 화면은 제거한다.

```text
앱 실행
→ 로그인
→ Android 시스템 권한창 순차 표시
→ 사용자가 허용
→ 연락처 핵심 메모 표시 활성화
→ 홈 진입
```

앱이 권한을 자동 승인할 수는 없으며 사용자가 Android 시스템창에서 허용해야 한다.

권한을 거절하면 별도 설명 페이지 대신 홈 상단에 `권한 허용` 행동 버튼을 표시한다.

---

## 9. 삼성 리마인더와의 차별점

콜태그는 다시 전화할 시간을 알려주는 리마인더가 아니다.

> 리마인더는 할 일을 알려준다. 콜태그는 전화가 끝난 뒤 해야 할 일을 실제로 처리한다.

차별 기능:

- 통화 이벤트 자동 감지
- 고객 상태와 상담 이력
- 부재중 자동 문자
- 통화 직후 자동 문자
- 3일 뒤 조건부 후속 문자
- 고객 상태 변경 시 예약 자동 취소
- 통화·문자·메모·일정 통합 타임라인
- 관리 누락 원인별 행동 목록
- 웹 고객·템플릿·예약발송 관리

## 10. 개발 기준

- Android 네이티브 Java 17
- minSdk 26
- targetSdk 35
- 로컬 SQLite 우선
- 서버 연결 시 양방향 동기화
- 기존 `call-auto-sms-android`의 검증된 문자 발송 로직을 모듈 단위로 이전
- 중복 고객 DB와 중복 통화 감지 서비스는 만들지 않음

---

## 11. 정책 게이트

SMS·통화기록 권한은 Google Play 제한 권한이다. 자동 문자와 통화 감지가 핵심 기능임을 명시하고 권한 선언 심사를 준비해야 한다.

1차 배포는 원스토어 또는 직접 APK를 우선 검토한다. Google Play 배포는 정책 승인 전 확정적으로 표현하지 않는다.

통신사 SMS·MMS 요금은 콜태그 구독료에 포함되지 않는다.

---

## 12. 성공 기준

- 통화 종료 후 10초 안에 고객 정리가 끝난다.
- 부재중·거절 전화에 설정된 문자가 발송된다.
- 통화 종료 3일 뒤 예약 발송이 재부팅 후에도 유지된다.
- 고객 상태 변경 또는 사용자 처리 시 불필요한 예약이 취소된다.
- 전화·문자·메모·일정이 같은 고객에게 연결된다.
- 전화관리·문자자동화·통합 구독의 기능 권한이 정확히 적용된다.
- 삼성 리마인더를 별도로 조작하지 않아도 전화 후 업무가 이어진다.
