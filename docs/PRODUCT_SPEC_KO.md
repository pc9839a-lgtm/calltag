# 콜태그 제품 기획서

기준일: 2026-07-29  
저장소: `pc9839a-lgtm/calltag`  
패키지명: `kr.pagero.calltag`

## 1. 제품 정의

콜태그는 업무용 Android 휴대폰의 통화 흐름을 기반으로 고객을 식별하고, 통화 종료 직후 상담 결과·다음 행동·재연락 일정을 기록하는 1인 영업자용 고객관리 앱이다.

제품 설명:

> 통화가 끝나면 신규 고객, 기존 고객, 상담 상태와 다음 할 일이 자동으로 정리됩니다.

## 2. 해결할 문제

- 처음 전화한 문의자를 고객목록에 다시 입력해야 한다.
- 기존 고객의 이전 상담 내용을 기억하기 어렵다.
- 다시 연락하기로 한 약속을 놓친다.
- 견적서·소개서·주소 등 보내기로 한 자료를 누락한다.
- 고객과 현재 진행 중인 문의를 하나의 상태로 관리해 분류가 꼬인다.
- 일반 CRM은 입력 단계가 많아 통화 직후 사용하기 어렵다.

## 3. 핵심 사용자

초기 버전은 전화 상담 비중이 높은 1인 사업자와 개인 영업자를 대상으로 한다.

- 보험설계사
- 부동산 중개인
- 자동차 영업사원
- 광고·홈페이지 제작자
- 학원 상담자
- 인테리어·이사·방문서비스 사업자

## 4. MVP 핵심 기능

1. 수신·발신 통화 종료 감지
2. 전화번호 정규화 및 기존 고객 조회
3. 미등록 번호의 신규 고객 등록 제안
4. 기존 고객의 마지막 상담 및 다음 할 일 표시
5. 통화 후 상담 결과 빠른 선택
6. 다음 행동과 재연락 날짜 지정
7. 고객별 상담 이력 저장
8. 신규·진행 중·기존·휴면·제외 고객 분류
9. 오늘 할 일과 기한이 지난 업무 표시
10. 수신거부·개인통화·스팸 제외 처리

## 5. MVP에서 제외

- 통화 녹음과 통화내용 자동 수집
- AI 통화 요약
- 직원·팀 계정
- PC 관리자페이지
- 매출 회계와 세금계산서
- 카카오톡 자동 발송
- 전자계약
- 통신 3사 CTI 직접 연동

## 6. 제품 원칙

- 자동 저장보다 사용자 확인을 우선한다.
- 통화 후 처리는 10초 안에 끝나야 한다.
- 고객과 상담건은 별도 객체로 관리한다.
- 연락처에 저장됐다는 이유만으로 기존 고객으로 확정하지 않는다.
- 사용자가 처리하지 않은 업무는 홈에서 사라지지 않는다.
- 연락 거부 고객에게 다시 연락하지 않도록 경고한다.

## 7. 초기 메뉴

- `오늘`: 재연락, 미발송 자료, 기한 초과 업무
- `고객`: 신규·진행 중·기존·휴면·제외 고객
- `상담`: 진행 중인 상담건과 상담 이력
- `전체`: 분류 규칙, 알림, 개인정보, 계정

## 8. 초기 기술 기준

- Android 네이티브 앱
- Java 17
- minSdk 26
- targetSdk 35
- 로컬 SQLite 우선
- 서버 계정과 구독은 기능 검증 후 연결
- 민감 데이터는 외부 서버로 자동 전송하지 않음
