## 1. 제품 정의

콜태그는 전화 전후의 고객 맥락과 후속 업무를 한 앱에서 이어주는 Android 고객관리 앱이다.

핵심 흐름:

```text
고객 전화
→ 고객정보 확인
→ 통화
→ 작은 통화 후 팝업에서 메모
→ 고객 상태·일정·문자 후속관리
→ 고객 타임라인/통계 반영
```

페이지로를 함께 사용하는 경우:

```text
페이지로 랜딩 문의
→ 콜태그 고객 자동 등록/갱신
→ 새 문의 알림
→ 전화·문자·일정 후속관리
```

콜태그는 기본 전화앱을 교체하지 않는다.

---

## 2. 상품·가격

| 상품 | 월 가격 | 범위 |
|---|---:|---|
| **전화관리** | **1,900원** | 고객표시·통화 후 고객관리·상태·메모·일정·통계 |
| **문자자동화** | **990원** | 통화 후 자동문자·템플릿·그룹/단체문자·발송 관리 |
| **페이지로** | **3,500원** | 랜딩페이지 제작·문의 수집 |
| **통합권** | **6,000원** | 전화관리 + 문자자동화 + 페이지로 전체 |

상품 권한 키는 향후 실제 결제 구현에서 `CALL / MESSAGE / PAGERO / ALL_IN_ONE`으로 분리한다.

현재 앱에는 Google Play Billing Library가 들어가 있지만 실제 구매·구독 검증은 아직 완성되지 않았다. 결제 화면을 실제 결제 완료 상태로 표현하지 않는다.

---

## 3. 무료체험·추천

현재 확정 정책:

- 일반 신규가입: 통합권 **7일 무료**
- 회원가입 시 추천인 코드 입력: **+7일**
- 추천가입자: 통합권 **총 14일 무료**
- 추천코드는 회원가입 시 1회만 입력 가능
- 가입 후 추천코드 등록/변경 불가
- 무료체험은 결제수단 등록 없이 제공
- 무료체험 종료 후 자동결제하지 않음
- 데이터는 무료체험 종료 후 즉시 삭제하지 않음

추천인과 파트너는 별도 제도다.

## 4. 앱 정보구조

하단 탭은 현재 다음 5개다.

```text
고객 / 캘린더 / 홈 / 통계 / 더보기
```

### 고객

- 고객 목록
- 고객 검색
- 상태·기간 필터
- 고객 빠른 수정
- 고객 상세
- 고객별 최근 메모·상담이력·일정
- 고객 문자 진입
- 고객 추가

### 캘린더

- 월간 일정
- 선택 날짜 할 일
- 일정 추가·변경·완료·다시 열기·삭제
- 일정 종류 관리
- **최근통화 목록을 넣지 않음**

### 홈

- 오늘 할 일
- 확인할 통화
- 고객 바로가기
- 빠른 고객 추가
- 통화 감지 상태

`오늘 할 일`에는 오늘 일정만 보여준다.

확인할 통화는 부재중·거절·연결되지 않은 발신 후속처리에 사용한다.

### 통계

- 기간별 통화/고객 지표
- 일별 추이
- 통화유형 분포

- 차트 터치 시 해당 날짜 상세 숫자 표시

### 더보기

핵심 메뉴:

- **통화 후 자동문자** — 검색창 아래 대형 독립 카드
- 문자 문구·이미지
- 그룹·단체문자
- 발송 관리
- 고객 상태
- 일정 종류
- 계정 및 개인정보
- 데이터 보호·복구
- 이용권·결제
- 친구 초대·파트너
- 파트너 정산
- 페이지로 연동
- 페이지로 서비스 안내
- 백업 및 복원

## 5. 통화 전 고객정보 표시

최우선 기능 중 하나다.

현재 Play-safe 방향은 Android `CallScreeningService` 역할과 콜태그 UI/알림을 이용한다.

원칙:

- 사용자 원본 연락처 이름을 변경하지 않음
- 원본 Google/삼성 연락처를 덮어쓰지 않음
- 시스템 CallLog에 고객명/메모를 쓰지 않음
- 잠금화면 개인정보 노출 수준을 제한 가능하게 유지
- 고객명·상태·최근 메모 등 필요한 정보만 표시

삼성/Google Phone/에이닷 환경 차이는 별도 실기기 검증 대상으로 둔다.

---

## 6. 통화 종료 팝업

현재 제품 기준은 **작은 팝업 1개**다.

금지:

- 전체화면 통화 종료 정리창
- 큰 팝업 + 작은 팝업 동시 표시
- 같은 통화 팝업 Activity 중복 실행
- 통화 메타정보를 과도하게 보여주는 화면

기본 구성:

```text
고객명
메모
[저장] [닫기]
```

팝업에서 처리할 항목을 늘려 복잡한 CRM 폼으로 만들지 않는다.

통화 결과·일정·상태 등 추가 작업은 홈/고객 상세에서 이어간다.

---

## 7. 고객 추가와 실제 최근통화

`고객 추가 > 최근 통화`는 휴대폰 Android `CallLog`를 읽어 고객 등록을 빠르게 하는 화면이다.

code83 기준:

- `DATE DESC` 최신순
- 최대 60건
- 같은 번호의 여러 통화를 임의로 한 건으로 합치지 않음
- 이미 콜태그에 등록된 번호도 숨기지 않음
- 등록된 번호는 `등록됨` 표시
- 등록된 번호 선택 → 기존 고객 열기
- 미등록 번호 선택 → 고객 등록
- 화면 복귀 시 최근통화 재조회

기본 전화앱이 여러 통화를 한 카드로 시각적 그룹화하더라도 콜태그는 raw CallLog 행 기준으로 보여줄 수 있다.

## 8. 확인할 통화

대상:

- 부재중
- 거절
- 연결되지 않은 발신

카드에서 제공:

- 고객명/번호
- 통화 유형
- 최근 메모
- 다시 전화
- 할 일 등록
- 삭제

`할 일 등록`은 반드시 일정 등록 화면으로 연결한다. 통화 후 메모 팝업으로 연결하지 않는다.

삭제는 콜태그의 확인할 통화 목록에서만 삭제하며 휴대폰 기본 통화기록을 삭제하지 않는다.

---

## 9. 고객·메모·타임라인

고객 데이터의 정본은 콜태그 DB다.

고객 단위로 관리:

- 고객명
- 전화번호
- 고객 상태
- 메모
- 최근 연락
- 통화 interaction
- 일정
- 페이지로 문의
- 문자 이력

최근 메모는 홈 확인할 통화와 고객 관련 화면에서 바로 확인할 수 있어야 한다.

## 10. 일정

일정은 고객과 연결한다.

지원:

- 일정 종류 선택
- 날짜/시간
- 추가
- 변경
- 완료
- 다시 열기

일정 화면은 고객 일정 관리 화면이며 최근통화 조회 화면으로 사용하지 않는다.

## 11. 문자자동화

핵심 유형:

```text
수신 / 발신 / 부재중 / 후속
```

기능:

- 문자 템플릿 저장·수정·복제·삭제
- 통화 후 자동문자
- 그룹·단체문자
- 예약/후속
- 발송 제외
- 중복발송 방지
- 발송내역
- 업무시간
- SIM/회선 고려

자동문자는 제품 핵심 기능이므로 더보기의 일반 목록 안에 묻지 않는다.

## 12. 페이지로 연동

페이지로와 콜태그는 같은 계정 체계를 사용할 수 있지만 **서로 다른 서비스**다.

페이지로만 사용하는 고객도 존재할 수 있다.

앱 화면은 다음 둘로 분리한다.

### 페이지로 연동

- 연결 계정
- 연결 상태
- 새 문의 확인
- 문의 알림 상태

서비스 설명을 길게 넣지 않는다.

### 페이지로 서비스 안내

- 페이지로 서비스 정의
- 랜딩페이지 제작
- 문의 수집
- 콜태그와 함께 사용할 때의 흐름

두 화면을 다시 합치지 않는다.

## 14. UI 디자인 원칙

- 다크 테마 기본

## 15. Play 정책·시스템 데이터 원칙

허용:

- `READ_CALL_LOG`로 필요한 통화 읽기
- CallTag DB에 고객/메모/통화 interaction 저장

금지:

- `WRITE_CALL_LOG`

- Play 경고를 없애기 위해 필요한 `.so` 라이브러리를 임의 제거

## 19. 절대 바꾸지 말아야 할 확정사항

1. 통화 후 팝업은 작은 팝업 1개다.
2. 일정에는 최근통화를 넣지 않는다.
3. 홈 `할 일 등록`은 일정 등록이다.
4. 고객 추가 최근통화에서 등록 고객을 숨기지 않는다.
5. 페이지로 연동과 페이지로 안내는 분리한다.
6. 일반 무료체험은 7일이다.
7. 추천코드 입력 시 +7일, 총 14일이다.
8. 추천코드는 가입 시에만 입력한다.
9. 현재 가격은 1,900 / 990 / 3,500 / 6,000원이다.
10. `WRITE_CALL_LOG`를 다시 넣지 않는다.
