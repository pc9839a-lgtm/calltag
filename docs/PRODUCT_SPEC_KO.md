---

## 1. 제품 정의

콜태그는 전화가 오기 전 고객 맥락을 확인하고, 통화가 끝난 뒤 고객 상태·메모·일정·문자를 처리하며, 필요한 시점의 후속문자와 고객 그룹 단체문자까지 연결하는 Android 고객관리 앱이다.

> 전화 한 통을 고객관리 행동으로 끝냅니다.

기본 전화 앱을 교체하지 않으며 통화녹음·AI 요약 앱과 공존한다.

---

## 2. 구독 기준

| 상품 | 월 가격 | 기능 |
|---|---:|---|
| 전화관리 | 1,900원 | 고객·통화·상태·메모·일정·통계 |
| 문자자동화 | 990원 | 템플릿·자동·수동·예약·그룹·단체문자 |
| 통합 이용 | 2,500원 | 전화와 문자의 전체 기능 |

현재 개발 빌드 권한과 실제 결제·영수증·구독 만료·환불 처리는 구분한다.

---

## 3. 핵심 흐름

```text
전화 수신 전 고객 맥락 확인
→ 통화
→ 통화 종료 정리
→ 상태·메모·다음 할 일 저장
→ 즉시 문자 또는 후속문자
→ 고객 타임라인 반영
```

---

## 4. 전화·고객·일정

- 통화 종료 큰 정리창
- 고객 상태·통화 결과·메모
- 다음 할 일 종류와 시각
- 일정 추가·변경·완료·다시 열기·삭제
- 고객 상세 핵심 행동 `전화 / 일정 추가 / 문자`
- 고객 타임라인에 통화·메모·일정·문자 반영

일정 연결 문자:

```text
없음
지금 안내문자
일정 하루 전
일정 시간
일정 완료 후
```

일정 상태는 실제 발송 직전에 다시 확인한다.

---

## 5. 문자 자동화

문자 유형:

```text
수신 / 발신 / 부재중 / 후속 / 수동 / 캠페인
```

지원 변수:

```text
{고객명}
{전화번호}
{통화일자}
{통화시간}
{내이름}
{상호명}
{다음일정}
```

- 템플릿 저장·수정·복제·삭제
- 즐겨찾기·검색·최근 사용
- 기본 템플릿 지정
- 미지원·미치환 변수 발송 차단
- 이미지 첨부 템플릿
- 수동 이미지 문자와 사용자 확인형 예약 MMS

자동 문자와 캠페인은 현재 텍스트 전용이다. 이미지 문자는 기본 메시지 앱에서 사용자가 최종 발송한다.

---

## 6. 문자 안전 정책

### 발송 제외

- 자동문자 제외
- 전체 문자 제외
- 수신·발신·부재중·후속 유형별 제외

제외 건은 `FAILED`가 아니라 `SKIPPED`로 기록한다.

### 중복발송 방지

- 같은 통화의 같은 목적 문자 한 번
- 같은 일정의 활성 후속문자 한 건
- 같은 캠페인의 같은 번호 한 번
- 제한 시간 안 동일 템플릿·본문 차단
- 예약·즉시문자 시점 충돌 차단

### 발송 직전 재검사

- 문자 이용 권한
- SMS 권한
- 발송 제외
- 중복방지
- 미치환 변수
- 일정 생명주기
- 업무시간
- 활성 SIM
- 캠페인 상태와 캠페인 SIM

---

## 7. 그룹과 단체문자

그룹:

- 수동 그룹
- 상태 스마트 그룹
- 미접촉 기간 그룹
- 미완료 일정 그룹
- 거래·미거래 그룹

캠페인:

- 최대 500명
- 고객별 변수 치환
- 중복·제외·번호·변수 오류 개별 건너뜀
- 4초 간격 순차 예약
- 수신자별 예정·진행·완료·실패·건너뜀·취소 상태
- 일시정지·재개
- 실패 대상 재시도
- 한 시점에 캠페인 하나만 발송
- 통신 실패 3회 연속 시 자동 일시정지

캠페인 생성 시 SIM ID를 저장하고 예약 실행과 실제 `SmsManager` 호출 직전에 회선을 다시 검사한다.

---

## 8. 예약·정합성 복구

앱 시작·재부팅·업데이트 시 미완료 문자 작업을 점검한다.

- 미래 예약 재등록
- 30분 이내 지연 예약 순차 복구
- 30분 초과 지연 자동 발송 차단
- 멈춘 `READY` 안전 복구
- 불명확한 `SENDING` 자동 재발송 금지
- 일시정지 캠페인 자동 재개 금지

DB 정합성 복구:

- 연결 캠페인·수신자가 없는 고아 작업 차단
- 문자 작업이 없는 진행 수신자 실패 전환
- 삭제 고객의 수동 그룹 참조 정리
- 최종 상태 PendingIntent 정리
- 늦은 SMS 콜백이 최종 상태를 덮어쓰지 못하도록 차단
- 캠페인 삭제 전 남은 알람·작업 안전 정리

## 9. 앱 상태 진단

경로:

```text
계정 및 개인정보
→ 앱 상태 진단
```

- 권한과 활성 SIM
- 선택 회선 유효성
- 문자 작업 상태와 지난 예약
- 캠페인 수신자 연결 누락과 상태 불일치
- 고아 캠페인 작업
- 삭제 고객 그룹 참조
- 이미지 파일 누락
- 최근 예약 복구·정합성 복구 결과
- 실제 단말 E2E 체크리스트

복사 가능한 진단 정보에는 고객명·전화번호·문자 본문을 포함하지 않는다.

## 10. 앱 데이터 백업·복원

경로:

```text
계정 및 개인정보
→ 백업 및 복원
```

### 파일

- 확장자 `.ctbackup`
- CallTag 전용 `CTBK` 헤더
- PBKDF2-HMAC-SHA256
- AES-256-GCM
- 암호화된 ZIP 내부 패키지

### 포함

- CallTag 전용 SQLite DB
- 문자자동화·회선 설정
- 템플릿과 기본 템플릿 지정
- 발송 제외 정책
- 일정 문자 연결 설정
- 앱 전용 템플릿 이미지

### 제외

- 로그인 세션과 인증 토큰
- 구독·결제·영수증 상태
- 임시 SMS 콜백 상태
- 진단 로그와 캐시

### 복원 기준

- 현재 데이터와 병합하지 않고 백업 시점 데이터로 교체
- 복원 전에 현재 데이터를 내부 롤백 스냅샷으로 보존
- 파일 경로·크기·SHA-256·AES 인증 태그 검사
- 현재 앱보다 새 버전 백업 차단
- DB 마이그레이션과 `PRAGMA quick_check`
- 복원 후 정합성 복구와 예약 복구
- 실패 시 기존 데이터로 자동 롤백

백업 암호는 앱에 저장하지 않는다. 암호를 잊으면 복원할 수 없다.

## 11. 데이터 저장과 보호

```text
calltag.db             고객·통화·상태·일정
calltag_messages.db    문자 작업·발송내역
calltag_groups.db      수동·스마트 그룹
calltag_campaigns.db   캠페인·수신자·회선·일시정지
calltag_task_types.db  일정 종류
calltag_pending.db     미정리 통화
```

기존 데이터를 초기화하지 않는다. DB 변경 시 보존 마이그레이션을 작성한다.

현재 구현하지 않는 기능:

- CSV·XLSX
- 고객 목록 외부 반출
- 캠페인 결과표
- 범용 연락처 파일
- 외부 CRM 이전 형식

데이터 내보내기는 추후 별도 유료 기능이다. 백업·복원과 합치지 않는다.
