## 1. 제품 정의

콜태그는 전화가 오기 전 고객 맥락을 확인하고, 통화가 끝난 뒤 고객 상태·메모·일정·문자를 한 번에 처리하며, 이후 후속문자까지 연결하는 Android 고객관리 앱이다.

> 전화 한 통을 고객관리 행동으로 끝냅니다.

기본 전화 앱을 교체하지 않으며 에이닷의 녹음·AI 요약과 공존한다.

---

## 2. 구독

| 상품 | 월 가격 | 기능 |
|---|---:|---|
| 전화관리 | 1,900원 | 고객·통화·상태·메모·일정·통계 |
| 문자자동화 | 990원 | 템플릿·자동·수동·예약·단체문자 |
| 통합 이용 | 2,500원 | 전화와 문자의 전체 기능 및 연결 자동화 |

APK는 하나이며 구매 권한으로 기능을 나눈다.

---

## 3. 핵심 흐름

```text
전화 수신 전
→ 연락처 이름에서 고객명 + 핵심 메모 확인
→ 통화
→ 통화 종료 큰 정리창
→ 고객 상태·메모·다음 할 일 저장
→ 즉시 문자 또는 후속문자
→ 고객 타임라인 반영
```

`전화정보 고객표시`라는 기술 메뉴와 긴 설정 화면은 제거한다. 최초 실행 시 Android 권한창을 순서대로 요청하고 홈으로 진입한다.

---

## 4. 통화 종료 화면

통화 종료 후 큰 상세 정리창을 기본으로 사용한다.

- 고객명
- 고객 상태 드롭다운
- 통화 결과
- 통화 메모
- 다음 할 일 종류와 시각
- 문자 템플릿
- 치환된 실제 문자 내용
- 후속문자 사용 여부와 시점
- 저장만 하기
- 저장하고 문자 보내기

작은 알림은 큰 정리창을 열기 위한 보조 수단이다.

---

## 5. 문자 자동화

문자 홈은 네 유형으로 나눈다.

```text
수신 / 발신 / 부재중 / 후속
```

`3일 뒤 후속문자`라는 기능명은 사용하지 않는다. 기능명은 `후속문자`, 시점은 `1일 후 / 3일 후 / 7일 후 / 직접 선택`으로 표시한다.

---

## 6. 저장형 템플릿

콜링크처럼 여러 문자 템플릿을 저장하고 재사용한다.

- 저장
- 수정
- 복제
- 삭제
- 즐겨찾기
- 최근 사용
- 검색
- 카테고리
- 이미지
- 자동화 기본 템플릿 지정

지원 변수:

```text
{고객명}
{전화번호}
{통화일자}
{통화시간}
{내이름}
{상호명}
{다음일정}
```

미지원 변수와 미치환 변수가 남으면 발송을 차단한다. 실제 고객 데이터로 미리보기를 제공한다.

---

## 7. 고객 상세

상단 행동:

```text
전화 / 일정 추가 / 문자
```

상태 변경은 고객명 옆 상태 배지 드롭다운으로 이동한다.

문자 버튼 흐름:

```text
템플릿 선택
→ 치환 미리보기
→ 수정
→ 지금 보내기 / 예약 / 후속문자
```

---

## 8. 일정과 문자

일정 추가에서 연결 문자를 선택한다.

- 없음
- 지금 안내문자
- 일정 하루 전
- 일정 시간
- 일정 완료 후

연결 문자는 후속문자로 저장한다. 일정 변경·완료·삭제 시 연결 후속문자도 함께 변경·발송·취소한다.

---

## 9. 문자 발송 제외

전화 고객관리 제외와 문자 발송 제외를 구분한다.

- 자동문자 제외
- 전체 문자 제외
- 특정 유형 제외: 수신·발신·부재중·후속

전체 문자 제외 고객에게는 수동·자동·예약·단체문자를 모두 보내지 않는다.

---

## 10. 중복발송 방지

- 같은 통화에서 같은 목적 문자 한 번
- 자동발송과 정리창 수동발송 병합
- 같은 일정의 활성 후속문자 한 건
- 같은 번호가 여러 그룹에 있어도 캠페인당 한 번
- 최근 동일 템플릿·본문 발송 제한
- 실패 문자는 성공 중복으로 처리하지 않음

중복 차단 사유와 마지막 발송 시각을 표시한다.

---

## 11. 그룹과 단체문자

고객 그룹을 만든 뒤 그룹을 단체문자 대상으로 사용한다.

그룹:

- 수동 그룹
- 고객 상태·최근 연락·일정·관리공백 등을 이용한 스마트 그룹

단체문자:

```text
그룹 선택
→ 템플릿 선택
→ 수신자별 치환 미리보기
→ 중복번호 제거
→ 발송 제외 제거
→ 번호 오류 제거
→ 최종 인원 확인
→ 즉시 또는 예약 순차발송
```

성공·실패·건너뜀을 수신자별로 기록하며 실패 대상만 재발송할 수 있다.

## 13. 삼성 리마인더와 차별점

> 리마인더는 할 일을 알려준다. 콜태그는 전화가 끝난 뒤 해야 할 일을 실제로 처리한다.

차별점:

- 통화 이벤트 감지
- 고객 상태와 상담 이력
- 수신·발신·부재중 자동문자
- 저장형 템플릿과 변수 치환
- 일정 연동 후속문자
- 상태·통화·일정 변화에 따른 자동 취소
- 발송 제외와 중복방지
- 그룹·단체문자
- 통화·문자·일정 통합 타임라인

---

## 14. 개발 우선순위

1. 기술 설정 화면 제거와 통화 종료 큰 정리창
2. 수신·발신·부재중·후속 구조
3. 저장형 템플릿과 변수 검증
4. 문자 발송 제외와 중복방지
5. 고객 상세 문자와 일정 연동 후속문자
6. 그룹과 단체문자
7. 이미지 MMS, 회선별 규칙, 결제, 웹 동기화

---

## 15. 성공 기준

- 통화 종료 후 큰 정리창에서 고객관리와 문자를 함께 처리한다.
- 템플릿은 앱 재실행 후에도 저장돼 있다.
- 모든 변수는 실제 값으로 치환된다.
- 제외 고객에게 잘못 발송되지 않는다.
- 같은 통화·일정·그룹에서 중복 발송되지 않는다.
- 고객 상세와 일정에서 바로 문자를 보낼 수 있다.
- 단체문자는 중복·제외·오류 번호를 제거한 최종 대상만 발송한다.
- 전화·메모·상태·일정·문자가 같은 고객 타임라인에 연결된다.
