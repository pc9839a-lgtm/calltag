## 1. 제품 정의

콜태그는 전화가 오기 전 고객 맥락을 확인하고, 통화가 끝난 뒤 고객 상태·메모·일정·문자를 한 번에 처리하며, 이후 후속문자와 필요한 고객 대상 단체문자까지 연결하는 Android 고객관리 앱이다.

> 전화 한 통을 고객관리 행동으로 끝냅니다.

기본 전화 앱을 교체하지 않으며 에이닷 등의 통화녹음·AI 요약 기능과 공존한다.

---

## 2. 구독

| 상품 | 월 가격 | 기능 |
|---|---:|---|
| 전화관리 | 1,900원 | 고객·통화·상태·메모·일정·통계 |
| 문자자동화 | 990원 | 템플릿·자동·수동·예약·그룹·단체문자 |
| 통합 이용 | 2,500원 | 전화와 문자의 전체 기능 및 연결 자동화 |

APK와 계정은 하나이며 구매 권한으로 기능을 나눈다.

현재 개발 빌드의 기능 접근 권한과 실제 운영 결제는 구분한다. 실제 결제, 영수증 검증, 구독 만료·복원·환불 상태는 출시 전 별도 구현이 필요하다.

---

## 3. 핵심 흐름

```text
전화 수신 전
→ 연락처 이름에서 고객명 + 핵심 메모 확인
→ 통화
→ 통화 종료 큰 정리창
→ 고객 상태·메모·다음 할 일 저장
→ 즉시 문자 또는 후속문자
→ 고객 타임라인 반영
```

`전화정보 고객표시` 같은 내부 기술 용어와 긴 설정 화면을 사용자 핵심 흐름으로 노출하지 않는다. 최초 실행에서는 필요한 Android 권한창을 순서대로 요청하고 홈으로 진입한다.

---

## 4. 통화 종료 화면

통화 종료 후 큰 상세 정리창을 기본으로 사용한다.

- 고객명
- 고객 상태 드롭다운
- 통화 결과
- 통화 메모
- 다음 할 일 종류와 시각
- 문자 템플릿
- 치환된 실제 문자 내용
- 후속문자 사용 여부와 시점
- 저장만 하기
- 저장하고 문자 보내기

작은 알림은 큰 정리창을 열기 위한 보조 수단이다.

---

## 5. 문자 자동화

문자 기능은 네 유형으로 나눈다.

```text
수신 / 발신 / 부재중 / 후속
```

기능명은 `후속문자`로 통일하고 시점은 `1일 후 / 3일 후 / 7일 후 / 직접 선택 / 일정 전 / 일정 시간 / 일정 완료 후`로 표시한다.

---

## 6. 저장형 템플릿

여러 문자 템플릿을 저장하고 반복 사용한다.

- 저장
- 수정
- 복제
- 삭제
- 즐겨찾기
- 최근 사용
- 검색
- 이미지
- 자동화 기본 템플릿 지정

지원 변수:

```text
{고객명}
{전화번호}
{통화일자}
{통화시간}
{내이름}
{상호명}
{다음일정}
```

미지원 변수와 미치환 변수가 남으면 발송을 차단한다. 고객별 실제 데이터로 문구를 치환한다.

이미지 템플릿은 수동 문자와 사용자 확인형 예약 문자에 사용한다. 이미지 문자는 기본 메시지 앱 작성창을 열며 사용자가 최종 전송을 실행한다. 현재 자동발송 기본 템플릿과 단체문자는 텍스트 전용이다.

---

## 7. 고객 상세

상단 행동:

```text
전화 / 일정 추가 / 문자
```

상태 변경은 고객명 옆 상태 배지 드롭다운에서 처리한다.

문자 버튼 흐름:

```text
템플릿 선택
→ 고객별 치환
→ 수정
→ 지금 보내기 또는 예약
```

---

## 8. 일정과 문자

일정 추가에서 연결 문자를 선택한다.

- 없음
- 지금 안내문자
- 일정 하루 전
- 일정 시간
- 일정 완료 후

일정 변경·완료·삭제·다시 열기와 통화에 의한 자동 완료 시 연결 문자의 예약·발송·취소 상태를 함께 처리한다. 예약 실행 직전에도 일정 상태를 다시 검사한다.

---

## 9. 문자 발송 제외

전화 고객관리 제외와 문자 발송 제외를 구분한다.

- 자동문자 제외
- 전체 문자 제외
- 특정 유형 제외: 수신·발신·부재중·후속

전체 문자 제외 고객에게는 수동·자동·예약·단체문자를 보내지 않는다. 제외 건은 실패가 아니라 `SKIPPED`로 기록하고 사유를 남긴다.

---

## 10. 중복발송 방지

- 같은 통화에서 같은 목적 문자 한 번
- 자동발송과 정리창 수동발송 충돌 방지
- 같은 일정의 활성 후속문자 한 건
- 같은 캠페인에서 같은 번호 한 번
- 최근 동일 템플릿·본문 제한
- 실패·제외·취소는 성공 중복으로 처리하지 않음

중복 차단 사유와 기존 작업 상태를 발송내역에 표시한다.

---

## 11. 그룹과 단체문자

### 수동 그룹

고객을 직접 여러 명 선택해 고정 그룹으로 저장한다.

### 스마트 그룹

캠페인 실행 직전에 최신 고객 데이터로 조건을 다시 계산한다.

- 고객 상태
- 7일·30일·90일 이상 미접촉
- 미완료 일정 보유
- 거래 고객·미거래 고객

### 단체문자

```text
그룹 선택
→ 텍스트 템플릿 선택
→ 고객별 변수 치환
→ 중복번호·제외·번호 오류·변수 오류 검사
→ 수신자별 순차 예약
→ 상태·사유 확인
→ 실패 대상 재시도
```

- 캠페인당 최대 500명
- 수신자별 4초 간격 순차 예약
- 고객별 예정·진행·완료·실패·건너뜀·취소 상태
- 남은 발송 일괄 취소
- 실패·건너뜀·취소 고객 재시도
- 재시도 시 최신 고객 데이터로 다시 치환

## 13. 데이터 저장과 보호

현재 주요 로컬 저장소:

```text
calltag.db             고객·통화·상태·일정
calltag_messages.db    문자 작업·발송내역
calltag_groups.db      수동·스마트 그룹
calltag_campaigns.db   캠페인·수신자 상태
```

DB를 변경할 때 기존 데이터를 초기화하거나 삭제하지 않는다. 반드시 보존 마이그레이션과 복구 기준을 작성한다.

### 13.1 백업·복원

백업·복원은 향후 필수 기능으로 구현한다.

- 고객·상태·메모
- 통화 활동
- 일정
- 문자 템플릿과 이미지
- 발송 제외
- 그룹
- 캠페인과 발송내역
- 자동화·회선 설정

백업은 앱 장애·기기 변경·데이터 손상에 대비해 앱 데이터를 안전하게 보관하고 같은 앱으로 복원하는 기능이다.

### 13.2 데이터 내보내기

다음 기능은 현재 구현하지 않는다.

- CSV
- XLSX
- 고객 목록 외부 반출
- 캠페인 결과표 외부 반출
- 범용 연락처 파일
- 외부 CRM 이전용 데이터

데이터 내보내기는 추후 별도 유료 기능으로 기획한다. 사용자의 별도 승인 전 현재 패치 범위에 넣지 않는다. 백업 파일을 일반 데이터 내보내기 파일처럼 사용하는 기능도 만들지 않는다.

## 17. 성공 기준

- 통화 종료 후 큰 정리창에서 고객관리와 문자를 함께 처리한다.
- 템플릿과 이미지가 앱 재실행 후에도 유지된다.
- 모든 변수는 실제 값으로 치환된다.
- 제외 고객에게 잘못 발송되지 않는다.
- 같은 통화·일정·캠페인에서 중복 발송되지 않는다.
- 고객 상세와 일정에서 바로 문자를 만들 수 있다.
- 단체문자는 중복·제외·오류·변수 문제를 수신자별로 분리한다.
- 성공·실패·건너뜀·취소 상태를 실제 문자 작업과 동기화한다.
- 앱 종료·재부팅·업데이트 후에도 미발송 작업이 중복 없이 복구된다.
- 백업과 복원이 기존 데이터를 파괴하지 않는다.
- 실제 운영 결제와 권한이 가격표와 일치한다.
