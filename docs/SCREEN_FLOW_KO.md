# 콜태그 화면 흐름

## 1. 최초 실행

1. 앱 소개
2. 개인정보 처리 안내
3. 전화 상태·통화기록 권한 설명
4. 필수 권한 요청
5. 업무시간과 최소 통화시간 설정
6. 홈 진입

## 2. 통화 수신 전 고객 팝업

MVP 1차에서는 통화 중 시스템 화면 위 팝업보다 통화 종료 후 안정적인 처리를 우선한다.

후속 단계에서 기존 고객 전화 수신 시 다음 정보를 표시한다.

- 고객명
- 신규·기존·휴면 상태
- 마지막 상담 요약
- 진행 중인 상담건
- 오늘 확인할 내용

## 3. 통화 종료 후 처리

### 미등록 번호

1. 통화 종료 감지
2. 전화번호와 통화시간 표시
3. 분류 선택
   - 신규 문의
   - 기존 고객 연결
   - 거래처
   - 개인 전화
   - 제외
4. 신규 문의 선택 시 이름·문의 분야 입력
5. 상담 결과 선택
6. 다음 행동과 날짜 선택
7. 저장

### 등록 고객

1. 고객 카드와 마지막 상담 표시
2. 현재 상담건 선택 또는 새 상담건 생성
3. 상담 결과 선택
4. 다음 행동과 날짜 선택
5. 저장

## 4. 오늘 화면

우선순위 순으로 표시한다.

1. 기한이 지난 재연락
2. 오늘 다시 연락할 고객
3. 보내지 않은 자료
4. 정리하지 않은 통화
5. 내일 예정 업무

각 업무에는 `전화`, `문자`, `미루기`, `완료` 버튼을 제공한다.

## 5. 고객 화면

상단 필터:

- 전체
- 신규
- 상담 중
- 기존
- 휴면
- 제외

고객 상세:

- 기본정보
- 관계 상태
- 진행 중 상담건
- 상담 이력
- 다음 업무
- 거래 완료 이력
- 수신거부·제외 설정

## 6. 상담 화면

상담건 상태별 보기:

- 신규 문의
- 상담 중
- 자료·견적 발송
- 검토 중
- 재연락
- 계약 예정
- 완료
- 보류·종료

## 7. 전체 화면

- 업무시간
- 최소 통화시간
- 휴면 기준일
- 상담 결과 항목
- 다음 행동 항목
- 제외번호
- 개인정보 처리 안내
- 데이터 초기화
- 계정과 결제: 후속 단계
