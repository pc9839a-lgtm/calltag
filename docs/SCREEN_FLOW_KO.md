# 콜태그 화면 흐름

## 1. 최초 실행

1. 앱 소개
2. 개인정보 처리 안내
3. 전화 상태·통화기록 권한 설명
4. 필수 권한 요청
5. 홈 진입

## 2. 통화 종료 후 처리

### 미등록 번호

1. 통화 종료 감지
2. 전화번호와 통화시간 표시
3. 고객 구분 선택
   - 신규
   - 기존
   - 제외
4. 상담 결과 선택
5. 다음 일정 선택
6. 저장

### 등록 고객

1. 기존 고객명과 현재 상태 표시
2. 상담 결과 선택
3. 다음 일정 선택
4. 저장
5. 결과에 따라 상태 갱신
   - 관심·견적·재연락: `상담 중`
   - 거래 완료: `기존`

## 3. 홈 화면

우선순위 순으로 표시한다.

1. 기한이 지난 일정
2. 오늘 일정
3. 신규 고객 수
4. 빠른 메뉴
   - 고객 추가
   - 고객 목록
   - 캘린더

일정 카드는 `전화`, `완료`를 제공하고 고객 상세로 연결한다.

## 4. 고객 화면

상단 필터:

- 전체
- 신규
- 상담 중
- 기존

고객 카드를 누르면 고객 상세로 이동한다.

## 5. 고객 상세

고객 상세는 고객의 현재 상태와 시간 흐름을 한 화면에서 관리한다.

- 고객명·전화번호
- 현재 상태
- 전화
- 일정 추가
- 상태 변경
- 등록 일정
- 메모
- 활동 기록

### 상태 변경

상태 배지 또는 `상태 변경`을 누르면 다음 상태로 언제든 변경할 수 있다.

- 신규
- 상담 중
- 기존
- VIP
- 휴면

변경된 상태는 즉시 고객 카드와 캘린더에 반영한다. 변경 전·후 상태는 활동 기록에 남긴다.

### 일정 관리

고객 상세에서 다음 일정 유형을 추가한다.

- 전화하기
- 방문·미팅
- 자료 보내기
- 직접 입력

등록된 일정은 날짜·시간 변경, 완료, 다시 열기, 삭제가 가능하다.

## 6. 캘린더 화면

기존 `상담` 탭은 `캘린더` 탭으로 대체한다.

### 월간 캘린더

- 이전 달·다음 달 이동
- 오늘 날짜 표시
- 선택 날짜 강조
- 날짜별 일정 개수 표시
- 모든 일정이 완료된 날짜는 완료 표시

### 날짜별 일정

날짜를 누르면 해당 날짜의 일정이 아래에 표시된다.

각 일정에 표시할 정보:

- 고객명
- 현재 고객 상태
- 일정 내용
- 시간
- 예정·완료 상태

제공 행동:

- 일정 추가
- 날짜·시간 변경
- 완료
- 다시 열기
- 삭제
- 고객 상세 이동

### 캘린더에서 일정 추가

1. 날짜 선택
2. `+ 일정 추가`
3. 고객 선택
4. 일정 종류 선택
5. 시간 선택
6. 저장

신규 고객에게 일정을 추가하면 고객 상태를 `상담 중`으로 전환하고 활동 기록에 남긴다.

## 7. 활동 흐름

고객별 활동 기록에는 다음 이벤트가 시간순으로 누적된다.

- 수신·발신 통화
- 상담 결과
- 고객 상태 변경
- 일정 등록
- 일정 변경
- 일정 완료

단순 숫자 요약이 아니라 고객 상태와 다음 행동이 어떻게 변했는지 확인할 수 있어야 한다.

## 8. 전체 화면

- 통화 후 처리 테스트
- 통화 감지 켜기·끄기
- 제외번호
- 향후 데이터·계정 설정
