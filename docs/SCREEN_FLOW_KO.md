# 콜태그 화면 흐름

기준일: 2026-07-30

## 1. 서비스 진입

### Android 앱

1. 앱 소개
2. 페이지로 계정 로그인 또는 시작
3. 개인정보 처리 안내
4. 전화 상태·통화기록 권한 설명
5. 필수 권한 요청
6. 홈 진입

### 웹

1. `calltag.pagero.kr` 접속
2. 페이지로 공통 계정 로그인
3. 연결된 Android 기기 확인
4. 홈 진입

콜링크 계정이 이미 있으면 같은 계정으로 로그인하며 별도 회원가입을 요구하지 않는다.

## 2. 고객 추가

고객 추가의 기본 흐름은 직접 입력이 아니라 최근 통화 선택이다.

1. 홈 또는 고객 화면에서 `고객 추가`
2. 최근 통화 목록 표시
3. 번호·연락처 이름·통화일시 확인
4. 이미 등록된 번호는 `등록됨` 표시 또는 목록 제외
5. 미등록 번호 선택
6. 고객명·초기 상태 확인
7. 저장
8. 고객 상세 이동

보조 흐름:

- `직접 입력`을 눌러 고객명과 전화번호 입력
- 웹에서도 Android가 동기화한 최근 통화 목록을 동일하게 사용

## 3. 통화 종료 후 처리

### 미등록 번호

1. 통화 종료 감지
2. 전화번호와 통화시간 표시
3. 고객 구분 선택
   - 신규
   - 기존 연결
   - 제외
4. 상담 결과 선택
5. 다음 일정 선택
6. 저장
7. 앱 로컬 저장
8. 로그인·네트워크 연결 시 서버와 웹에 동기화

### 등록 고객

1. 기존 고객명과 현재 상태 표시
2. 마지막 상담·예정 일정 표시
3. 상담 결과 선택
4. 다음 일정 선택
5. 저장
6. 결과에 따라 상태 갱신
   - 관심·견적·재연락: `상담 중`
   - 거래 완료: `기존`
7. 앱·웹 고객 타임라인에 반영

## 4. 홈 화면

우선순위 순으로 표시한다.

1. 통화 감지 상태
2. 기한이 지난 일정
3. 오늘 일정
4. 신규 고객 수
5. 주 행동 `최근 통화에서 고객 추가`
6. 보조 행동
   - 고객 목록
   - 캘린더
7. 다음 연락 목록

일정 카드는 `전화`, `완료`를 제공하고 고객 상세로 연결한다.

웹 홈은 다음 항목을 함께 표시한다.

- 미정리 통화
- 보내기로 했지만 발송하지 않은 문자·자료
- 콜링크 발송 실패

## 5. 고객 화면

상단 필터:

- 전체
- 신규
- 상담 중
- 기존
- 후속 웹 확장: VIP·휴면

고객 카드를 누르면 고객 상세로 이동한다.

웹에서는 이름·전화번호·메모 검색과 최근 연락일 정렬을 추가한다.

## 6. 고객 상세

고객 상세는 고객의 현재 상태와 시간 흐름을 한 화면에서 관리한다.

- 고객명·전화번호
- 현재 상태
- 전화
- 문자
- 일정 추가
- 상태 변경
- 등록 일정
- 메모
- 활동 기록

활동 기록에는 앱 구분보다 고객의 시간 흐름을 우선해 다음을 통합 표시한다.

- 수신·발신 통화
- 상담 결과
- 상태 변경
- 일정 등록·변경·완료
- 콜링크 문자 발송·실패

### 상태 변경

상태 배지 또는 `상태 변경`을 누르면 다음 상태로 언제든 변경할 수 있다.

- 신규
- 상담 중
- 기존
- VIP
- 휴면

변경된 상태는 앱·웹 고객 카드와 캘린더에 반영한다. 변경 전·후 상태는 활동 기록에 남긴다.

### 일정 관리

고객 상세에서 다음 일정 유형을 추가한다.

- 전화하기
- 방문·미팅
- 자료 보내기
- 직접 입력

선택지는 일반 텍스트 목록이 아니라 배경·테두리·눌림 상태가 있는 실제 버튼으로 표시한다.

등록된 일정은 날짜·시간 변경, 완료, 다시 열기, 삭제가 가능하다.

## 7. 캘린더 화면

### 월간 캘린더

- 이전 달·다음 달 이동
- 오늘 날짜 표시
- 선택 날짜 강조
- 날짜별 일정 개수 표시
- 모든 일정이 완료된 날짜는 완료 표시

### 날짜별 일정

날짜를 누르면 해당 날짜의 일정이 아래에 표시된다.

표시 정보:

- 고객명
- 현재 고객 상태
- 일정 내용
- 시간
- 예정·완료 상태

제공 행동:

- 일정 추가
- 날짜·시간 변경
- 완료
- 다시 열기
- 삭제
- 고객 상세 이동

### 캘린더에서 일정 추가

1. 날짜 선택
2. `+ 일정 추가`
3. 고객 선택
4. 일정 종류를 버튼형 목록에서 선택
5. 시간 선택
6. 저장
7. 앱·웹 캘린더에 동기화

신규 고객에게 일정을 추가하면 고객 상태를 `상담 중`으로 전환하고 활동 기록에 남긴다.

웹에서는 월간·주간·목록 보기를 제공하고 날짜·시간 드래그 변경은 후속 단계에서 지원한다.

## 8. 콜링크 문자 연결

### 앱에서 문자

1. 고객 상세 또는 일정에서 `문자`
2. 콜링크 설치 여부 확인
3. 고객 상태·일정 종류에 맞는 템플릿 표시
4. 콜링크에서 내용 확인
5. 발송
6. 발송 결과를 공통 고객 타임라인에 기록

### 웹에서 문자 요청

1. 고객 상세에서 `문자 보내기`
2. 콜링크 템플릿 선택
3. 내용 수정
4. 발송 요청 생성
5. 연결된 콜링크 Android 앱으로 전달
6. 앱에서 확인 후 발송
7. 성공·실패 결과를 웹과 콜태그에 반영

웹 브라우저가 일반 SMS를 직접 발송하지 않는다.

웹 기본 메뉴:

1. 홈

4. 통화·상담
5. 문자
6. 템플릿

### 통화·상담

- 최근 통화
- 미정리·정리 완료
- 수신·발신
- 통화시간
- 고객 연결
- 상담 결과
- 다음 일정

### 전체

- 계정
- 연결 기기
- 콜링크·콜태그 이용 상태
- 구독·결제
- 제외번호
- 데이터 내보내기
- 개인정보·탈퇴

## 10. 동기화 흐름

1. Android 앱에서 로컬 SQLite에 우선 저장
2. 로그인과 네트워크 상태 확인
3. 변경 데이터를 서버로 전송
4. 서버가 공통 고객·통화·일정 ID로 저장
5. 웹과 다른 연결 기기가 변경사항 수신
6. 충돌 발생 시 최신 수정과 활동 이력을 비교
7. 삭제·완료 충돌은 사용자에게 표시
