# 콜태그 v0.15.0 UX 안정화 기준

## 1. 고객 탭 상단 높이

고객 탭을 열었을 때 첫 번째 고객 카드가 화면 안에 보여야 한다.

상단 구성:

1. `고객` 제목과 `+ 추가` 버튼 한 줄
2. `목록 / 통계` 탭 한 줄
3. 고객 검색 한 줄
4. 상태·기간·상태 편집 한 줄
5. 고객 목록

제한:

- 전체 폭 고객 추가 버튼을 별도 행으로 두지 않는다.
- 상태 편집 버튼을 별도 행으로 두지 않는다.
- 목록 화면 상단 제어 영역은 약 145dp 이내로 유지한다.
- 고객 카드 사이 여백은 8dp를 기준으로 한다.

## 2. 통계의 목적

통계는 보기 좋은 숫자 모음이 아니라 영업자가 오늘 무엇을 처리해야 하는지 알려주는 화면이어야 한다.

### 업무 현황

- 전체 고객
- 오늘 실제 통화 고객
- 기한 초과 할 일
- 확인이 필요한 부재중·거절·미연결 통화

### 관리 공백

- 30일 이상 미접촉 고객
- 예정된 할 일이 없는 고객
- 첫 상태에 있으면서 다음 할 일이 없는 고객

### 실행 성과

- 최근 30일 할 일 완료율
- 완료 건수와 전체 도래 건수
- 최근 7일 일별 통화 추이
- 최근 7일 수신·발신·부재중·거절 구분

### 고객 분포

- 상태별 고객 수
- 상태별 고객 비율
- 사용자가 설정한 상태 색상 적용

### 할 일 분포

- 전화하기
- 미팅
- 자료 보내기
- 사용자 지정 할 일

각 종류의 남은 건수와 사용자가 설정한 색상을 표시한다.

## 3. 전화 수신 고객정보 알림 팝업

### 사용자 요구

전화가 올 때 보이는 것은 별도 오버레이 카드나 앱 화면이 아니라 Android 상단의 헤드업 알림 팝업이다.

### 기존 문제

- 앱이 열린 상태에서 실행된 Activity를 알림 팝업으로 오인했다.
- 기존 수신 알림 채널의 중요도는 생성 후 코드에서 변경해도 휴대전화 설정에 반영되지 않았다.
- 설정 화면과 실제 수신 서비스가 서로 다른 알림 채널을 확인해, 설정 완료로 보여도 실제 전화 팝업은 표시되지 않을 수 있었다.
- 오버레이 권한은 사용자가 요구한 상단 알림 팝업과 다른 기능이었다.

### v0.15.0 방식

- 수신정보 서비스가 호출되면 앱 화면 상태와 관계없이 즉시 알림을 게시한다.
- 전용 채널 ID는 `calltag_incoming_popup_v5`를 사용한다.
- 설정 화면과 실제 수신 서비스는 같은 채널을 확인한다.
- 채널 중요도는 `IMPORTANCE_HIGH`로 생성한다.
- 진동과 알림음을 활성화해 삼성 기기의 헤드업 팝업 조건을 강화한다.
- 알림 카테고리는 `CATEGORY_CALL`, 우선순위는 `PRIORITY_MAX`를 사용한다.
- `다른 앱 위에 표시`, 전체 화면 실행, 오버레이 코드는 사용하지 않는다.

### 표시 내용

- 고객명과 현재 상태
- 전화번호 또는 최근 메모 첫 줄
- 펼친 알림에서 상태와 최근 메모 전체
- 알림 선택 시 고객 상세 이동

### 필수 설정

1. 연락처 권한
2. 알림 권한
3. Android 수신정보 앱 역할
4. `전화 수신 고객정보 팝업` 채널 중요도 높음
5. 삼성 기기에서 해당 채널의 `팝업으로 표시` 허용

설정 화면의 `전화 수신 팝업 설정` 버튼은 해당 알림 채널 설정으로 직접 이동한다.

### 진단 상태

설정 화면의 최근 수신 확인 문구에는 다음 상태를 구분한다.

- 미등록 번호
- 제외번호
- 번호 미전달
- 알림 게시 성공
- 알림 채널 팝업 꺼짐
- 알림 게시 실패

## 4. 통화 종료 알림 팝업

통화 종료 후 정리 알림도 앱이 열려 있는지 확인하지 않고 별도 높은 중요도 채널에 게시한다.

전용 채널 ID는 `calltag_post_call_popup_v2`다.

- 수신 통화 종료
- 발신 통화 종료
- 부재중 전화
- 거절한 전화
- 발신 연결 안 됨

표시 기준:

- 통화 유형과 고객명
- 고객 상태 또는 최근 메모 첫 줄
- 펼친 알림에서 상태와 메모 전체
- 알림을 누르면 통화 정리 화면 이동
- 상단 배너가 사라져도 알림함에는 유지

설정 화면의 `통화 종료 팝업 설정` 버튼은 해당 알림 채널 설정으로 직접 이동한다.

## 5. 백그라운드 테스트

설정 화면에는 두 개의 테스트 버튼을 제공한다.

- `수신 팝업 테스트`
- `종료 팝업 테스트`

테스트 버튼을 누르면 앱을 뒤로 보낸 뒤 2초 후 알림을 게시한다. 앱이 열린 상태에서만 보이는 착시를 막고 실제 백그라운드 팝업을 확인하기 위한 방식이다.

## 6. 실기기 QA

### 고객 탭

- 360dp 너비에서 첫 고객 카드 노출
- 큰 글자 설정에서 필터 버튼 글자 잘림 없음
- 키보드가 열린 상태에서 검색 결과 갱신
- 목록·통계 전환 후 스크롤 정상

### 통계

- 고객 0명
- 할 일 0건
- 상태 추가 후 분포 반영
- 일정 종류 수정 후 색상·이름 반영
- 완료된 일정 포함 최근 30일 완료율 확인

### 수신·종료 알림 팝업

다음 상태에서 각각 두 테스트 버튼과 실제 등록 고객 전화를 확인한다.

1. 콜태그 화면이 열린 상태
2. 홈 화면 상태
3. 다른 앱 사용 중
4. 화면 잠금 상태
5. 콜태그 최근 앱에서 제거 상태

각 상태에서 상단 알림 팝업이 표시되는지 확인한다. 앱을 열어둔 상태에서만 표시되면 각 채널 설정의 `팝업으로 표시`, 무음·방해금지, 앱 알림 허용 상태를 먼저 확인한다.
