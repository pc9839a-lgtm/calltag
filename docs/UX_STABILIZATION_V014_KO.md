# 콜태그 v0.14.0 UX 안정화 기준

## 1. 고객 탭 상단 높이

고객 탭을 열었을 때 첫 번째 고객 카드가 화면 안에 보여야 한다.

상단 구성:

1. `고객` 제목과 `+ 추가` 버튼 한 줄
2. `목록 / 통계` 탭 한 줄
3. 고객 검색 한 줄
4. 상태·기간·상태 편집 한 줄
5. 고객 목록

제한:

- 전체 폭 고객 추가 버튼을 별도 행으로 두지 않는다.
- 상태 편집 버튼을 별도 행으로 두지 않는다.
- 목록 화면 상단 제어 영역은 약 145dp 이내로 유지한다.
- 고객 카드 사이 여백은 8dp를 기준으로 한다.

## 2. 통계의 목적

통계는 보기 좋은 숫자 모음이 아니라 영업자가 오늘 무엇을 처리해야 하는지 알려주는 화면이어야 한다.

### 업무 현황

- 전체 고객
- 오늘 실제 통화 고객
- 기한 초과 할 일
- 확인이 필요한 부재중·거절·미연결 통화

### 관리 공백

- 30일 이상 미접촉 고객
- 예정된 할 일이 없는 고객
- 첫 상태에 있으면서 다음 할 일이 없는 고객

### 실행 성과

- 최근 30일 할 일 완료율
- 완료 건수와 전체 도래 건수
- 최근 7일 일별 통화 추이
- 최근 7일 수신·발신·부재중·거절 구분

### 고객 분포

- 상태별 고객 수
- 상태별 고객 비율
- 사용자가 설정한 상태 색상 적용

### 할 일 분포

- 전화하기
- 미팅
- 자료 보내기
- 사용자 지정 할 일

각 종류의 남은 건수와 사용자가 설정한 색상을 표시한다.

## 3. 앱 종료 상태 수신 고객정보

### 기존 문제

Activity 직접 실행과 전체 화면 알림은 Android 백그라운드 실행 제한과 제조사 전화 앱 정책에 따라 앱이 화면에 있을 때만 보일 수 있다.

### v0.14.0 방식

`SYSTEM_ALERT_WINDOW` 권한과 `TYPE_APPLICATION_OVERLAY`를 사용해 전화 앱 위에 고객정보 카드를 직접 표시한다.

필수 설정:

1. 연락처 권한
2. 알림 권한
3. Android 수신정보 앱 역할
4. 다른 앱 위에 표시 권한

### 오버레이 표시 내용

- 콜태그 등록 고객 표시
- 고객명
- 전화번호
- 현재 상태 색상 태그
- 최근 메모 최대 3줄
- 최근 연락 시각
- 고객 상세 보기
- 닫기

### 종료 조건

- 전화 상태가 `IDLE`로 변경되면 자동 닫기
- 사용자가 닫기 버튼을 누르면 즉시 닫기
- 예외 상황에서는 60초 후 자동 닫기

### 실패 대체

다른 앱 위에 표시 권한이 없거나 오버레이 생성이 실패하면 메모가 포함된 높은 중요도 알림을 사용한다.

설정 화면의 최근 수신 확인 문구에는 다음 상태를 구분한다.

- 미등록 번호
- 제외번호
- 번호 미전달
- 오버레이 권한 없음
- 오버레이 표시 요청
- 알림 차단

## 4. 실기기 QA

### 고객 탭

- 360dp 너비에서 첫 고객 카드 노출
- 큰 글자 설정에서 필터 버튼 글자 잘림 없음
- 키보드가 열린 상태에서 검색 결과 갱신
- 목록·통계 전환 후 스크롤 정상

### 통계

- 고객 0명
- 할 일 0건
- 상태 추가 후 분포 반영
- 일정 종류 수정 후 색상·이름 반영
- 완료된 일정 포함 최근 30일 완료율 확인

### 수신 팝업

다음 상태에서 각각 테스트한다.

1. 콜태그 화면이 열린 상태
2. 홈 화면 상태
3. 다른 앱 사용 중
4. 화면 잠금 상태
5. 콜태그 최근 앱에서 제거 상태

등록 고객 번호로 전화하고 고객명·상태·메모가 전화 화면 위에 표시되는지 확인한다. 통화 종료 후 오버레이가 사라지는지도 확인한다.
