## 1. 최종 제품 정의

콜태그는 단순 전화 메모 앱, 리마인더 앱, 예약문자 앱이 아니다.

> **전화가 오기 전 고객 맥락을 확인하고, 통화가 끝난 뒤 고객 상태·메모·일정·문자를 한 번에 처리하며, 필요한 시점에 후속문자까지 이어주는 전화 기반 고객관리 앱**

기존 콜링크는 별도 앱이나 별도 제품명으로 출시하지 않는다. 콜링크에서 검증한 문자 템플릿·발송·예약 기능을 콜태그의 문자 모듈로 이전한다.

제품이 해결하는 실제 문제는 “다시 전화할 시간을 잊는다”가 아니다.

```text
전화가 끝남
→ 메모가 다른 앱에 흩어짐
→ 자료 문자를 나중으로 미룸
→ 재연락 일정을 만들지 않음
→ 예약문자를 만들어도 고객 상태가 바뀐 뒤 그대로 발송됨
→ 결국 고객을 놓침
```

콜태그는 이 흐름을 하나의 고객 기록과 자동화로 묶는다.

## 2. 제품명과 구독

앱은 **콜태그 하나**만 제공한다. APK와 계정도 하나다.

| 상품 | 월 구독료 | 핵심 범위 |
|---|---:|---|
| 전화관리 | 1,900원 | 고객·통화·상태·메모·일정·통계 |
| 문자자동화 | 990원 | 템플릿·자동·수동·예약·단체문자·발송내역 |
| 통합 이용 | 2,500원 | 전화관리와 문자자동화 전체 및 연결 자동화 |

개별 합계는 2,890원이며 통합 상품은 2,500원이다.

### 2.1 전화관리 구독

- 수신·발신·부재중·거절·미연결 통화 감지
- 전화번호 기준 고객 조회
- 고객 상태와 통화 결과
- 통화 메모
- 다음 할 일과 일정
- 고객별 타임라인
- 통계와 관리공백
- 연락처 표시명을 이용한 수신 전 핵심 메모 표시

### 2.2 문자자동화 구독

- 저장형 문자 템플릿
- 수신·발신·부재중·후속 자동화
- 고객별 수동 문자
- 즉시·예약·후속문자

- 발송내역과 실패 재시도

- 통화 종료 정리창에서 상태·메모·일정·문자 동시 처리
- 일정과 후속문자 연결
- 고객 상태와 후속문자 취소 조건 연결
- 고객 타임라인에 통화·일정·문자 통합
- 관리공백에서 전화·문자·일정 바로 실행

## 3. 제품 원칙

1. 기본 전화 앱을 교체하지 않는다.
2. 에이닷 통화녹음·AI 요약과 공존한다.
3. 전화 수신 중 일반 오버레이를 핵심 가치로 약속하지 않는다.
4. 전화가 오기 전 정보는 연락처 표시명 동기화를 기본으로 한다.
5. 통화 종료 후에는 큰 정리창을 기본 동작으로 사용한다.
6. 모든 문자는 사용자가 저장하거나 활성화한 규칙과 템플릿을 기준으로 발송한다.
7. 예약 시점이 됐더라도 발송 직전에 제외·중복·상태·일정을 다시 검사한다.
8. 자동문자와 수동문자가 같은 통화에서 두 번 발송되지 않아야 한다.
9. 일정과 후속문자는 서로 연결돼 변경·완료·삭제가 반영돼야 한다.
10. 단체문자는 그룹, 제외, 중복 제거, 발송 결과를 확인한 뒤 실행한다.

## 4. 최초 실행과 권한

사용자에게 `전화정보 고객표시`, `수신정보 앱`, `상세 오버레이 테스트` 같은 기술 용어와 긴 설정 화면을 보여주지 않는다.

### 4.1 최초 실행

```text
로그인 또는 회원가입
→ 연락처 읽기·수정 권한
→ 전화 상태·통화기록 권한
→ 문자 발송 권한
→ 알림 권한
→ 허용된 기능 활성화
→ 홈
```

앱이 권한을 대신 승인할 수는 없다. Android 시스템 권한창을 순서대로 열고 사용자가 허용한다.

### 4.2 권한 거절

복잡한 필수 설정 페이지로 강제 이동하지 않는다.

```text
전화·문자 자동화를 사용하려면 권한이 필요합니다.
[권한 허용]
```

`다시 묻지 않음`이면 앱 상세 설정으로 연결한다.

### 4.3 사용자 설정에 남길 항목

- 연락처 핵심 메모 표시 켜기·끄기
- 연락처 이름 원래대로 복원
- 통화 종료 정리창 켜기·끄기
- 수신·발신·부재중·후속 자동화
- 기본 발송 회선
- 업무시간
- 중복발송 제한
- 문자 발송 제외
- 알림

`전화정보 고객표시`라는 메뉴명과 별도 설명 화면은 사용하지 않는다.

## 5. 전화 수신 전 고객정보 표시

전화 앱 위 오버레이가 아니라 시스템 연락처 표시명을 미리 동기화한다.

```text
김민수 · 견적서 다시 발송
고객 4396 · 금요일 오전 전화
```

### 동작 기준

- 원본 Google·삼성 연락처를 직접 덮어쓰지 않는다.
- 콜태그 소유 연락처 레이어를 같은 번호와 결합한다.
- 기능을 끄면 콜태그 레이어만 제거한다.
- 이름 없는 고객은 `고객 + 번호 끝 네 자리`로 표시한다.
- 표시할 핵심 메모는 사용자가 고정하거나 자동 우선순위로 선택한다.
- 일정이 만료되면 오래된 일정 문구를 자동 제거한다.

사용자는 내부 구현을 설정할 필요가 없다.

## 6. 통화 종료 큰 정리창

정상 기본 흐름은 작은 알림만 남기는 것이 아니라 **통화 종료 직후 큰 상세 정리창을 표시하는 것**이다.

```text
통화 종료 감지
→ 큰 통화 정리창
→ 저장 또는 닫기
→ 미처리 시 홈과 알림에 유지
```

Android가 백그라운드 화면 실행을 막는 환경에서는 전체화면 알림을 보조 진입점으로 사용한다. 사용자가 알림을 누르면 동일한 큰 정리창이 열린다.

### 6.1 정리창 구성

```text
김민수
수신 통화 · 3분 24초

고객 상태
[진행 중 ▾]

통화 결과
[관심 있음] [견적 발송] [다시 연락]
[완료] [보류] [종료]

통화 메모
[견적서를 수정해 다시 보내기로 함]

다음 할 일
[자료 보내기 ▾]
[8월 3일 오전 10:00]

문자
[수신 템플릿 선택 ▾]
[실제 치환된 발송 내용]

후속문자
[사용 안 함 ▾]
또는 [3일 후 ▾]

[저장만 하기]
[저장하고 문자 보내기]
```

### 6.2 용어

기능명은 항상 **후속문자**로 표기한다.

- 잘못된 명칭: `3일 뒤 후속문자`, `지연문자`, `예약 후속문자`
- 올바른 구조: `후속문자` 아래에서 `1일 후 / 3일 후 / 7일 후 / 직접 선택`

## 7. 메인 정보 구조

하단 메뉴는 네 개로 고정한다.

```text
홈 / 고객 / 문자 / 일정
```

### 7.1 홈

- 정리하지 않은 통화
- 다시 연락할 고객
- 오늘 일정
- 기한 초과 일정
- 발송 예정 후속문자
- 실패 문자
- 관리공백 고객

### 7.2 고객

- 고객 목록과 통계
- 검색
- 상태·기간·그룹 필터
- 고객 상세
- 통화·상태·메모·일정·문자 통합 타임라인

### 7.3 문자

문자 홈 첫 화면은 네 자동화 유형을 가장 먼저 보여준다.

```text
수신 / 발신 / 부재중 / 후속
```

그 아래에 다음 메뉴를 둔다.

- 템플릿
- 그룹·단체문자
- 예약·후속문자
- 발송내역
- 발송 제외
- 회선·업무시간·중복방지 설정

### 7.4 일정

- 월간 캘린더
- 오늘·기한 초과·완료
- 고객·일정 종류 필터
- 일정에 연결된 문자 상태
- 일정 추가·변경·완료·삭제

## 8. 문자 자동화 네 유형

### 8.1 수신

전화를 받아 연결된 통화가 종료된 경우다.

- 자동발송 켜기·끄기
- 저장된 기본 템플릿 선택
- 발송 시점
- 업무시간
- 중복 제한
- 통화 종료 정리창에서 최종 확인 여부

### 8.2 발신

사용자가 전화를 걸어 연결된 통화가 종료된 경우다.

수신과 별도 템플릿·규칙을 사용한다.

### 8.3 부재중

받지 못한 수신 전화와 사용자가 거절한 전화를 포함한다.

- 부재중·거절 내부 구분은 저장
- 사용자 메뉴는 `부재중` 하나로 통합
- 설정에 따라 즉시 자동발송 가능

### 8.4 후속

통화 종료 직후가 아니라 고객·통화·일정에 연결해 나중에 발송하는 문자다.

- 1일 후
- 3일 후
- 7일 후
- 날짜·시간 직접 선택
- 일정 전·일정 시간·일정 완료 후
- 조건이 사라지면 자동 취소

## 9. 저장형 템플릿

문자 템플릿은 콜링크처럼 앱에 저장돼야 한다. 매번 자동화 설정창에서 문구 하나만 덮어쓰는 구조로 만들지 않는다.

### 9.1 템플릿 기능

- 새 템플릿 저장
- 제목과 내용 수정
- 복제
- 삭제
- 즐겨찾기
- 최근 사용
- 검색
- 분류
- 이미지 첨부
- 기본 회선 또는 회선별 버전
- 수신·발신·부재중·후속 기본 템플릿 지정

### 9.2 템플릿 분류

자동화 기본 템플릿:

- 수신
- 발신
- 부재중
- 후속

사용자 공용 템플릿 예시:

- 견적서 발송
- 예약 확정
- 자료 전달
- 다시 연락
- 계약 완료
- 주소 안내

같은 템플릿을 통화 종료 정리창, 고객 상세, 일정 추가, 그룹문자에서 재사용한다.

### 9.3 변수

지원 변수:

```text
{고객명}
{전화번호}
{통화일자}
{통화시간}
{내이름}
{상호명}
{다음일정}
```

규칙:

- 저장 전 지원하지 않는 변수 검사
- 발송 전 미치환 변수가 남아 있으면 차단
- 고객명이 없으면 `고객`으로 대체
- `{다음일정}`이 없으면 경고 후 사용자가 수정하거나 빈값 허용 여부 선택
- 편집 화면에서 실제 고객 데이터로 미리보기

```text
작성
안녕하세요, {고객명}님. {다음일정}에 다시 연락드리겠습니다.

미리보기
안녕하세요, 김민수님. 8월 3일 오전 10시에 다시 연락드리겠습니다.
```

## 10. 고객 상세 흐름

고객 상세 상단 기본 행동은 다음으로 변경한다.

```text
전화 / 일정 추가 / 문자
```

`상태 변경`은 별도 행동 버튼을 차지하지 않는다. 고객명 옆 상태 배지를 누르면 드롭다운을 연다.

```text
김민수    [진행 중 ▾]
```

### 10.1 고객 상세 문자

```text
문자 선택
→ 저장된 템플릿 선택
→ 변수 치환 미리보기
→ 내용·이미지 수정
→ 지금 보내기 / 예약 / 후속문자
→ 발송
```

빈 작성창을 먼저 보여주지 않는다. 최근 사용과 즐겨찾기 템플릿을 우선 노출한다.

## 11. 일정과 후속문자 연결

일정 추가는 리마인더 생성으로 끝나지 않는다.

```text
다음 할 일
[자료 보내기 ▾]

일정
[8월 3일 오전 10:00]

연결 문자
[없음 ▾]
[지금 안내문자]
[일정 하루 전]
[일정 시간]
[일정 완료 후]
```

연결된 문자는 `후속문자`로 저장한다.

### 일정 변경

- 연결된 후속문자 시간도 함께 변경할지 확인
- 기본값은 함께 변경
- 사용자가 분리 가능

### 일정 완료

- 완료 후 발송 규칙이면 발송
- 일정 전·일정 시간 후속문자가 아직 남아 있으면 자동 취소

### 일정 삭제

- 연결된 미발송 후속문자 자동 취소
- 취소 사유 저장

## 12. 문자 발송 제외

제외 기능은 전화 고객관리 제외와 문자 발송 제외를 구분한다.

### 12.1 제외 수준

1. **자동문자 제외**  
   자동화와 후속문자는 보내지 않지만 사용자가 수동으로 발송할 수 있다.

2. **전체 문자 제외**  
   자동·예약·단체·수동 문자를 모두 막는다. 수동 발송 시 경고 후 관리자 해제가 필요하다.

3. **특정 자동화 제외**  
   수신·발신·부재중·후속 중 선택한 유형만 제외한다.

### 12.2 등록 위치

- 고객 상세
- 문자 설정의 발송 제외 목록
- 발송 실패·수신거부 처리 화면
- 단체문자 수신자 검토 화면

### 12.3 제외 데이터

- 전화번호
- 고객 ID
- 제외 수준
- 제외할 자동화 유형
- 사유
- 등록일
- 해제일

발송 직전에 항상 다시 검사한다.

## 13. 중복발송 방지

중복방지는 단순히 `24시간 안에 같은 번호 차단` 하나로 끝내지 않는다.

### 13.1 차단 기준

- 같은 통화 이벤트에서 동일 목적 문자는 한 번만
- 같은 고객·템플릿·본문이 설정 시간 안에 발송됐으면 차단
- 자동발송 예정이 있으면 통화 종료창의 수동발송과 하나로 병합
- 같은 일정에 연결된 후속문자는 하나만 활성화
- 같은 번호가 여러 그룹에 포함돼도 단체문자 한 번만
- 예약과 즉시발송이 겹치면 사용자에게 선택 요청
- 실패한 발송은 성공 중복으로 계산하지 않음

### 13.2 멱등키

```text
workspace_id
+ normalized_phone
+ trigger_type
+ call_event_id 또는 task_id 또는 campaign_id
+ template_id
+ body_hash
```

같은 멱등키의 활성 작업은 하나만 허용한다.

### 13.3 사용자 설정

- 1시간
- 6시간
- 12시간
- 24시간
- 3일
- 7일
- 직접 입력

사용자가 수동으로 강제 재발송할 때는 중복 사유와 마지막 발송 시각을 보여준다.

## 14. 그룹과 단체문자

단체문자는 연락처를 무작정 선택해 한꺼번에 보내는 화면으로 만들지 않는다. **고객 그룹을 먼저 만들고 그룹을 발송 대상으로 사용**한다.

### 14.1 그룹 종류

수동 그룹:

- 사용자가 고객을 직접 추가·제거

스마트 그룹:

- 고객 상태
- 최근 연락 기간
- 다음 일정 유무
- 일정 종류
- 관리공백
- 사용자 태그
- 문자 발송 여부

예시:

- 견적 발송 고객
- 이번 주 예약 고객
- 7일 이상 미연락 고객
- 완료 전 고객
- 재방문 안내 대상

### 14.2 단체문자 발송 흐름

```text
그룹 선택
→ 템플릿 선택
→ 변수 치환 미리보기
→ 예상 수신자 계산
→ 중복번호 제거
→ 발송 제외 제거
→ 오류 번호 제거
→ 최종 인원 확인
→ 지금 발송 / 예약 발송
→ 순차 발송
→ 결과 요약
```

### 14.3 발송 전 검토

반드시 아래 숫자를 보여준다.

- 그룹 전체
- 실제 발송 대상
- 중복 제거
- 자동문자 제외
- 전체 문자 제외
- 전화번호 오류
- 이미 최근 발송

### 14.4 발송 실행

- 수신자별 변수 개별 치환
- 설정한 간격으로 순차 발송
- 진행 중 남은 발송 취소 가능
- 성공·실패·건너뜀 개별 기록
- 실패 수신자만 다시 보내기
- 같은 캠페인에서 같은 번호 한 번만

## 15. 후속문자 취소 조건

후속문자는 예약 시간이 됐다고 무조건 보내지 않는다.

자동 취소 조건:

- 고객과 다시 통화함
- 고객 상태가 완료·종료로 변경됨
- 연결 일정이 변경·완료·삭제됨
- 고객이 자동문자 또는 전체 문자 제외로 변경됨
- 같은 목적의 문자를 수동 발송함
- 새 후속문자로 교체함
- 구독 또는 자동화 규칙이 비활성화됨

취소 사유를 타임라인과 발송내역에 표시한다.

```text
후속문자 취소
사유: 고객과 다시 통화함
```

## 16. 자동발송과 정리창 충돌

수신·발신 자동발송이 켜져 있을 때 통화 종료 정리창에서 같은 문자를 다시 보내면 안 된다.

### 기본 동작

```text
통화 종료
→ 자동발송 작업을 임시 예정 상태로 생성
→ 큰 정리창에 `자동발송 예정` 표시
→ 사용자가 문구 수정·취소·즉시 확정
→ 저장 시 한 번만 발송
```

정리창을 사용하지 않도록 설정한 경우에만 자동화 규칙대로 백그라운드 발송한다.

부재중 문자는 통화 종료 정리창을 기다리지 않고 설정대로 처리할 수 있다.

## 18. 삼성 리마인더와의 차별점

> **리마인더는 할 일을 알려준다. 콜태그는 전화가 끝난 뒤 해야 할 일을 실제로 처리한다.**

삼성 리마인더와 다른 핵심:

- 통화 이벤트 자동 감지
- 고객 상태와 상담 이력
- 수신·발신·부재중 자동문자
- 저장형 템플릿과 변수 치환
- 일정과 연결된 후속문자
- 상태·통화·일정 변화에 따른 자동 취소
- 문자 발송 제외와 중복방지
- 그룹·단체문자
- 통화·문자·일정 통합 타임라인
- 관리공백에서 즉시 행동

콜태그는 단순 알림의 대체재가 아니라 **전화 기반 CRM 실행 도구**다.

## 20. 개발 우선순위

### P0 — 사용자 혼란 제거

- `전화정보 고객표시` 화면·메뉴 제거

- 통화 종료 큰 정리창 기본 복구
- 모든 명칭을 `후속문자`로 통일

### P1 — 문자 기본 구조 재설계

- 수신·발신·부재중·후속 네 유형

- 중복발송 방지

### P2 — 고객과 일정 연결

- 고객 상세 `전화 / 일정 추가 / 문자`
- 상태 배지 드롭다운
- 템플릿 우선 문자 발송
- 일정과 후속문자 연결
- 일정 변경·완료·삭제 연동
- 고객 타임라인 문자 통합

### P3 — 그룹과 단체문자

## 21. 완료 기준

- 사용자가 `전화정보 고객표시`라는 기술 메뉴를 보지 않는다.
- 통화 종료 후 큰 정리창이 기본 진입점으로 열린다.
- 문자 설정이 수신·발신·부재중·후속으로 명확히 나뉜다.
- 템플릿을 여러 개 저장·검색·수정·복제·삭제할 수 있다.
- 지원 변수는 실제 값으로 치환되고 미치환 변수는 발송되지 않는다.
- 고객 상세에서 템플릿을 골라 즉시·예약·후속문자를 보낼 수 있다.
- 일정과 연결된 후속문자가 일정 변경·완료·삭제에 따라 처리된다.
- 제외 고객에게 자동·단체문자가 발송되지 않는다.
- 같은 통화·일정·캠페인에서 중복문자가 발송되지 않는다.
- 그룹 단체문자는 중복·제외·오류 번호를 제거한 최종 대상만 발송한다.
- 전화·메모·상태·일정·문자가 같은 고객 타임라인에 연결된다.
