# 콜태그 v0.40.8 안정화 패치

## 사용자 확인 완료

2026-08-03 사용자 실기기에서 에이닷·삼성 전화 실제 수신 시 고객명과 최근 메모가 표시되는 것을 확인했다.

이 확인은 사용자 실기기 결과이며 다음 경계 조건까지 자동으로 완료 처리하지 않는다.

- 미저장 번호
- 이름없는고객
- Google·삼성 동일 번호 중복 결합
- 기능 해제 후 원본 복원
- 메모 변경 직후 갱신

## 1. 앱 시작 무한 로딩 방지

- 로딩 화면 최소 표시 시간은 750ms로 유지한다.
- 서버 로그인 확인의 최대 대기 시간을 8초로 제한한다.
- 8초 안에 응답이 없으면 저장된 로그인 상태를 기준으로 이동한다.
- 저장된 로그인 상태가 있으면 필수 설정 또는 메인 화면으로 이동한다.
- 저장된 로그인 상태가 없으면 로그인 화면으로 이동한다.
- 늦게 도착한 서버 응답이 화면을 다시 열지 못하도록 1회 라우팅을 유지한다.

## 2. 사용자 진단 메뉴 제거

- 계정 화면의 `앱 상태 진단` 메뉴를 제거했다.
- AccountActivity의 DiagnosticActivity 실행 경로를 제거했다.
- 사용자 APK Manifest에서 DiagnosticActivity 등록을 제거했다.
- DiagnosticActivity 소스는 과거 개발 이력 보존을 위해 남아 있을 수 있으나 일반 사용자 앱에서 실행할 수 없다.

## 3. 통화 종료 팝업 작은 화면·키보드 대응

- 팝업 최대 가로 420dp와 최대 세로 560dp는 유지한다.
- 최소 높이를 420dp에서 300dp로 낮췄다.
- 작은 화면은 좌우 여백을 줄여 사용 가능한 폭을 확보한다.
- Android 11 이상은 IME 키보드 높이를 감지한다.
- 키보드가 열리면 팝업 높이를 사용 가능한 영역에 맞춰 줄인다.
- 키보드가 닫히면 원래 소형 팝업 높이로 복원한다.
- 하단 저장 버튼은 ScrollView 밖에 고정한다.
- 헤더, 입력창, 섹션 간격, 메모·문자 입력 높이를 축소했다.

## 4. 데이터 안전

이번 패치는 DB 스키마를 변경하지 않는다.

- 기존 고객 유지
- 기존 메모 유지
- 기존 문자·예약·캠페인 유지
- Google·삼성 원본 연락처 직접 수정 없음
- 앱 삭제 없이 덮어 설치

## 5. 검증 구분

빌드 성공으로 확인 가능한 범위:

- Android 리소스 처리
- Java 컴파일
- Manifest 병합
- Debug APK 패키징

실기기에서 별도로 확인할 범위:

- 통화 종료 팝업 30초 이상 유지
- 작은 화면과 큰 글자
- 키보드 표시 중 저장 버튼 접근
- 오프라인에서 8초 이내 앱 진입
