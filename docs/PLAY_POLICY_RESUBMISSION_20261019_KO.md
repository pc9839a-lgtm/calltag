# 콜태그 0.44.63 Google Play 재제출 문안 (2026-10-19)

대상: `kr.pagero.calltag`, versionCode `2026101901`. 이 문안은 수정 빌드와 일치하도록 작성했다. Play Console에 반영된 상태나 Google의 승인을 뜻하지 않는다.

## 앱 이름
콜태그 - 통화 후 고객관리·자동문자

## 간단한 설명
통화 후 고객관리와 SMS 발송을, 사용자가 설정한 통화 조건에 따라 자동화합니다.

## 자세한 설명
콜태그는 통화가 끝난 뒤 고객관리 업무와 안내 문자 발송을 돕는 Android 앱입니다. 사용자가 자동문자를 켜고 통화 후·부재중·후속 예약 조건, 템플릿, 발송 회선과 업무시간을 직접 설정하면, 조건에 맞는 통화를 확인한 뒤 휴대전화의 SIM을 통해 SMS를 자동 발송합니다. 자동문자는 처음에는 꺼져 있으며 언제든 끌 수 있습니다.

통화 후 고객을 구분하고 상담 결과, 메모, 다음 할 일, 재연락 일정을 남길 수 있습니다. 저장한 기록은 고객별 상담 이력으로 모여 필요한 내용을 확인할 수 있습니다.

주요 기능
• 수신·발신 통화 종료와 부재중 전화에 따른 고객관리
• 사용자가 켠 조건에 따른 통화 후·부재중·후속 예약 SMS 자동 발송
• 문자 템플릿, 발송 회선, 업무시간 및 중복 발송 방지 설정
• 고객별 상담 메모와 연락 이력, 태그 관리
• 오늘 할 일과 후속 일정 관리
• 고객 그룹 및 단체 문자 관리
• 고객 상태와 상담 단계, 기간별 통계
• 외부 캘린더 일정 추가

권한 사용 안내
• 통화기록(READ_CALL_LOG) 및 전화 상태: 통화 종료 후 번호·시각·통화 유형을 확인하고 고객관리 이력 연결과 자동화 중복 실행 방지에 사용합니다. 사용자가 권한 허용 화면에서 직접 선택합니다.
• 문자 발송(SEND_SMS): 사용자가 자동문자와 개별 통화 조건을 켜고 저장할 때 별도로 요청합니다. 승인된 조건에 따른 SMS 발송에 사용합니다.
• 연락처: 전화번호에 해당하는 고객명을 확인하고 연락처에서 고객을 선택하는 데 사용합니다.
• 알림 및 다른 앱 위 표시: 통화 종료 후 고객관리 화면과 후속 일정 알림을 제공하는 데 사용합니다.

콜태그는 기본 전화 앱을 변경하거나 통화 내용을 녹음하거나 듣지 않습니다. SMS는 사용 중인 휴대전화의 SIM과 이동통신망으로 발송되며 이동통신사 요금제에 따라 비용이 발생할 수 있습니다. 이미지 문자는 기기의 기본 메시지 앱에서 사용자가 최종 확인한 뒤 발송합니다.

계정과 서버에 저장된 관련 데이터는 앱의 회원탈퇴 기능 또는 콜태그 계정 삭제 안내 페이지를 통해 삭제 요청할 수 있습니다.

## SMS/통화 기록 선언의 검토 안내 (500자 이내)
콜태그는 사용자가 설정한 통화 후·부재중·후속 예약 조건에 따라 고객관리와 SMS 발송을 자동화합니다. READ_CALL_LOG로 실제 통화의 번호·시각·유형을 확인해 이력을 연결하고 중복 실행을 막습니다. SEND_SMS는 사용자가 자동문자와 개별 조건·템플릿·회선을 켜고 권한을 허용한 경우에만 사용합니다. 검토: 로그인 → ‘통화 후 자동관리 권한 허용’ → 자동문자 설정 → ‘자동문자 사용’과 ‘통화 후’ 켜기 → 저장·SMS 권한 허용 → 실제 통화 → 발송 내역 확인 → 자동문자 끄기. 심사 계정에는 문자 기능 이용권이 필요합니다.

## 업데이트 시 자동문자 설정
0.44.61의 전역 자동문자 설정에는 계정 소유자 정보가 없어 안전하게 특정 계정에 귀속시킬 수 없습니다. 0.44.63은 계정별 설정을 새로 만들고 자동문자를 OFF로 시작합니다. 기존 사용자는 업데이트 후 조건과 템플릿을 확인하고 자동문자를 다시 켜야 합니다.

- 수정된 0.44.63 빌드를 실제 기기에 설치한 뒤 권한 요청, 통화, SMS 결과, 자동문자 OFF를 화면 녹화한다.
