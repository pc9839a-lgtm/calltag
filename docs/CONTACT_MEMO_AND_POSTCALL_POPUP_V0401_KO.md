# 콜태그 v0.40.6 전화 수신 메모·통화 종료 팝업 기준

> 이 문서는 현재 Android 구현의 정본이다. v0.40.3의 오버레이 단독 방식은 폐기됐고, v0.40.5부터 연락처 Provider 방식이 다시 주 기능이다.

## 1. 전화 수신 메모 표시

전화가 오기 전에 콜태그 전용 RawContact를 생성하고 표시명을 `고객명 · 최근 메모` 형태로 동기화한다.

- Google·삼성 원본 RawContact는 직접 수정하거나 삭제하지 않는다.
- 같은 번호의 콜태그 RawContact를 만들어 Android 연락처 집계로 결합한다.
- 최근 메모는 최대 16자다.
- 전체 표시명은 최대 32자다.
- 이름없는고객은 `고객 + 전화번호 끝 4자리`로 표시한다.
- 메모가 없으면 고객명만 표시한다.
- 앱 사용 중 5초마다 변경사항을 동기화한다.
- 고객 수정·통화 메모 저장 후에도 재동기화한다.
- 기능을 끄면 콜태그 전용 연락처와 계정만 제거한다.

## 2. 필수 권한

- READ_CONTACTS
- WRITE_CONTACTS
- READ_PHONE_STATE
- READ_PHONE_NUMBERS
- READ_CALL_LOG
- POST_NOTIFICATIONS
- 문자 기능 사용 시 SEND_SMS

WRITE_CONTACTS는 콜태그 전용 RawContact의 생성·갱신·삭제에만 사용한다.

## 3. 상세 수신 오버레이

CallScreeningService와 다른 앱 위 표시를 이용한 상세 카드는 선택 기능이다. 삼성 전화·에이닷 수신 화면에서 메모가 보이는 기본 경로는 연락처 표시명이다.

## 4. 통화 종료 팝업

통화 종료 후 앱 전체 화면을 열지 않고 중앙의 작은 정리 팝업을 표시한다.

- 가로 최대 420dp
- 세로 화면의 약 66%, 최대 560dp
- 내부 내용은 팝업 안에서 스크롤
- 바깥 영역 터치로 닫히지 않음
- 배경 어둡기 0.42
- 전화 앱 종료 전환이 끝나도록 1.2초 기다린 뒤 표시
- 같은 통화 ID는 8초 안에 중복 실행하지 않음
- 콜태그 메인 task와 분리된 전용 popup task에서 실행
- Activity created·started·resumed 시 창 크기를 다시 적용

## 5. 팝업 종료 조건

다음 사용자 동작 전에는 자동으로 닫지 않는다.

- 상단 닫기
- 저장만 하기 완료
- 저장하고 문자 보내기 완료
- 고객관리 제외 완료

통화 상태 IDLE, 연락처 동기화, Activity pause·stop만으로 팝업을 종료하지 않는다.

## 6. 실기기 QA

### 수신 메모

1. 삼성 연락처 앱에서 `고객명 · 최근 메모` 확인
2. 에이닷·삼성 전화로 실제 수신
3. 메모 변경 후 5초 내 연락처 표시명 갱신 확인
4. 기존 Google·삼성 연락처 원본 데이터가 유지되는지 확인

### 통화 종료 팝업

1. 통화 종료 후 전화 앱 화면 전환이 끝나고 소형 팝업이 표시되는지 확인
2. 팝업이 최소 30초 이상 자동으로 사라지지 않는지 확인
3. 바깥 영역을 눌러도 닫히지 않는지 확인
4. 저장 또는 닫기 버튼을 눌렀을 때만 종료되는지 확인
5. 저장 후 연락처 표시명에 최신 메모가 반영되는지 확인

APK 컴파일 성공과 실제 삼성·에이닷 실기기 성공은 구분하여 기록한다.
