# 홈·고객·문자 UX 재개편 계획

## 목표

콜태그의 핵심 흐름을 `통화 종료 → 고객 정리 → 오늘 할 일 → 고객에게 문자`로 단순화한다.

## 적용 범위

1. 하단 가운데 홈을 다른 메뉴보다 크고 위로 돌출된 주 행동 버튼으로 표시한다.
2. 고객 화면에 `고객 / 문자` 상단 탭을 복구하되 고객을 선택하지 않은 독립 문자 작성은 제공하지 않는다.
3. 홈 빠른 메뉴를 `고객 추가 / 고객 목록 / 문자`로 고정한다.
4. 홈의 `고객 할 일` 문구를 `오늘 할 일`로 변경한다.
5. 통화 종료 후 `PostCallActivity`를 즉시 여는 것을 우선하고, 시스템 차단 시 전체 화면 알림을 대체 수단으로 사용한다.
6. 문자 템플릿은 카테고리 토글을 제거하고 카드 한 번 클릭으로 선택한다. 관리 모드에서만 수정·삭제를 노출한다.
7. 템플릿 편집 입력값은 `이름 / 내용 / 이미지`만 유지한다.
8. 선택한 템플릿 이름과 이미지 여부를 문자 작성 화면에 명확히 표시하고 바로 수정할 수 있게 한다.
9. 더보기는 검색 가능한 큰 카드 버튼으로 교체하고 `문자 관리 / 고객·일정 / 앱·계정`으로 묶는다.
10. 고객 그룹과 단체문자는 `그룹·단체문자` 하나의 진입점으로 합친다.
11. 홈 오늘 할 일과 고객 목록에 `페이지로 유입 / 전화 유입 / 직접 등록` 배지를 표시한다.

## 데이터·발송 안전

- 기존 고객, 일정, 템플릿, 메시지 작업을 초기화하지 않는다.
- 템플릿 카테고리 값은 호환을 위해 저장하되 화면 입력과 목록 구분에는 사용하지 않는다.
- 이미지 문자는 기존 정책대로 기본 메시지 앱에서 사용자가 최종 전송한다.
- 자동문자, 발송 제외, 중복 방지, SIM 및 생명주기 검사를 우회하지 않는다.
- 통화 종료 화면 직접 호출 실패 시 기존 알림을 유지한다.
- main 브랜치에 병합하지 않고 Draft PR을 유지한다.
