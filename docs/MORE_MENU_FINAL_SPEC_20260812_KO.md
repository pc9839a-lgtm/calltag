# 콜태그 더보기 메뉴 최종 구조

기준일: **2026-08-12**

이 문서는 더보기 메뉴 정보구조와 고객센터 처리 방식의 확정안이다. 구현 시 상위 메뉴를 과도하게 잘게 나누지 않고, 각 화면에 필요한 핵심 기능만 둔다.

## 1. 더보기 상위 메뉴 순서

```text
더보기

계정
이용권
문자 관리
고객 관리
페이지로
파트너
데이터 관리
앱 정보
```

총 8개를 기본으로 한다.

### 절대 기준

- `계정`은 더보기 최상단에 둔다.
- `통화 후 자동문자`는 독립 상위 메뉴/대형 카드로 빼지 않고 `문자 관리` 첫 항목에 둔다.
- `이용권·결제`처럼 기능명을 과도하게 늘리지 않고 상위 메뉴명은 `이용권`으로 단순화한다.
- 상위 화면에서 세부 기능을 전부 노출하지 않는다. 더보기는 목적지 선택용, 세부 화면은 실제 설정용으로 분리한다.

## 2. 계정

사람/로그인 정보만 둔다.

- 이름
- 이메일
- 휴대폰번호
- 비밀번호 변경
- 로그아웃
- 회원탈퇴

결제, 약관, 버전, 백업은 계정 화면에 넣지 않는다.

## 3. 이용권

최대한 단순하게 유지한다.

예시:

```text
이용권

현재 이용권        통합권
이용 상태          이용 중
다음 결제일        2026.09.12

[ 이용권 변경 / 결제 관리 ]
```

구매 복원, 결제 내역, 무료기간, 구독 상태를 각각 별도 상위 메뉴로 만들지 않는다. 필요한 기능은 이용권 화면 또는 결제 관리 흐름 안에서 처리한다.

## 4. 문자 관리

- 통화 후 자동문자
- 문자 템플릿
- 그룹·단체문자
- 발송 내역
- 발송 설정

`통화 후 자동문자`는 문자 관리의 첫 항목으로 배치한다.

## 5. 고객 관리

- 고객 상태
- 일정 종류
- 통화 후 팝업 설정

CRM 사용자가 직접 조정하는 기준값과 통화 후 고객관리 동작만 둔다.

## 6. 페이지로

- 연결 상태
- 페이지로 연결 / 해제
- 페이지로 바로가기

별도의 장문 `페이지로 서비스 안내` 메뉴는 만들지 않는다. 필요한 설명은 연결되지 않은 상태에서 짧게 노출한다.

## 7. 파트너

- 내 추천코드
- 추천 현황
- 파트너 현황
- 정산

친구 초대, 추천, 파트너, 정산을 여러 상위 메뉴로 분리하지 않는다.

## 8. 데이터 관리

- 동기화 상태
- 백업 및 복원
- 필요한 경우 복구 상태/진단

`데이터 보호`, `복구`, `백업`, `동기화`를 각각 별도 상위 메뉴로 만들지 않는다.

## 9. 앱 정보

법적/서비스 정보는 모두 여기로 모은다.

- 버전 정보
- 서비스 이용약관
- 개인정보처리방침
- 고객센터

오픈소스 라이선스가 실제 배포 요구나 사용 라이브러리 고지상 필요하면 이 화면에 추가한다.

### 버전 표시

사용자에게는 `콜태그 0.44.20`처럼 versionName 중심으로 표시한다. 내부 versionCode는 디버그/진단용으로만 추가 표기할 수 있다.

## 10. 고객센터 — 확정 방식

고객센터는 외부 메일 앱을 여는 `mailto:` 방식이 아니라 **앱 안의 문의 폼 → 서버 API → 운영 메일 전송** 방식으로 구현한다.

수신 메일:

```text
roadfor@kakao.com
```

기본 입력:

- 문의 유형: 일반문의 / 결제 / 오류 / 기타
- 이름
- 연락처 또는 이메일
- 문의 내용

앱에서 자동 첨부 가능한 정보:

- 앱 버전
- 로그인 계정 식별에 필요한 최소 정보
- 문의 접수 시각

개인정보는 문의 해결에 필요한 최소 범위만 전송한다.

### 메일 형식 예시

제목:

```text
[콜태그 고객문의] 결제 - 사용자명
```

본문에는 사용자 입력값과 앱 버전을 정리해 전송한다.

고객이 이메일을 입력한 경우 서버 발송 메일의 `Reply-To`를 고객 이메일로 설정하여 `roadfor@kakao.com`에서 답장 시 고객에게 바로 회신할 수 있게 한다.

## 11. 구현 우선순위

1. 더보기 상위 8개 구조로 재배치
2. 계정을 최상단 이동
3. 통화 후 자동문자를 문자 관리로 이동
4. 이용권 화면 단순화
5. 앱 정보 화면에 이용약관/개인정보처리방침/버전/고객센터 배치
6. 고객센터 문의 API 및 `roadfor@kakao.com` 메일 발송 연결
7. 기존 중복 메뉴/설명 카드 제거
