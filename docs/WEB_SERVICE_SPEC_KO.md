# 콜태그 웹서비스 기획 및 구현 기준

기준일: 2026-07-30  
공개 도메인: `https://calltag.pagero.kr`  
Cloudflare Pages 프로젝트: `calltag`  
배포 저장소: `pc9839a-lgtm/calltag`  
배포 브랜치: `main`  
배포 디렉터리: `web`

## 1. 서비스 관계

콜태그 웹은 Android 앱과 별개의 제품이 아니라 같은 고객관리 서비스의 PC 화면이다.

- Android 앱: 통화 감지, 통화 직후 고객 분류, 상담 결과 입력, 다음 행동 등록
- 콜태그 웹: 고객 목록, 상담 진행 상태, 일정·캘린더, 후속업무 관리
- 콜링크: 통화 후 문자, 메시지 템플릿, 발송 이력
- 공통 기반: 페이지로 계정, 고객, 통화·상담 기록, 기기, 결제·구독

장기적으로 콜태그와 콜링크는 같은 계정과 고객 데이터를 사용한다. 도메인이 달라도 로그인과 데이터 구조는 통합한다.

## 2. 현재 웹 1차 구현 범위

`web/index.html`에 반응형 웹 대시보드 1차 화면을 구축한다.

### 주요 메뉴

1. 오늘
   - 기한 지난 업무
   - 오늘 재연락
   - 정리하지 않은 통화
   - 진행 중 상담
   - 최근 통화
2. 고객
   - 이름·전화번호·상담내용 검색
   - 신규·상담 중·기존·휴면 필터
   - 고객 상태와 다음 업무 확인
3. 상담
   - 신규 문의
   - 상담 중
   - 검토·재연락
   - 계약 예정
4. 캘린더
   - 월간 일정
   - 재연락, 자료 발송, 방문, 계약 확인
   - 일정 추가
5. 설정
   - Android 기기 연결 상태
   - 자동 동기화
   - 고객 분류 기준
   - 통화 후 처리 기준

### 1차 상호작용

- 좌측 메뉴와 모바일 하단 메뉴 전환
- 고객 검색과 상태 필터
- 고객 추가 모달
- 일정 추가 모달
- 업무 완료·미루기
- 완료 상태 로컬 저장
- 월간 캘린더 이전·다음 이동
- 앱 동기화 상태 표시

현재 단계의 데이터는 UI 검증용 샘플이며 브라우저 로컬 상태만 사용한다.

## 3. 화면 설계 원칙

- 색상은 네이비·블루를 중심으로 사용하고 상태 표시 외 장식색을 최소화한다.
- 버튼은 테두리, 배경, 높이로 클릭 가능 여부가 즉시 구분돼야 한다.
- PC에서는 좌측 메뉴, 모바일에서는 하단 메뉴를 사용한다.
- 주요 버튼 높이는 최소 40px, 모바일 터치 영역은 최소 44px를 확보한다.
- 업무 흐름은 `통화 → 고객 확인 → 상담 상태 → 다음 행동 → 캘린더` 순서로 연결한다.
- 고객과 상담건을 분리해 한 고객이 여러 상담을 가질 수 있도록 유지한다.
- 일정은 단순 날짜 표시가 아니라 전화·문자·자료 발송·방문 등 실제 후속 행동과 연결한다.

## 5. 데이터 기준

웹에서도 기존 데이터 모델을 그대로 사용한다.

- `Customer`: 고객 장기 관계 정보
- `Opportunity`: 개별 문의·견적·계약 진행건
- `Interaction`: 통화, 문자, 메모, 미팅 기록
- `FollowUpTask`: 재연락, 자료 발송, 방문 등 다음 행동
- `PhoneRule`: 제외번호, 수신거부, 개인통화 규칙

캘린더는 별도 일정 객체를 중복 생성하기보다 `FollowUpTask.dueAt`을 기본 일정으로 사용한다. 일반 일정이나 회의가 필요한 경우 `Interaction.type = MEETING` 또는 후속 일정 객체를 확장한다.

## 6. Cloudflare Pages 배포 설정

```text
프로젝트 이름: calltag
프로덕션 분기: main
프레임워크: 없음
빌드 명령: exit 0
빌드 출력 디렉터리: web
사용자 설정 도메인: calltag.pagero.kr
```

`main` 브랜치의 `web/` 변경사항은 Cloudflare Pages에서 자동 배포한다.

## 7. 완료 기준

웹 1차 버전은 다음 조건을 충족하면 완료로 본다.

- `calltag.pagero.kr`에서 화면이 정상 로드된다.
- PC 1280px 이상에서 좌우 잘림이 없다.
- 모바일 360px 이상에서 메뉴와 버튼이 겹치지 않는다.
- 오늘·고객·상담·캘린더·설정 메뉴가 모두 전환된다.
- 고객 검색, 업무 완료, 일정 추가 화면이 작동한다.
- Android 앱과 웹의 역할이 문서상 명확히 구분된다.
