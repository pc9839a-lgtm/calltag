# CallTag v0.42.4 자동문자 템플릿·후속기간 패치

- 적용일: 2026-08-05
- 버전: `0.42.4` / versionCode `64`

## 변경 사항

### 자동문자 메인 화면

통화 후, 부재중, 후속 예약 카드마다 `템플릿 선택` 버튼을 항상 표시한다.

각 카드에는 현재 연결된 템플릿 이름을 다음 형식으로 표시한다.

```text
선택된 템플릿 · 수신 통화 안내
```

기존처럼 카드 전체를 눌러야 템플릿 선택 화면이 열리는 숨은 동작에 의존하지 않는다.

### 후속문자 발송 시점

후속 예약 카드에 `발송 시점 · N일 후` 버튼을 표시한다.

선택값:

- 1일 후
- 3일 후
- 5일 후
- 7일 후
- 직접 입력: 1~30일

기존 사용자에게 저장된 값이 없으면 3일을 기본값으로 사용한다.

후속 기간은 공통 설정에서 제거하고 후속 예약 카드에서 직접 변경한다.

### 템플릿 편집 화면

다음 변수 예시 문구를 제거한다.

```text
변수 · {고객명}, {날짜}, ...
```

변수 치환 엔진과 기존 템플릿 데이터는 유지한다. 사용자 화면의 변수 예시만 제거한다.

## 저장·호환성

- 템플릿 선택 즉시 기본 템플릿 연결값을 저장한다.
- 후속 기간은 최종 `저장` 버튼을 누를 때 `delay_days`로 저장한다.
- 허용 범위는 1~30일이다.
- 기존 자동문자 활성화, 업무시간, 중복방지, SIM 회선 설정은 유지한다.

- 후속 기간이 공통 설정에 남아 있지 않음
- 템플릿 변수 예시 제거
