# 콜태그 v0.19.0 통합 개발 상태

기준일: 2026-07-31  
브랜치: `agent/calltag-foundation`  
버전: `0.19.0` / versionCode `21`

## 1. 이번 통합의 목적

기존 콜태그의 전화관리 기능과 기존 콜링크의 문자 자동화 핵심 로직을 별도 앱으로 유지하지 않고 `kr.pagero.calltag` 단일 앱 안에서 실행하기 시작한다.

이번 버전은 UI만 합친 버전이 아니다. 하나의 통화 감지 서비스가 전화관리와 문자 자동화 모듈을 각각 실행하는 첫 통합 버전이다.

## 2. 완료된 기능

### 단일 앱과 구독 권한 골격

- 앱명 `콜태그` 유지
- 패키지 `kr.pagero.calltag` 유지
- 전화관리 월 1,900원
- 문자자동화 월 990원
- 통합 이용 월 2,500원
- 하나의 APK 안에서 전화관리·문자자동화 권한을 분리하는 `FeatureEntitlementStore` 추가
- 결제 연동 전 개발 빌드는 통합 이용 권한을 기본 적용

### 최초 권한 흐름

- 기존 긴 `전화 고객정보 표시` 필수 화면 제거
- 로그인 후 Android 시스템 권한창 자동 실행
- 연락처 읽기·수정, 전화 상태, 전화번호, 통화기록, 문자 발송, 알림 권한 요청
- 사용자가 거절해도 긴 설정 화면으로 반복 이동하지 않음
- 허용된 기능만 활성화하고 홈으로 진입

### 메인 메뉴 통합

하단 메뉴:

1. 홈
2. 고객
3. 캘린더
4. 문자

문자 화면에 다음 기능을 직접 배치했다.

- 템플릿으로 시작
- 자유롭게 작성
- 통화 종료 자동발송 켜기·끄기
- 부재중·거절 자동발송 켜기·끄기
- N일 뒤 후속문자 켜기·끄기
- 자동발송 상세 설정
- 발송·예약 내역

### 실제 SMS 발송

- Android `SmsManager` 사용
- 선택한 SIM·eSIM 회선 사용
- 장문은 multipart SMS로 분할 발송
- 각 발송 조각의 시스템 발송 결과 수신
- 전체 조각 성공 후 `발송 완료` 기록
- 통신사·권한 오류 시 실패 사유 기록

### 자동 발송

- 연결된 수신 통화 종료 후 자동발송
- 연결된 발신 통화 종료 후 자동발송
- 부재중·거절 통화 후 자동발송
- 업무시간 제한
- 같은 번호·같은 트리거 중복발송 방지
- 자동발송 규칙은 기본 OFF로 시작해 의도하지 않은 문자 발송 방지

### 예약·후속 문자

- 수동으로 1~30일 뒤 예약
- 연결 통화 후 기본 3일 뒤 후속문자 자동 예약
- 지연 일수 사용자 변경
- 새 통화가 감지되면 같은 번호의 이전 자동 후속문자 취소
- 예약 내역에서 지금 보내기·예약 취소
- 재부팅·앱 업데이트 후 예약 작업 복구
- exact alarm 특수권한 없이 `AlarmManager.setAndAllowWhileIdle` 사용

### 발송 기록

상태:

- `SCHEDULED`
- `READY`
- `SENDING`
- `SENT`
- `FAILED`
- `SKIPPED`
- `CANCELLED`

기록 항목:

- 고객 ID
- 통화기록 ID
- 전화번호
- 본문 스냅샷
- 트리거 종류
- 발송 회선
- 예약시각
- 발송시각
- 오류·취소 이유

## 3. 통합 실행 흐름

```text
통화 종료 또는 부재중 감지
→ CallMonitorService에서 최신 통화기록 확정
→ 전화관리 구독이면 고객·일정·통화 후 정리 처리
→ 문자자동화 구독이면 자동발송 규칙 평가
→ 즉시 SMS 또는 지연 예약 작업 생성
→ 고객·통화 ID와 문자 작업 연결
```

## 4. 아직 이전하지 않은 콜링크 기능

이번 버전에 포함하지 않은 기능:

- 이미지 MMS 실제 발송
- 템플릿 라이브러리 저장·복제·삭제
- 고객 그룹 단체문자
- CSV 가져오기
- 한 작업 최대 30명 순차발송
- 랜딩페이지 자동 첨부
- 회선별 서로 다른 이미지·문구 세트
- 원스토어 실제 정기결제
- 서버 구독 검증
- 웹 동기화

위 기능은 기존 `pc9839a-lgtm/call-auto-sms-android`의 검증 코드를 콜태그 데이터 모델에 맞게 순차 이전한다.
