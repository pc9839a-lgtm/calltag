# CallTag v0.43.1 내부 테스트 피드백 패치

최종 갱신: 2026-08-06

## 적용 항목

1. Android 15·16 edge-to-edge 환경에서 모든 Activity가 상태바·카메라 홀·내비게이션바 안전영역을 적용한다.
2. Android 16 PendingIntent 백그라운드 Activity 시작 opt-in과 통화 종료 full-screen 알림 fallback을 추가한다.
3. 통화 종료 팝업 권한 확인 화면을 추가하고 업데이트 후 권한이 빠진 사용자에게 한 번 안내한다.
4. 개별 일정 공유 화면을 모든 예정 일정의 외부 캘린더 자동 연동 화면으로 교체한다.
5. 통화 직후 자동문자와 후속문자 자동화를 별도 화면으로 분리한다.
6. 후속문자는 이름·발송일 1~30일·템플릿·사용 여부가 서로 다른 규칙을 여러 개 등록할 수 있다.
7. 더보기에서 중복된 문자·고객·일정 메뉴를 제거한다.
8. 더보기에 페이지로 전용 섹션을 만들고 문의 동기화와 페이지로 사용 안내를 분리한다.
9. 내 추천인 코드·추천인 코드 등록·정산을 각각 별도 화면으로 분리한다.
10. 정산 화면에 은행·예금주·계좌번호·정산 이메일·정산 유형·사업자등록번호를 추가한다.
11. 계좌·정산정보는 계정별 Android Keystore AES-GCM으로 암호화해 현재 기기에 저장한다.

## 외부 캘린더 연동

- 권한: `READ_CALENDAR`, `WRITE_CALENDAR`
- 사용자가 쓰기 가능한 Google·삼성 캘린더를 선택한다.
- 콜태그의 모든 미완료 일정을 insert/update한다.
- 완료·삭제된 일정은 앱이 생성한 외부 이벤트 매핑에서 제거한다.
- 앱 실행·복귀·백그라운드 전환 시 활성화된 계정만 다시 확인한다.
- 외부 이벤트에는 고객명, 일정명, 연락처, 최근 메모, 콜태그 일정 ID가 포함된다.

## 자동문자 분리

### 통화 후 자동문자

- 통화 직후 자동문자 전체 사용
- 연결된 통화 후 문자
- 부재중·거절 전화 문자
- 업무시간
- 중복 발송 방지 시간
- 발송 SIM

### 후속문자 자동화

- 규칙 개수 제한 없이 추가
- 규칙별 1~30일
- 규칙별 템플릿
- 규칙별 사용 여부
- 새 연결 통화가 감지되면 같은 번호의 기존 후속 예약 전체 취소

## 정산정보 보안

- 저장 키: Android Keystore AES-GCM
- 계정 owner ID 또는 이메일 SHA-256을 AAD·저장키에 사용
- 다른 로그인 계정과 정산정보 분리
- 계좌번호 원문을 일반 SharedPreferences에 저장하지 않음
- 화면에는 마지막 4자리만 요약 표시
- 서버 정산 API가 준비되기 전에는 현재 기기에서만 보관
