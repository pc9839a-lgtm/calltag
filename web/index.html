자주 묻는 질문

시작 전에
확인하세요.

콜태그와 문자자동화는 별도 앱인가요?

아닙니다. 정식 서비스명과 앱은 콜태그 하나입니다. 전화관리와 문자자동화는 같은 앱 안에서 이용권에 따라 사용할 수 있습니다.

문자는 어떤 번호로 발송되나요?

별도 서버 번호가 아니라 사용 중인 Android 휴대폰의 SIM·eSIM 회선으로 발송합니다. 실제 요금과 발송 제한은 통신사 정책을 따릅니다.

자동으로 아무 문자나 발송되나요?

아닙니다. 사용자가 저장하고 활성화한 템플릿과 규칙만 사용합니다. 발송 직전에는 제외, 중복, 변수, 일정 상태를 다시 확인합니다.

현재 모든 기능이 바로 제공되나요?

통합 제품 기준에 따라 기능을 순차 적용 중입니다. 베타와 출시 시점의 실제 제공 범위는 앱 내 안내와 개발 현황을 기준으로 합니다.

아이폰에서도 사용할 수 있나요?

통화 감지와 휴대폰 회선 문자 발송 구조상 현재는 Android 전용으로 준비하고 있습니다.
