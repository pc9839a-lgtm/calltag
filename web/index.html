PRIVACY FIRST

통화 내용은 듣지 않습니다.

콜태그는 통화가 끝난 뒤 사용자가 직접 확인한 정보로 고객과 다음 업무를 정리합니다.

통화 녹음·자동 수집 없음

통화 음성이나 대화 내용을 저장해 분석하는 서비스가 아닙니다.

자동 확정보다 사용자 확인

연락처에 저장됐다는 이유만으로 기존 고객으로 단정하지 않고 사용자가 확인합니다.

업무용 통화만 선택적으로

개인통화, 스팸, 수신거부 번호는 고객관리 대상에서 제외할 수 있습니다.

고객과 상담을 분리해 관리

한 고객에게 여러 문의가 있어도 상담건별 진행 상태와 후속 업무가 섞이지 않습니다.

궁금한 점

아닙니다. 콜태그는 통화 녹음이나 음성 자동 수집을 하지 않습니다. 통화 종료 뒤 사용자가 상담 결과와 다음 행동을 직접 확인해 저장합니다.

개인통화, 스팸, 수신거부 번호는 제외할 수 있습니다. 연락처에 있는 번호라고 해서 자동으로 고객으로 확정하지 않습니다.

통화 직후 처리는 Android 앱에서 빠르게 진행하고, 고객·상담·후속 일정은 웹에서도 확인하고 관리할 수 있도록 개발 중입니다.

현재 Android MVP와 웹서비스를 개발하고 있습니다. 도입 문의를 남기면 출시 일정과 테스트 참여 방법을 안내합니다.
